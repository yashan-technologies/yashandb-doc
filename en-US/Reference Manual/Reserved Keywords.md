The reserved keywords are a subset of the syntax keywords used by YashanDB. Unlike ordinary keywords, reserved keywords are not allowed to be used as [name identifiers](../Development Guide/SQL Reference Manual/Basic SQL Elements/Identifiers) (such as table names, column names, etc.), unless they are enclosed in double quotes.

You can obtain information about all keywords in YashanDB by querying the V$RESERVED_WORDS view.
