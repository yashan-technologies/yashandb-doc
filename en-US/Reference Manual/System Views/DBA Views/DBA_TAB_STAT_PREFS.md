This view displays the statistics options for all tables.

|Field |Type |Description |
| --- | --- | --- |
| OWNER           | VARCHAR(64)| The username of the table        |
| TABLE_NAME      | VARCHAR(64)| The name of the table            |
| PREFERENCE_NAME  | VARCHAR(30)| The name of the statistics option |
| PREFERENCE_VALUE | VARCHAR(4000)| The value of the statistics option |
