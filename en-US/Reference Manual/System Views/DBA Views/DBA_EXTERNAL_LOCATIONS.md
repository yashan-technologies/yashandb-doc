This view displays information about all external tables LOCATIONS.

|Field |Type |Description |
| --- | --- | --- |
| OWNER          | VARCHAR(64)| Username of the owner of the external table location |
| TABLE_NAME     | VARCHAR(64)| Name of the external table to which the location belongs |
| LOCATION       | VARCHAR(4000)| Description of the location                 |
| DIRECTORY_OWNER| CHAR(3)   | Username of the owner of the external table location directory |
| DIRECTORY_NAME | VARCHAR(64)| Name of the external table location directory |
