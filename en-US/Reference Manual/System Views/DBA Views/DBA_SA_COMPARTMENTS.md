This view displays all compartment information of all LBAC label policies.

|Field |Type |Description |
| --- | --- | --- |
| POLICY_NAME  | VARCHAR(64)  | The name of the LBAC label policy |
| COMP_NUM     | SMALLINT     | Compartment number |
| SHORT_NAME    | VARCHAR(64)  | The short name of the compartment |
| LONG_NAME     | VARCHAR(64)  | The long name of the compartment |
