This view displays all level information of all LBAC label policies.

|Field |Type |Description |
| --- | --- | --- |
| POLICY_NAME    | VARCHAR(64)   | The name of the LBAC label policy |
| LEVEL_NUM    | SMALLINT    | Level number       |
| SHORT_NAME    | VARCHAR(64) | The short name of the level |
| LONG_NAME     | VARCHAR(64) | The long name of the level |
