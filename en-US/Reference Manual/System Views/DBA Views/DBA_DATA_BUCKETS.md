This view displays the databucket file information for all LSC tablespaces.

|Field |Type |Description |
| --- | --- | --- |
| BUCKET\_ID | INTEGER | databucket ID |
| BUCKET_NAME      | VARCHAR(255)| databucket name                 |
| BUCKET_TYPE      | INTEGER     | databucket type<br>* 0: LOCAL_FS |
| TABLESPACE_NAME  | VARCHAR(64) | The name of the tablespace to which the databucket belongs |
