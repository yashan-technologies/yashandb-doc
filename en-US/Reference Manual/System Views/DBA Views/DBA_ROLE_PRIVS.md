This view displays the authorization information for all roles in the database.

|Field |Type |Description |
| --- | --- | --- |
| GRANTEE      | VARCHAR(64) | The name of the user or role that receives the authorization |
| GRANTED_ROLE | VARCHAR(64) | The name of the role that is granted |
| ADMIN_OPTION  | VARCHAR(1)  | Indicates whether the authorization includes the admin option<br>*   Y<br/>*   N |
