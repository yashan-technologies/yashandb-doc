This view displays the tablespace information of all partitioned tables and their extended partitions.

|Field |Type |Description |
| --- | --- | --- |
| OWNER            | VARCHAR(64)  | Username of the partition table |
| TABLE_NAME       | VARCHAR(64)  | Table name             |
| TABLESPACE_NAME  | VARCHAR(64)  | Tablespace name        |
| POSITION         | INTEGER      | Tablespace position     |
