This view displays information about all objects that have entered the recycle bin.

|Field |Type |Description |
| --- |-------------| --- |
| OWNER            | VARCHAR(64)   | Username                                              |
| OBJECT_NAME      | VARCHAR(64)   | Name generated by the system after the object is deleted |
| ORIGINAL_NAME    | VARCHAR(64)   | Name of the object before deletion                    |
| OPERATION        | VARCHAR(9)    | Method by which the object entered the recycle bin<br>\*   DROP<br/>*   TRUNCATE |
| TYPE             | VARCHAR(18)   | Number of columns that the Partition key contains     |
| TS_NAME          | VARCHAR(64)   | Tablespace name                                       |
| RECYCLEBIN_TIME  | VARCHAR(19)   | Time the object entered the recycle bin               |
| RECYCLEBIN_SCN   | BIGINT        | SCN when the object entered the recycle bin          |
| PARTITION_NAME    | VARCHAR(64)   | Partition name                                        |
| TRUNCATE_PART    | VARCHAR(3)    | Whether the object entered the recycle bin via alter table truncate partition<br>\*   YES<br/>*   NO |
| RELATED          | BIGINT        | ID of related objects<br>\*   For partition objects: Object ID of the parent object<br>\*   For non-partition objects: Object ID of the root table, such as non-partition index, overall index of partition index |
| BASE_OBJECT      | BIGINT        | Object ID of the table to which this object is attached |
| PURGE_OBJECT     | BIGINT        | Object ID of the dependent object that can be recycled |
| BLOCK_COUNT      | INTEGER       | Number of blocks occupied by the segment of this object |
