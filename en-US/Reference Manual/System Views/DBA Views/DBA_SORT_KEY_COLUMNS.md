This view shows information about all sorting key columns.

|Field |Type |Description |
| --- | --- | --- |
| OWNER        | VARCHAR(64)   | The username of the table owner |
| TABLE_NAME   | VARCHAR(64)   | The table name               |
| COLUMN_NAME  | VARCHAR(64)   | The column name              |
| COLUMN_POSITION | INTEGER    | The position of the column in the sorting key |
