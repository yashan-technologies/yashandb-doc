This view displays the constraint information of columns in all tables.

|Field |Type |Description |
| --- | --- | --- |
| OWNER          | VARCHAR(64) | The user name of the object to which the column belongs |
| CONSTRAINT_NAME| VARCHAR(64) | The name of the constraint to which the column belongs |
| TABLE_NAME     | VARCHAR(64) | The name of the table to which the column belongs |
| COLUMN_NAME    | VARCHAR(64) | Column name                                      |
| POSITION       | INTEGER     | The position of the column in the constraint     |
