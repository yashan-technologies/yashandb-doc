This view displays the parameter information of the YStream server.

|Field |Type |Description |
| --- | --- | --- |
| SERVER_ID    | INTEGER     | Service number |
| SERVER_NAME  | VARCHAR(64) | Service name   |
| PARAM_NAME   | VARCHAR(64) | Parameter name  |
| PARAM_VALUE  | VARCHAR(64) | Parameter value |
| PARAM_DEFAULT| VARCHAR(64) | Default value   |
