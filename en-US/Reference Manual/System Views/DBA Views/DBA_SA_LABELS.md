This view displays information about all labels.

|Field |Type |Description |
| --- | --- |---------------------------------------------------------------------------------------------|
| POLICY_NAME | VARCHAR(64)  | Policy name                                                                                     |
| LABEL       | VARCHAR(4000)| Label content                                                                                    |
| LABEL_TAG   | BIGINT       | Label value                                                                                     |
| LABEL_TYPE  | VARCHAR(15)  | Label type<br>\*   USER LABEL: User label, data with this label has a user sensitivity level<br>\*   USER/DATA LABEL: User/data label, data with this label has a row sensitivity level |
