The PROFILES view displays information related to PROFILE.

|Field |Type |Description |
| --- | --- |-----------|
| PROFILE        | VARCHAR(128)| PROFILE name        |
| RESOURCE_NAME  | VARCHAR(128)| Resource name       |
| RESOURCE_TYPE  | VARCHAR(8)  | Resource type       |
| LIMIT          | VARCHAR(8000)| Resource limit      |
| COMMON | VARCHAR(1) | Whether it is a global profile<br>\* Y<br/>* N |
