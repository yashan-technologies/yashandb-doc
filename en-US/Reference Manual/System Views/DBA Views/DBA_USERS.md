This view displays information about all users in the database.

|Field |Type |Description |
| --- |---------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERNAME                       | VARCHAR(64)     | Username                                                                                                                                                                                                             |
| USER_ID                        | INTEGER         | User ID                                                                                                                                                                                                              |
| PASSWORD                       | VARCHAR(4000)   | Encrypted string                                                                                                                                                                                                    |
| ACCOUNT_STATUS                 | VARCHAR(49)     | User status<br>\* OPEN<br/>* EXPIRED<br/>* EXPIRED(GRACE)<br/>* LOCKED(TIMED)<br/>* LOCKED<br/>* EXPIRED & LOCKED(TIMED)<br/>* EXPIRED(GRACE) & LOCKED(TIMED)<br/>* EXPIRED & LOCKED<br/>* EXPIRED(GRACE) & LOCKED   |
| LOCK_DATE                      | DATE            | If the user status is locked, this indicates the time the user was locked                                                                                                                                           |
| EXPIRY_DATE                    | DATE            | User password expiration time                                                                                                                                                                                                 |
| DEFAULT_TABLESPACE             | VARCHAR(64)     | Default tablespace                                                                                                                                                                                                   |
| CREATED                        | DATE            | User creation time                                                                                                                                                                                                   |
| AUTHENTICATION_TYPE            | VARCHAR(8)      | Indicates the user's authentication mechanism<br>\* PASSWORD<br>\* EXTERNAL<br>\* GLOBAL                                                                                                                             |
| LAST_LOGIN                     | DATE            | User's last login time                                                                                                                                                                                               |
| PASSWORD_CHANGE_DATE           | DATE            | User's last password change time                                                                                                                                                                                     |
| DATABASE_MAINTAINED            | VARCHAR(1)      | Whether it is a built-in user<br>\*   Y: Database built-in user<br>\*   N: User-defined created user    |
| PROFILE                        | VARCHAR(128)    | Profile name corresponding to the user                                                                                                                                                                              |
| TEMPORARY_TABLESPACE           | VARCHAR(64)     | Default temporary tablespace                                                                                                                                                                                          |
| LOCAL_TEMP_TABLESPACE          | VARCHAR(64)     | Default local temporary tablespace                                                                                                                                                                                  |
| DEFAULT_TABLESPACE_SET         | VARCHAR(64)     | Default tablespace set (meaningful only in ISC Distributed Cluster Deployment; in other deployment forms, this value is always NULL)                                                                                           |
| TYPE                           | VARCHAR(7)      | User type                                                                                                                                                                                                            |
| INITIAL_RSRC_CONSUMER_GROUP    | VARCHAR(22)     | User's initial resource group; SYS user belongs to SYS_GROUP, other users belong to DEFAULT_CONSUMER_GROUP                                                                                                          |
| COMMON | VARCHAR(1) | Whether it is a global user<br>\* Y<br/>* N |
