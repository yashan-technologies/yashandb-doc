This view shows the usage information of columns in all triggers.

|Field |Type |Description |
| --- | --- |---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TRIGGER_OWNER   | VARCHAR(64) | The username of the trigger owner.                                                                                                                                                                                         |
| TRIGGER_NAME    | VARCHAR(64) | The name of the trigger.                                                                                                                                                                                                   |
| TABLE_OWNER     | VARCHAR(64) | The username of the owner of the table where the trigger is located.                                                                                                                                                      |
| TABLE_NAME      | VARCHAR(64) | The name of the table where the trigger is located.                                                                                                                                                                        |
| COLUMN_NAME     | VARCHAR(64) | The name of the column of the table used by the trigger.                                                                                                                                                                   |
| COLUMN_LIST     | VARCHAR(3)  | Indicates whether the column is defined in the UPDATE statement (YES) or in the procedure body (NO).                                                                                                                       |
| COLUMN_USAGE    | VARCHAR(17) | The usage scenario of the column in the trigger.<br> * NONE: Not used<br> * OLD IN: Old value as input parameter<br> * NEW IN: New value as input parameter<br> * NEW IN OLD IN: New value as input parameter, old value as input parameter<br> * NEW OUT: New value as output parameter<br> * NEW OUT OLD IN: New value as output parameter, old value as input parameter<br> * NEW IN OUT: New value as input and output parameter<br> * NEW IN OUT OLD IN: New value as input and output parameter, old value as input parameter |
