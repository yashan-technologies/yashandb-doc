This view displays all stored procedure information. 

|Field |Type |Description |
| --- | --- | --- |
| OWNER | VARCHAR(64) | The user to whom the object belongs |
| NAME | VARCHAR(64) | The name of the object |
| TYPE | VARCHAR(17) | The type of the object |
| TEXT | CLOB | The source code of the stored procedure |
| ORIGIN_CON_ID | VARCHAR(1) | Reserved field, value is NULL |
| OBJ# | BIGINT | The object ID |
| VERSION | INTEGER | The version number of the object |
