This view displays the column information of all ACs.

|Field |Type |Description |
| --- |-------------|-------------------------------------------------------------------------------------|
| OWNER          | VARCHAR(64)   | The username of the AC                                                  |
| NAME           | VARCHAR(64)   | The name of the AC                                                      |
| COLUMN_POSITION | INTEGER       | The position of the column                                               |
| COLUMN_NAME    | VARCHAR(64)   | The name of the column                                                  |
| COLUMN_EXPRTEXT | VARCHAR(4000) | The expression of the column                                            |
| COLUMN_ALIAS   | VARCHAR(4000) | The alias of the column                                                 |
