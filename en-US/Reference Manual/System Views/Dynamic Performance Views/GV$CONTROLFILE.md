This view displays the information of all current control files.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID     | NUMBER  | Group ID                  |
| GROUP_NODE_ID| NUMBER  | Node ID within the group  |
| INST_ID      | NUMBER  | Instance ID               |
| ID           | INTEGER | File number               |
| NAME         | VARCHAR(255) | File name (full path)   |
| BLOCK_SIZE   | INTEGER | Block size of the file (in bytes) |
| FILE_SIZE_BLKS| INTEGER | Number of blocks in the file |
| BYTES        | BIGINT  | File size (in bytes)      |
