This view displays whether a transaction exists for all DBLinks.

|Field |Type |Description |
|------------------------|---------|----------------------------------|
| GROUP_ID | NUMBER | Group ID |
| GROUP_NODE_ID | NUMBER | Node ID in Group |
| INST_ID | NUMBER | Instance ID |
| DB_LINK | VARCHAR(64) | Name of the current DBLink |
| IN_TRANSACTION | VARCHAR(3) | Whether a transaction exists for the current DBLink |
