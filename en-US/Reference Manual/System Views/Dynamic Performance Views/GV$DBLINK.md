This view displays all the transaction status of the Database Link.

|Field |Type |Description |
|-------------------|-------------|--|
| GROUP_ID         | NUMBER  | Group ID                                        |
| GROUP_NODE_ID    | NUMBER  | Node ID within the group                        |
| INST_ID          | NUMBER  | Instance ID                                     |
| DB_LINK | VARCHAR(64) | Name of the Database Link |
| IN_TRANSACTION | VARCHAR(3) | The transaction status of the Database Link |
