This view displays information about all completed xfmr tasks that use columnar storage to convert and generate stable data.

|Field |Type |Description |
|------------------|---------------|------------------------------------------------------------------------------------------------------|
| GROUP_ID          | NUMBER        | Group ID                                                                                                    |
| GROUP_NODE_ID     | NUMBER        | Node ID within the group                                                                                    |
| INST_ID           | NUMBER        | Instance ID                                                                                                 |
| ID                | BIGINT        | xfmr task ID                                                                                               |
| OWNER             | VARCHAR(64)   | Username of the xfmr task owner                                                                             |
| TABLESPACE_NAME   | VARCHAR(64)   | Name of the tablespace where the xfmr task belongs                                                         |
| TABLE_NAME        | VARCHAR(64)   | Name of the table where the xfmr task belongs                                                               |
| PARTITION_NAME     | VARCHAR(64)   | Name of the partition where the xfmr task belongs                                                          |
| TYPE              | VARCHAR(16)   | Type of xfmr task, including transform, compact, etc.                                                      |
| FORCE             | VARCHAR(16)   | Whether the xfmr task is executed forcibly                                                                   |
| STATUS            | VARCHAR(16)   | Status of the xfmr task:<br/> * finished: has completed execution                                           |
| SLICE_INFO        | VARCHAR(1024) | Slice information corresponding to the xfmr task:<br/> * Transform task corresponds to the IDs and row counts of slices being transformed to generated slices<br/> * Merge task corresponds to the IDs and row counts of all slices being merged to generated slices |
| FILE_ID           | BIGINT        | File ID corresponding to the slice generated by the xfmr task                                              |
| CREATE_TIME       | TIMESTAMP     | Creation time of the xfmr task                                                                             |
| START_TIME        | TIMESTAMP     | Start execution time of the xfmr task                                                                       |
| FINISH_TIME       | TIMESTAMP     | End execution time of the xfmr task                                                                         |
| EXECUTE_COUNT     | INTEGER       | Execution count of the xfmr task                                                                            |
| MAX_MEM_USE       | BIGINT        | Maximum memory usage during the execution of the xfmr task                                                 |
| MAX_MEM_QUOTA     | BIGINT        | Maximum memory quota during the execution of the xfmr task                                                 |
| SWAP_OUT_SIZE     | BIGINT        | Size of bytes swapped out during the current execution of the xfmr task                                     |
| SWAP_IN_SIZE      | BIGINT        | Size of bytes swapped in during the current execution of the xfmr task                                      |
| SWAP_OUT_COUNT    | INTEGER       | Count of swaps out during the current execution of the xfmr task                                            |
| SWAP_IN_COUNT     | INTEGER       | Count of swaps in during the current execution of the xfmr task                                             |
| SWAP_OUT_TIME     | BIGINT        | Time spent on swapping out during the current execution of the xfmr task                                    |
| SWAP_IN_TIME      | BIGINT        | Time spent on swapping in during the current execution of the xfmr task                                     |
