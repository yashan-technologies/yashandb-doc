This view shows the hash distribution of master resources in YAC.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID | NUMBER | Group ID |
| GROUP_NODE_ID | NUMBER | Node ID within the group |
| INST_ID | NUMBER | Instance ID |
| INSTANCE_ID | TINYINT | Node ID |
| HASH_ID | SMALLINT | Hash value |
| VERSION | SMALLINT | Current GRC version number |
