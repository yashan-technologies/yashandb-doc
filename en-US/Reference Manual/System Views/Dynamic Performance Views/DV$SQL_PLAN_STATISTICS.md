This view displays the detailed execution plan information of sub-cursors for all nodes in an ISC distributed cluster. The parameter `statistics_level=all` must be configured to use it.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID             | INTEGER    | Group ID                                                          |
| GROUP_NODE_ID        | INTEGER    | Node ID within the group                                          |
| ADDRESS              | RAW(8)     | SQL Address                                                       |
| HASH_VALUE           | BIGINT     | Hash value of the SQL, computed from the SQL text                |
| SQL_ID               | VARCHAR(13)| Unique identifier for a SQL statement, calculated through hashing/encryption of the SQL text |
| PLAN_HASH_VALUE      | BIGINT     | Equivalent to SQL_ID                                              |
| CHILD_ADDRESS        | RAW(8)     | Child cursor address                                              |
| CHILD_NUMBER         | INTEGER    | Number of child cursors                                           |
| OPERATION_ID         | BIGINT     | Number assigned to each step in the execution plan (reserved field) |
| EXECUTIONS           | BIGINT     | Number of times this cursor has been executed                    |
| LAST_STARTS          | BIGINT     | Number of times this operation has started during the last execution |
| STARTS               | BIGINT     | Number of times this operation has started, accumulated over past executions |
| LAST_OUTPUT_ROWS     | BIGINT     | Number of rows generated by the data source during the last execution |
| OUTPUT_ROWS          | BIGINT     | Number of rows generated by the data source, accumulated over past executions |
| LAST_CR_BUFFER_GETS  | BIGINT     | Number of consistent blocks read from cache during the last execution |
| CR_BUFFER_GETS       | BIGINT     | Number of consistent blocks read from cache, accumulated over past executions |
| LAST_CU_BUFFER_GETS  | BIGINT     | Number of current mode blocks read from cache during the last execution. This retrieves cache for statements such as INSERT, UPDATE, and DELETE |
| CU_BUFFER_GETS       | BIGINT     | Number of current mode blocks read from cache, accumulated over past executions. This retrieves cache for statements such as INSERT, UPDATE, and DELETE |
| LAST_DISK_READS      | BIGINT     | Number of physical disk reads performed during the last execution |
| DISK_READS          | BIGINT     | Number of physical disk reads performed, accumulated over past executions |
| LAST_DISK_WRITES     | BIGINT     | Number of physical disk writes performed during the last execution |
| DISK_WRITES         | BIGINT     | Number of physical disk writes performed, accumulated over past executions |
| LAST_ELAPSED_TIME     | BIGINT     | Elapsed time (in microseconds) corresponding to this operation during the last execution |
| ELAPSED_TIME        | BIGINT     | Elapsed time (in microseconds) corresponding to this operation, accumulated over past executions |
