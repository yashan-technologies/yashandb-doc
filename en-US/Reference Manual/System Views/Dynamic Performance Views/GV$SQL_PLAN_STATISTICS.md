This view shows detailed execution plan information for child cursors, and the parameter statistics_level=all must be configured to use it.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID         | NUMBER  | Group ID                                                                               |
| GROUP_NODE_ID    | NUMBER  | Node ID within the group                                                               |
| INST_ID          | NUMBER  | Instance ID                                                                           |
| ADDRESS          | RAW(8)  | SQL address                                                                           |
| HASH_VALUE       | BIGINT  | Hash value of the SQL, computed from the SQL text                                     |
| SQL_ID           | VARCHAR(13) | A unique ID value that identifies a SQL statement, obtained through hashing/encryption of the SQL text |
| PLAN_HASH_VALUE  | BIGINT  | Equivalent to SQL_ID                                                                   |
| CHILD_ADDRESS     | RAW(8)  | Child cursor address                                                                    |
| CHILD_NUMBER      | INTEGER | Child cursor number                                                                     |
| OPERATION_ID     | BIGINT  | The ID of each step in the execution plan (reserved field)                          |
| EXECUTIONS       | BIGINT  | The number of times this cursor has been executed                                     |
| LAST_STARTS      | BIGINT  | The number of times this operation has started during the last execution               |
| STARTS           | BIGINT  | The accumulated number of times this operation has started in past executions          |
| LAST_OUTPUT_ROWS | BIGINT  | The number of rows generated by the row source during the last execution               |
| OUTPUT_ROWS      | BIGINT  | The number of rows generated by the row source, accumulated in past executions         |
| LAST_CR_BUFFER_GETS | BIGINT | The number of consistent blocks read from cache during the last execution             |
| CR_BUFFER_GETS   | BIGINT  | The accumulated number of consistent blocks read from cache in past executions         |
| LAST_CU_BUFFER_GETS | BIGINT | The number of current mode blocks read from cache during the last execution. For current mode, this retrieves cache for INSERT, UPDATE, and DELETE statements |
| CU_BUFFER_GETS   | BIGINT  | The accumulated number of current mode blocks read from cache in past executions. For current mode, this retrieves cache for INSERT, UPDATE, and DELETE statements |
| LAST_DISK_READS  | BIGINT  | The number of physical disk reads performed by the operation during the last execution   |
| DISK_READS       | BIGINT  | The accumulated number of physical disk reads performed by the operation in past executions |
| LAST_DISK_WRITES | BIGINT  | The number of physical disk writes performed by the operation during the last execution  |
| DISK_WRITES      | BIGINT  | The accumulated number of physical disk writes performed by the operation in past executions |
| LAST_ELAPSED_TIME | BIGINT  | The elapsed time (in milliseconds) corresponding to this operation during the last execution |
| ELAPSED_TIME     | BIGINT  | The accumulated elapsed time (in milliseconds) corresponding to this operation in past executions |
| BLOCK_RECEIVED    | BIGINT  | The number of times the latest pages have been obtained from other nodes in the cluster |
| CR_BLOCK_RECEIVED | BIGINT  | The number of times CR pages have been obtained from other nodes in the cluster      |
| LOCAL_GRANTS      | BIGINT  | The number of times local node authorized page loading in the cluster                |
| REMOTE_GRANTS     | BIGINT  | The number of times other nodes authorized page loading in the cluster               |
| LOCAL_UPGRADES    | BIGINT  | The number of times local node authorized page lock upgrades in the cluster          |
| REMOTE_UPGRADES   | BIGINT  | The number of times other nodes authorized page lock upgrades in the cluster         |
