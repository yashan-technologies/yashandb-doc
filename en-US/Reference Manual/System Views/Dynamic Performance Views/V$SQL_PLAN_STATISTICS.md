The view is retained for compatibility only and contains no actual data.    

|Field |Type |Description |
| --- | --- | --- |
| ADDRESS             | RAW(8)    | SQL address                                                  |
| HASH_VALUE          | BIGINT    | Hash value of the SQL, calculated from the SQL text         |
| SQL_ID              | VARCHAR(13)| Unique ID value that identifies a SQL statement, obtained through hashing/encryption of the SQL text |
| PLAN_HASH_VALUE     | BIGINT    | Equivalent to SQL_ID                                         |
| CHILD_ADDRESS       | RAW(8)    | Child cursor address                                         |
| CHILD_NUMBER        | INTEGER   | Child cursor number                                          |
| OPERATION_ID        | BIGINT    | The number of each step in the execution plan (reserved field) |
| EXECUTIONS          | BIGINT    | The number of times the cursor has been executed            |
| LAST_STARTS         | BIGINT    | The number of times this operation was initiated during the last execution |
| STARTS              | BIGINT    | The cumulative number of times this operation has been initiated in past executions |
| LAST_OUTPUT_ROWS    | BIGINT    | The number of rows generated by the row source during the last execution |
| OUTPUT_ROWS         | BIGINT    | The cumulative number of rows generated by the row source in past executions |
| LAST_CR_BUFFER_GETS | BIGINT    | The number of consistent blocks read from cache during the last execution |
| CR_BUFFER_GETS      | BIGINT    | The cumulative number of consistent blocks read from cache in past executions |
| LAST_CU_BUFFER_GETS | BIGINT    | The number of current mode blocks read from cache during the last execution. In current mode for statements like INSERT, UPDATE, and DELETE, retrieve from cache |
| CU_BUFFER_GETS      | BIGINT    | The cumulative number of current mode blocks read from cache in past executions. In current mode for statements like INSERT, UPDATE, and DELETE, retrieve from cache |
| LAST_DISK_READS    | BIGINT    | The physical disk read count for operation execution during the last execution |
| DISK_READS          | BIGINT    | The cumulative physical disk read count for operation execution in past executions |
| LAST_DISK_WRITES    | BIGINT    | The physical disk write count for operation execution during the last execution |
| DISK_WRITES         | BIGINT    | The cumulative physical disk write count for operation execution in past executions |
| LAST_ELAPSED_TIME   | BIGINT    | The elapsed time (in microseconds) corresponding to this operation during the last execution |
| ELAPSED_TIME        | BIGINT    | The cumulative elapsed time (in microseconds) corresponding to this operation in past executions |
| BLOCK_RECEIVED      | BIGINT    | The number of latest pages retrieved from other nodes in the cluster |
| CR_BLOCK_RECEIVED   | BIGINT    | The number of CR pages retrieved from other nodes in the cluster |
| LOCAL_GRANTS        | BIGINT    | The number of pages authorized for loading by this node in the cluster |
| REMOTE_GRANTS       | BIGINT    | The number of pages authorized for loading by other nodes in the cluster |
| LOCAL_UPGRADES      | BIGINT    | The number of page lock upgrades authorized by this node in the cluster |
| REMOTE_UPGRADES     | BIGINT    | The number of page lock upgrades authorized by other nodes in the cluster |
