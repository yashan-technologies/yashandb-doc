This view displays the SPA memory information used by all current sessions.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID      | NUMBER    | Group ID                   |
| GROUP_NODE_ID | NUMBER    | Node ID within the group   |
| INST_ID       | NUMBER    | Instance ID                |
| SID           | SMALLINT  | Session ID                 |
| TYPE          | VARCHAR(32) | Memory type               |
| USE_SIZE      | BIGINT    | Memory usage size (in bytes) |
