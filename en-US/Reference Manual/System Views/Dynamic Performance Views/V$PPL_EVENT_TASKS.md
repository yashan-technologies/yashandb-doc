Task view for pipeline parallel execution, which displays the execution status of each task in the current pipeline.

|Field |Type |Description |
| --- | --- | --- |
  SID | SMALLINT | Session ID | 
| GLOBAL_SESSION_ID | INTEGER | Global session ID |
| SQL_ID  | VARCHAR(13) | ID that uniquely identifies an SQL statement. The value is generated by hashing or encrypting the SQL text |
| HASH_VALUE | BIGINT |  Unique identifier for an execution plan  |
| PPL_ID |  SMALLINT  | Pipeline identifier within an execution plan under the pipeline parallel execution model  |
| EVENT_ID | SMALLINT | Event ID of the pipeline |
| EVENT_TYPE | SMALLINT | Type of the event: <br/>* 0: VEC_EVENT_PPL_INIT, init event  <br/>* 1: VEC_EVENT_PPL_PUSH, push event  <br/>* 2: VEC_EVENT_PPL_ONFINISH, onfinish event  <br/>* 3: VEC_EVENT_PPL_FINISH, finish event  <br/>* 4: VEC_EVENT_PPL_COMPLETE, complete event  <br/>* 5: VEC_EVENT_HJ_REPARTITION, repartition event  <br/>* 6: VEC_EVENT_HJ_TABLE_BUILD, hash table build event  <br/>* 7: VEC_EVENT_HJ_RUNTIME, runtime filter build event  <br/>* 8: VEC_EVENT_SORT_MERGE, sort merge event  <br/>* 9: VEC_EVENT_WINDOW_PART_MERGE, window part merge event  <br/>* 10：VEC_EVENT_INSERT, insert event |
| EVENT_CREATE | TIMESTAMP(6) | Creation time of the event  |
| EVENT_FINISH | TIMESTAMP(6) | Completion time of the event |
| EVENT_ISRESCHEDULE | SMALLINT | Whether the event is rescheduled |
| TASK_ID | SMALLINT | Task ID |
| TASK_STATUS | INTEGER | Current status of the task: <br/>* 0: TASK_STATUS_INIT, task initialized <br/>* 1: TASK_STATUS_SCHEDULED, task scheduled <br/>* 2: TASK_STATUS_DESCHEDULED, task descheduled <br/>* 3: TASK_STATUS_READY, task ready to execute<br/>* 4: TASK_STATUS_RUNNING, task running <br/>* 5: TASK_STATUS_IDLE, task idle <br/>* 6: TASK_STATUS_BLOCKED, task blocked <br/>* 7: TASK_STATUS_FINISHED, task finished <br/>* 8: TASK_STATUS_ERROR, task execution error <br/>* 9: TASK_STATUS_DESTROYED, task destroyed |
| SCH_COUNT | INTEGER | Number of times the current task has been scheduled |
| DESCH_COUNT | INTEGER | Number of times the task has been descheduled  |
| LAST_BLOCK_POS | VARCHAR(50) | Last blocked position of the current task, in the format: <br/>NOBLOCK<br/>MSTBUILD<br/>PXSINK<br/>PXCOMBINE<br/>PXSOURCE<br/>HJSOURCE<br/>WINSOURCE<br/>HJNASYNC  |
| TASK_CREATE | TIMESTAMP(6) | Creation time of the task |
| TASK_FINISH | TIMESTAMP(6) | Completion time of the task |
 |
