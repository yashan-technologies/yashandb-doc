This view shows the SPA memory information for all node sessions in the distributed cluster.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID    | INTEGER    | Group ID                 |
| GROUP_NODE_ID | INTEGER  | Node ID within the group  |
| SID         | SMALLINT   | Session ID               |
| TYPE        | VARCHAR(32)| Memory type              |
| USE_SIZE    | BIGINT     | Memory usage size (units: bytes) |
