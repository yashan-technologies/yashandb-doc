This view displays the CLUSTER INFO information stored in the CM module.

|Field |Type |Description |
| --- | --- | --- |
| ID | VARCHAR(64) | Cluster ID |
| NAME | VARCHAR(64) | Cluster Name |
| VERSION | INTEGER | Cluster static information version number |
| NEXT\_GROUP\_ID | INTEGER | ID of the next group in the cluster |
| CREATE\_TIME | TIMESTAMP(6) | Cluster creation time |
| LAST\_UPDATE\_TIME | TIMESTAMP(6) | Last update time of cluster information |
| MAX\_ENDPOINT | SMALLINT | Maximum value of endpoints in the cluster |
