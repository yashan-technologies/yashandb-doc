This view displays detailed information about all error codes.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID     | NUMBER  | Group ID          |
| GROUP_NODE_ID| NUMBER  | Node ID within group |
| INST_ID      | NUMBER  | Instance ID       |
| NUM          | INTEGER | Error Number      |
| NAME         | VARCHAR(255) | Error Name    |
| MESSAGE      | VARCHAR(1024) | Error Message |
