This view displays the definition information of all fixed views. 

|Field |Type |Description |
| --- |---------------| --- |
| GROUP_ID      | NUMBER          | Group ID     |
| GROUP_NODE_ID | NUMBER          | Node ID within the group |
| INST_ID       | NUMBER          | Instance ID  |
| VIEW_NAME     | VARCHAR(64)     | View name    |
| VIEW_DEFINITION| VARCHAR(4000)   | View definition |
