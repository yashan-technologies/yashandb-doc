This view shows the global memory information of all nodes in the ISC distributed cluster.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID       | INTEGER  | Group ID                     |
| GROUP_NODE_ID  | INTEGER  | Node ID within the group     |
| NAME           | VARCHAR(32) | Memory item name            |
| SIZE           | BIGINT   | Memory size (unit: bytes)    |
