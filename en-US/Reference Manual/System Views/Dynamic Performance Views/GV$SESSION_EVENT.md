This view displays all current waiting event statistics. The definitions and explanations of specific waiting events can be found in the [Waiting Events](../../Wait Events) documentation.

|Field |Type |Description |
|-------------------------|-------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUP_ID                | NUMBER       | Group ID                                                                                                                                                                             |
| GROUP_NODE_ID           | NUMBER       | Node ID within the group                                                                                                                                                             |
| INST_ID                 | NUMBER       | Instance ID                                                                                                                                                                          |
| SID                     | SMALLINT     | Session ID                                                                                                                                                                          |
| GLOBAL_SESSION_ID       | INTEGER      | Global Session ID                                                                                                                                                                   |
| EVENT                   | VARCHAR(32)  | Waiting event name                                                                                                                                                                   |
| TOTAL_WAITS             | BIGINT       | Total number of waits                                                                                                                                                                |
| TOTAL_TIMEOUTS          | BIGINT       | Total number of timeouts                                                                                                                                                             |
| TIME_WAITED             | BIGINT       | Wait time (in milliseconds)                                                                                                                                                          |
| AVERAGE_WAIT            | NUMBER       | Average wait time (in milliseconds)                                                                                                                                                 |
| TIME_WAITED_MICRO       | BIGINT       | Wait time (in microseconds)                                                                                                                                                          |
| TOTAL_WAITS_FG         | BIGINT       | Total number of foreground waits                                                                                                                                                     |
| TOTAL_TIMEOUTS_FG      | BIGINT       | Total number of foreground timeouts                                                                                                                                                  |
| TIME_WAITED_FG          | BIGINT       | Foreground wait time (in milliseconds)                                                                                                                                              |
| AVERAGE_WAIT_FG         | NUMBER       | Average foreground wait time (in milliseconds)                                                                                                                                      |
| TIME_WAITED_MICRO_FG    | BIGINT       | Foreground wait time (in microseconds)                                                                                                                                              |
| EVENT_ID                | INTEGER      | Waiting event ID                                                                                                                                                                     |
| WAIT_CLASS              | VARCHAR(16)  | Waiting event category<br>\*   APPLICATION: Waits generated by the application, such as row locks caused by different application layer transactions.<br>\*   CONCURRENCY: Waits generated by database internal resources, such as latch contention waits.<br>\*   COMMIT: Waits caused by redo log synchronization during transaction commits.<br>\*   USER I/O: I/O generated by user threads, such as I/O waits caused by reading data blocks.<br>\*   SYSTEM I/O: Waits caused by database background thread I/O, for example, I/O waits due to the Database Writer thread synchronizing dirty blocks to disk.<br>\*   OTHER: Other types of waits.<br>\*   IDLE: Database waiting for client messages; such waits indicate that the session is in an idle state.<br>\*   NETWORK: Waits caused by network transmission, such as waits occurring during data transmission over the network.<br>\*   CONFIGURATION: Waits caused by database instance configuration, such as waits during configuration of redo size, undo size, or DATA BUFFER size.<br>\*   CLUSTER: Cluster wait events, such as waits for response during cross-node interactions.<br>\*   DISTRIBUTED: Distributed wait events, such as waits for responses from various nodes. |
