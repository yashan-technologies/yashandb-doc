This view displays the memory usage information of objects in the dictionary cache.

|Field |Type |Description |
|----------------------|-------------|-----------------|
| GROUP_ID             | NUMBER      | Group ID             |
| GROUP_NODE_ID        | NUMBER      | Node ID within the group          |
| INST\_ID             | NUMBER      | Instance ID            |
| TYPE                 | VARCHAR(32) | Object type             |
| ID                   | BIGINT      | Object ID          |
| SIZE                 | BIGINT      | Memory size of the object in dictionary cache |
