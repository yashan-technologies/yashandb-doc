This view shows archived file statistics.

|Field |Type |Description |
|------------------|--------------| --- |
| GROUP_ID          | NUMBER        | Group ID     |
| GROUP_NODE_ID     | NUMBER        | Node ID within the group |
| INST_ID           | NUMBER        | Instance ID  |
| NAME              | VARCHAR(255)  | Archived file path |
| SEQUENCE#         | INTEGER       | Archive file sequence number |
| THREAD#           | TINYINT       | Instance number |
| RESETLOGS_ID      | INTEGER       | Archive file reset ID |
| FIRST_CHANGE#     | BIGINT        | SCN of the first log within the archive file |
| FIRST_TIME        | TIMESTAMP(6)     | Time corresponding to the SCN of the first log within the archive file |
| NEXT_CHANGE#      | BIGINT        | SCN of the last log within the archive file |
| NEXT_TIME         | TIMESTAMP(6)     | Time corresponding to the SCN of the last log within the archive file |
| BLOCKS            | BIGINT        | Number of pages in the archive file |
| BLOCK_SIZE        | INTEGER       | Page size of the archive file (unit: bytes) |
| COMPLETION_TIME   | DATE          | Generation time of the archive file |
| COMPRESSED        | VARCHAR(8)    | Whether it is a compressed file |
| FAL               | VARCHAR(8)    | Whether the Archive log files are generated by the FAL thread |
| REGISTRAR         | VARCHAR(8)    | Method of registration <br>\* MANUAL: Manual registration<br>\* ARCH: Registered by archive thread |
| STATUS            | VARCHAR(3)    | Status of the archive <br>\* A: Available |
| ARCHIVED          | VARCHAR(3)    | Whether online redo has been archived <br>\* YES: Archived<br>\* NO: Not archived |
| DELETED           | VARCHAR(3)    | Whether the archive file has been deleted <br>\* YES: File deleted<br>\* NO: File not deleted |
| BACKUP_COUNT      | TINYINT       | Number of backups for the archive file, starting from 0 and accumulating the backup count, maximum value is 15 |
