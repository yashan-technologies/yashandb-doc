This view shows storage-related statistics of the LSC table on all master nodes in a distributed cluster. When there are partitions, it divides and displays the information for each slice by partition (excluding AC slices).

|Field |Type |Description |
|------------------|----------|----------------------------------------------------------------|
| GROUP_ID        | INTEGER   | Group ID                                                         |
| GROUP_NODE_ID  | INTEGER   | Node ID within the group                                          |
| BO               | BIGINT    | LSC parent table ID                                              |
| OBJ              | BIGINT    | LSC child table ID (partition ID)                               |
| DATAOBJ          | BIGINT    | LSC child table data object ID                                   |
| SLICE_ID        | BIGINT    | Slice logical ID                                                |
| STATUS           | INTEGER   | Slice status, 0: invalid, 1: active, 2: full, 3: stale, 4: free, 5: stable |
| SORTED           | BOOLEAN   | Whether sorted                                                   |
| COMPACTED        | BOOLEAN   | Whether compacted                                                |
| SCN              | BIGINT    | SCN when active slice became full, SCN generated by stable slice |
| SPACE_ID        | INTEGER   | Tablespace to which the slice belongs                            |
| BUCKET_ID       | INTEGER   | Data bucket to which the slice belongs; NULL for non-stable slices |
| SLICE_FILE_ID  | BIGINT    | Unique ID of the slice; NULL for non-stable slices              |
| FILE_SIZE       | BIGINT    | Size of the slice file (including data file and metadata file); NULL for non-stable slices |
| DATA_SIZE       | BIGINT    | Final data size of the slice after encoding and compression (excluding metadata size); NULL for non-stable slices |
| ORIGINAL_SIZE   | BIGINT    | Original write data size corresponding to the slice; NULL for non-stable slices |
| ROW_COUNT       | BIGINT    | Number of rows stored in the slice; NULL for non-stable slices   |
| ROW_GROUP_NUM  | BIGINT    | Number of rowgroups in the slice; NULL for non-stable slices     |
