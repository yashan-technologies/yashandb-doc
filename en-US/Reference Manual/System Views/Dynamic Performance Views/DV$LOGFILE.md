This view displays the redo file information for all nodes in an ISC distributed cluster.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID       | INTEGER   | Group ID                                                                                              |
| GROUP_NODE_ID  | INTEGER   | Node ID within the group                                                                              |
| THREAD#        | TINYINT   | Instance number                                                                                       |
| ID             | INTEGER   | Redo file ID                                                                                         |
| NAME           | VARCHAR(255) | Redo file path                                                                                       |
| BLOCK_SIZE     | INTEGER   | Page size of the redo file (unit: bytes)                                                             |
| BLOCK_COUNT    | BIGINT    | Total number of pages in the redo file                                                                |
| USED_BLOCKS    | BIGINT    | Number of pages used in the redo file                                                                 |
| SEQUENCE#      | INTEGER   | Sequence number of the redo file, which is incremented                                                |
| STATUS         | VARCHAR(8) | Status of the redo file<br>\*   NEW: A newly created redo file that has not been used<br>\*   INACTIVE: In this state, the pages corresponding to the redo in the redo file have all been written to disk. The redo file in this state can be reused<br>\*   ACTIVE: In this state, the redo file contains pages corresponding to the redo that have not been written to disk, or the redo has not been archived. Therefore, files in this state cannot be reused<br>\*   CURRENT: The redo file currently in use |
| TYPE           | VARCHAR(8) | Type of the redo file<br>\*   ONLINE: Indicates an ONLINE file used to store redos generated by the primary database<br>\*   STANDBY: Indicates a STANDBY file used to store redos generated by the logical standby database |
