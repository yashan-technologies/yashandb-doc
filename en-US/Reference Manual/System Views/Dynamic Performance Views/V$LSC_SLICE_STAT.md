In Standalone Deployment, this view displays the storage-related statistics of all LSC tables. When partitions exist, the information for each slice is divided and presented according to the partition (excluding AC slice).

In ISC Distributed Cluster Deployment, this view displays the storage-related statistics of all LSC tables in the current instance, except for CN. When partitions exist, the information for each slice is divided and presented according to the partition. On CN, this view displays the storage-related statistics of all LSC tables in the MN instance.

|Field |Type |Description |
|------------------|----------|----------------------------------------------------------------|
| BO               | BIGINT    | Parent table ID                                              |
| OBJ              | BIGINT    | This table ID (partition ID)                                  |
| DATAOBJ          | BIGINT    | Data object ID of this table                                  |
| SLICE\_ID        | BIGINT    | Slice logical ID                                             |
| STATUS           | INTEGER   | Slice status: 0: invalid, 1: active, 2: full, 3: stale, 4: free, 5: stable |
| SORTED           | BOOLEAN   | Whether sorted                                              |
| COMPACTED        | BOOLEAN   | Whether compacted                                           |
| SCN              | BIGINT    | SCN when active slice becomes full, SCN generated by stable slice |
| SPACE\_ID        | INTEGER   | Table space to which the slice belongs                      |
| BUCKET\_ID       | INTEGER   | Data bucket to which the slice belongs, NULL for non-stable slices |
| SLICE\_FILE\_ID  | BIGINT    | Unique ID of the slice, NULL for non-stable slices          |
| FILE\_SIZE       | BIGINT    | Size of the slice file (including data file and metadata file), NULL for non-stable slices |
| DATA\_SIZE       | BIGINT    | Final data size after encoding and compression (excluding metadata size), NULL for non-stable slices |
| ORIGINAL\_SIZE   | BIGINT    | Original data size written to the slice, NULL for non-stable slices |
| ROW\_COUNT       | BIGINT    | Number of rows stored in the slice, NULL for non-stable slices |
| ROW\_GROUP\_NUM  | BIGINT    | Number of row groups in the slice, NULL for non-stable slices |
