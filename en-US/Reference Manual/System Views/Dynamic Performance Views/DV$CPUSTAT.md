This view displays summary information on CPU resource management for all nodes in an ISC distributed cluster.

|Field |Type |Description |
|----------------| --- | --- |
| GROUP\_ID        | INTEGER  | Group ID         |
| GROUP\_NODE\_ID  | INTEGER  | Node ID in Group  |
| RESNAME          | VARCHAR(256) | Resource Group   |
| USER             | VARCHAR(256) | User Mode       |
| SYSTEM           | VARCHAR(256) | System Mode     |
| NR\_PERIODS      | VARCHAR(256) | Period          |
| NR\_THROTTLED    | VARCHAR(256) | Throttle Count   |
| THROTTLED\_TIME  | VARCHAR(256) | Throttle Time    |
