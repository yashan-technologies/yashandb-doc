This view displays all archived file statistics of nodes in a distributed cluster.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID        | INTEGER   | Group ID                                         |
| GROUP_NODE_ID   | INTEGER   | Node ID within the group                         |
| NAME             | VARCHAR(255) | Path of the archived file                       |
| SEQUENCE#       | INTEGER   | Archive file sequence number                     |
| THREAD#         | TINYINT   | Instance number                                  |
| RESETLOGS_ID    | INTEGER   | Archive file reset ID                           |
| FIRST_CHANGE#   | BIGINT    | SCN of the first log in the archive file        |
| FIRST_TIME      | TIMESTAMP | Time corresponding to the SCN of the first log  |
| NEXT_CHANGE#    | BIGINT    | SCN of the last log in the archive file         |
| NEXT_TIME       | TIMESTAMP | Time corresponding to the SCN of the last log   |
| BLOCKS          | BIGINT    | Number of pages in the archive file              |
| BLOCK_SIZE      | INTEGER   | Page size of the archive file (in bytes)        |
| COMPLETION_TIME | DATE      | Generation time of the archive file              |
| COMPRESSED      | VARCHAR(8) | Whether it is a compressed file                  |
| FAL             | VARCHAR(8) | Whether the archive log files are generated by the FAL thread |
| REGISTRAR       | VARCHAR(8) | Method of archiving registration.<br>\* MANUAL: Manual registration<br>\* ARCH: Registered by archive thread |
| BACKUP_COUNT    | TINYINT   | Number of backups for the archived file, initial value is 0, incremented based on the backup count of this archived file, maximum value is 15 |
