This view displays detailed statistics for the most recent instance recovery task.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID       | NUMBER   | Group ID |
| GROUP_NODE_ID  | NUMBER   | Node ID within the group |
| INST_ID        | NUMBER   | Instance ID |
|  ITEM           | VARCHAR(32) | Name of the statistic item |
| UNITS          | VARCHAR(16) | Unit of the statistic item |
| VALUE          | BIGINT   | Value of the statistic item |



Statistic item information:

|Statistic Item |Unit |Description |
| --- | --- | --- |
| Grc Remater Time                 | Millisecond   |  Time consumed by GRC resource redistribution |
| Grc Recover Time                 | Millisecond   |  Time consumed by GRC resource recovery |
| Reform Init Time                 | Millisecond   |  Time consumed by Reform initialization |
| Redo Analyze Time                | Millisecond   |  Time consumed by Redo analysis |
| Recovery Set Blocks              | Number        |  Number of blocks in the recovery set |
| Replay Blocks                    | Number        |  Number of blocks to replay |
| Current Blocks                   | Number        |  Number of blocks with the latest version in the recovery set |
| Lock Recovery Set Reads          | Number        |  Number of reads generated by analyzing the recovery set |
| Lock Recovery Set Read Time      | Millisecond   |  Time consumed by reading during recovery set analysis |
| Lock Recovery Set Writes         | Number        |  Number of writes generated by analyzing the recovery set |
| Lock Recovery Set Write Time     | Millisecond   |  Time consumed by writing during recovery set analysis |
| Reform Prepare Time              | Millisecond   |  Time consumed by Reform prepare phase |
| Alloc Ctrls                      | Number        |  Number of ctrls allocated from bufferPool |
| Alloc Ctrl Time                  | Millisecond   |  Time consumed by allocating ctrls from bufferPool |
| Lock Recovery Set Time           | Millisecond   |  Time consumed by recovery set analysis |
| Lock Recovery Set Threads        | Threads       |  Number of parallel threads for recovery set analysis |
| Physical Recover Reads           | Number        |  Number of reads during physical recovery |
| Physical Recover Read Time       | Millisecond   |  Time consumed by reading during physical recovery |
| Physical Recover Writes          | Number        |  Number of writes during physical recovery |
| Physical Recover Write Time      | Millisecond   |  Time consumed by writing during physical recovery |
| Physical Recover Time            | Millisecond   |  Time consumed by physical recovery |
| Physical Recover Threads         | Threads       |  Number of parallel threads for physical recovery |
| Physical Recover Write Threads   | Threads       |  Number of parallel threads for dirty page flushing during physical recovery |
| Flush Current Time               | Millisecond   |  Time consumed by flushing latest version blocks |
| Flush Current Threads            | Threads       |  Number of parallel threads for flushing latest versions |
