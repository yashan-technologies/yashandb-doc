This view displays information about the YFS disk FailureGroup.

|Field |Type |Description |
|-------|------|------|
|  ID   | INTEGER     | The ID of the FailureGroup within its associated DiskGroup |
| GLOBAL_ID      | INTEGER     | The global ID of the FailureGroup            |
| NAME           | VARCHAR(32) | The name of the FailureGroup                                  |
| GROUP_NUMBER   | INTEGER     | The ID of the DiskGroup to which the FailureGroup belongs    |
