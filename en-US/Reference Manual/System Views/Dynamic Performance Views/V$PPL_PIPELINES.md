Pipeline parallel view showing pipeline info and dependencies for running SQL.

|Field |Type |Description |
| --- | --- | --- |
  SID | SMALLINT |  Session ID | 
| GLOBAL_SESSION_ID | INTEGER | Global session ID |
| SQL_ID | VARCHAR(13) | ID that uniquely identifies an SQL statement. The value is generated by hashing or encrypting the SQL text |
| HASH_VALUE | BIGINT | Unique identifier for an execution plan  |
| PPL_ID | SMALLINT | Pipeline identifier within an execution plan under the PIPELINE parallel execution model |
| PIPELINE | VARCHAR(4000) | Information about each PIPELINE, including the plan_type and plan_id of each operator. Format: PX RECEIVER(source)(27)queue id(3) -> HASH JOIN RIGHT SEMI(sink)(11) |
| DEP_IDS | VARCHAR(8000) | List of PPL_IDs that the current PIPELINE depends on. Format: 1,2,3 |
