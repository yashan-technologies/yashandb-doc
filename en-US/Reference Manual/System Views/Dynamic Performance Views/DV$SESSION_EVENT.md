This view displays the system event statistics for all nodes in the ISC distributed cluster.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID                  | INTEGER  | Group ID                                                         |
| GROUP_NODE_ID             | INTEGER  | Node ID within the group                                         |
| SID                       | SMALLINT | Session ID                                                      |
| GLOBAL_SESSION_ID         | INTEGER  | Global session ID in a distributed environment                   |
| EVENT                     | VARCHAR(32) | Waiting event name                                             |
| TOTAL_WAITS               | BIGINT   | Total wait times                                                |
| TOTAL_TIMEOUTS            | BIGINT   | Total timeout times                                             |
| TIME_WAITED               | BIGINT   | Wait time (in milliseconds)                                     |
| AVERAGE_WAIT              | NUMBER   | Average wait time (in milliseconds)                             |
| TIME_WAITED_MICRO        | BIGINT   | Wait time (in microseconds)                                     |
| TOTAL_WAITS_FG           | BIGINT   | Total foreground wait times                                      |
| TOTAL_TIMEOUTS_FG        | BIGINT   | Total foreground timeout times                                   |
| TIME_WAITED_FG           | BIGINT   | Foreground wait time (in milliseconds)                          |
| AVERAGE_WAIT_FG          | NUMBER   | Foreground average wait time (in milliseconds)                  |
| TIME_WAITED_MICRO_FG     | BIGINT   | Foreground wait time (in microseconds)                          |
| EVENT_ID                  | INTEGER  | Waiting event ID                                                |
| WAIT_CLASS                | VARCHAR(16) | Waiting event category<br>\*   APPLICATION: Waits caused by applications, such as row lock waits generated by transactions from different application layers.<br>\*   CONCURRENCY: Waits caused by internal database resources, such as latch contention waits.<br>\*   COMMIT: Waits caused by redo log synchronization during transaction commits.<br>\*   USER I/O: I/O generated by user threads, such as I/O waits caused by reading data blocks.<br>\*   SYSTEM I/O: Waits caused by database background thread I/O, such as I/O waits caused by Database Writer threads synchronizing dirty blocks to disk.<br>\*   OTHER: Other types of waits.<br>\*   IDLE: Database waiting for client messages; such waiting events indicate that the session is in an idle state.<br>\*   NETWORK: Waits caused by network transmission, such as waits during data transmission over the network.<br>\*   CONFIGURATION: Waits caused by database instance configuration, such as waits when configuring redo size, undo size, and DATA BUFFER size.<br>\*   CLUSTER: Cluster wait events, such as waiting for responses during inter-node interaction.<br>\*   DISTRIBUTED: Distributed wait events, such as waits for responses from various nodes by CN. |
