This view displays information about all built-in functions provided by the current system. For a detailed list, please refer to the development manual [Built-in Functions](../../../Development Guide/SQL Reference Manual/Built-in Functions/00Built-in Functions).

|Field |Type |Description |
| --- | --- |---------------------------|
| ID  | SMALLINT | The ID of the function               |
| NAME | VARCHAR(64) | The name of the function             |
| ISAGGR | VARCHAR(8) | Whether it is an aggregate function <br>\*Y: Yes<br>\*N: No |
