This view displays the list of GROUP INFO information stored in the CM module.

|Field |Type |Description |
| --- | --- | --- |
| TYPE| VARCHAR(16) | Group type, such as CN, DN, etc. |
| ID | INTEGER | Group ID |
| NAME| VARCHAR(64) | Group name |
| VERSION | INTEGER | Group static information version number |
| NEXT\_NODE\_ID | INTEGER | ID of the next node in the group |
| CREATE\_TIME | TIMESTAMP(6) | Group creation time |
| LAST\_UPDATE\_TIME | TIMESTAMP(6) | Last update time of the group information |
