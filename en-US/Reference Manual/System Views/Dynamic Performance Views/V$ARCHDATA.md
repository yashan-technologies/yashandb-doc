This view displays archived slice file cleaning information, used to view the archived slice file cleaning status and the archiving cleaning LFN information of each instance.

| Field         | Type    | Description               |
|---------------|---------|---------------------------|
| ARCH_INST_ID  | TINYINT | Archiving instance ID     |
| CLEAN_LFN     | BIGINT  | Cleaned log file number   |
| ARCH_MIN_LFN  | BIGINT  | Minimum archived log file number |
