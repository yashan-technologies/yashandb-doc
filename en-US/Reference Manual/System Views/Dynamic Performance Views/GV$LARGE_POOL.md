This view displays the statistics related to large object pools.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID       | NUMBER  | Group ID          |
| GROUP_NODE_ID  | NUMBER  | Node ID within group |
| INST_ID        | NUMBER  | Instance ID       |
| TOTAL_BLOCK    | INTEGER | Total number of data blocks |
| FREE_BLOCKS    | INTEGER | Number of free data blocks |
| HIGH_WATER_MARK| INTEGER | HWM               |
