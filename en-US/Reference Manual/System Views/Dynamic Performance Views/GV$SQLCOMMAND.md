This view displays all information related to SQL commands.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID      | NUMBER  | Group ID            |
| GROUP_NODE_ID | NUMBER  | Node ID within the group |
| INST_ID       | NUMBER  | Instance ID         |
| COMMAND_TYPE   | INTEGER | SQL command type value |
| COMMAND_NAME  | VARCHAR(64) | SQL command name   |
