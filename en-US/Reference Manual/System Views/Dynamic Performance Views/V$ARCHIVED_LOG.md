This view displays the archived file statistics.

|Field |Type |Description |
| --- | --- | --- |
| NAME          | VARCHAR(255) | Archive file path                                      |
| SEQUENCE#     | INTEGER      | Archive file sequence number                           |
| THREAD#       | TINYINT      | Instance number                                        |
| RESETLOGS_ID  | INTEGER      | Archive file reset ID                                  |
| FIRST_CHANGE# | BIGINT       | SCN of the first log in the archive file              |
| FIRST_TIME    | TIMESTAMP(6)    | Time corresponding to the SCN of the first log in the archive file |
| NEXT_CHANGE#  | BIGINT       | SCN of the last log in the archive file               |
| NEXT_TIME     | TIMESTAMP(6)    | Time corresponding to the SCN of the last log in the archive file |
| BLOCKS        | BIGINT       | Number of pages in the archive file                    |
| BLOCK_SIZE    | INTEGER      | Page size of the archive file (unit: bytes)           |
| COMPLETION_TIME | DATE       | Generation time of the archive file                    |
| COMPRESSED     | VARCHAR(8)  | Whether it is a compressed file                        |
| FAL           | VARCHAR(8)   | Whether the archive log files are generated by the FAL thread |
| REGISTRAR     | VARCHAR(8)   | Registration method of archiving<br>\* MANUAL: Manual registration<br>\* ARCH: Archive thread registration |
| STATUS        | VARCHAR(3)   | Status of the archive <br>\* A: Available             |
| ARCHIVED      | VARCHAR(3)   | Whether the online redo has been archived<br>\* YES: Archived<br>\* NO: Not archived |
| DELETED       | VARCHAR(3)   | Whether the archive file has been deleted<br>\* YES: File deleted<br>\* NO: File not deleted |
| BACKUP_COUNT  | TINYINT      | Number of backups for the archive file, initial value is 0, accumulated up to 15 |
