YashanDB provides a series of system views that present users with various static data about the database and real-time dynamic data during operation, specifically including:

*   [Dynamic Performance Views](Dynamic Performance Views/00Dynamic Performance Views): These views display real-time data regarding the database's operation, especially performance-related data. Users can manage and optimize the system by querying these views.
*   [DBA Views](DBA Views/00DBA Views): These views present a global view of the entire database based on its structure definition, including information about all user objects, generally for DBA use.
*   [ALL Views](ALL Views/00ALL Views): This is a type of extended view based on the DBA views, including information about all objects that the user has privilege access to.
*   [USER Views](USER Views): This is a type of extended view based on the DBA views, including information about all objects owned by the user.
*   [NLS Views](NLS Views/00NLS Views): These views display the configuration information corresponding to the entire database, allowing users to manage and optimize the database by querying these views.
