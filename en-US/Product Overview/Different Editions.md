### Edition Description

- Basic Edition: The YashanDB commercial edition aimed at small-scale users, containing all basic core capabilities of YashanDB database. Supports Standalone (Primary-Standby) Deployment, with complete data migration and monitoring operation tools. Suitable for price-sensitive scenarios and applications.

- Standard Edition: The YashanDB commercial edition aimed at small to medium-scale users with moderate pricing. Apart from enterprise-level features such as multi-model data types, multi-tenant and advanced security capabilities, this edition contains all basic core capabilities of YashanDB database. Supports Standalone (Primary-Standby) Deployment, with complete data migration and monitoring operation tools. It can provide basic capabilities to support government or small to medium enterprise business needs.

- Enterprise Edition: The YashanDB commercial edition aimed at large-scale users. This edition contains the complete core capabilities of YashanDB database, supports PB-level massive data storage and large numbers of concurrent users, supports multi-model data types and advanced security capabilities. Supports standalone (primary-standby) deployment, YAC deployment, distributed cluster deployment, and ISC distributed cluster deployment, with complete data migration and monitoring operation tools. It can meet the needs of various enterprise applications.
