### Version Description

- Standard Edition: The YashanDB commercial version aimed at small-scale users, priced reasonably. In addition to enterprise-level functionalities such as multi-model data types and advanced security capabilities, this version includes all basic core capabilities of the YashanDB database. It supports standalone primary/standby deployment, with complete data migration and monitoring operation and maintenance tools, providing the basic capabilities needed for government or small and medium enterprises.

- Enterprise Edition: The YashanDB commercial version aimed at large-scale users, containing the complete core capabilities of the YashanDB database. It supports PB-level massive data storage and a large number of concurrent users, supports multi-model data types and advanced security capabilities, supports standalone (primary/standby) deployment, YAC Deployment, and ISC Distributed Cluster Deployment modes, with complete data migration and monitoring operation and maintenance tools that can support various enterprise applications.
