## Data Types in yashan Mode

YashanDB supports 6 native numeric types, including the native integer types BINARY_TINYINT/BINARY_SMALLINT/BINARY_INTEGER/BINARY_BIGINT, which have encoding methods consistent with CPU-supported numeric types, and the corresponding single-precision floating point INARY_FLOAT and double-precision floating point BINARY_DOUBLE as defined by ANSI/IEEE Std 754-1985 standards.

- Compared to native integer types, the NUMBER type supports a larger numeric range and more significant digits. The NUMBER type uses a variable-length storage for significant digits and typically occupies less storage space when the value is significantly smaller than the boundary of native integer types.

- Compared to native floating-point types, the NUMBER type can support up to 38 significant digits, providing more precision than native floating-point types.

- Arithmetic operations on native types can directly invoke CPU instructions, leading to better performance.

- After installation, the system parameter USE_NATIVE_TYPE is set to TRUE, meaning that the data type handling for TINYINT, SMALLINT, INTEGER, BIGINT, and FLOAT is consistent with native integer types; if the system parameter USE_NATIVE_TYPE is changed to FALSE, then these five numeric types are automatically parsed as Oracle compatible types `NUMBER(p,s)` or NUMERIC_FLOAT for processing, and precision settings are supported.
