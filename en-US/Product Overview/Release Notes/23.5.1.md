## Version Information

**Version Number**: v23.5.1.100

**Release Date**: Nov 1, 2025

## Version Positioning

YashanDB v23.5.1 version is positioned as an architectural release, introducing multi-tenant architecture, enhancing YAC and high availability capabilities, and committed to achieving cost reduction and efficiency improvement for domestic implementation in financial core business systems. It supports product forms such as standalone primary-standby and YAC, accompanied by data migration, monitoring operations, and developer tools to meet the needs of various enterprise applications.

## Feature Updates

YashanDB v23.5.1 version inherits all released features from YashanDB v23.4.4 version, while adding the following key features.

### Storage Engine Enhancements

- [Multi-tenant](../../Product Concepts/Multitenant Architecture/00Multitenant Architecture) Support

  To better utilize hardware resources and achieve business cost reduction and efficiency improvement, as well as respond to customers' business consolidation needs. Starting from v23.5, YashanDB supports kernel-level multi-tenant capabilities, providing CDB/PDB tenant architecture. It implements tenant resource isolation, high availability replication and switching, backup and recovery, PDB/CDB creation, startup, shutdown, and deletion, as well as performan reports and tenant-level view management capabilities. It supports both Oracle and MySQL ecosystem tenant modes, meeting customers' choices in different business scenarios and ecosystem compatibility.

- Performance Improvement

  YashanDB's system views are typically generated by joining multiple system base tables with filtering conditions. This version adds support for creating indexes on the base tables corresponding to system views and dynamic views. During system view queries, the optimizer can optionally select indexes when generating execution plans, thereby reducing intermediate data computation during execution, improving efficiency, and ultimately accelerating system view queries.

### YAC Product Capabilities

- `mysql` Mode Support: Since v23.3, YashanDB's standalone deployment has supported mysql mode compatible with native MySQL database. To meet customer requirements, starting from v23.5, YAC now additionally supports compatibility with native MySQL database mode. The corresponding capabilities and usage limitations remain consistent with existing functions in standalone deployment.

- Object Resource Affinity Support: In previous versions, when accessing data in YAC, coordination with the object resource Master was required before accessing data. If the resource Master and business access were not on the same instance, message interaction would occur. To reduce message interaction network overhead during data access and improve data access efficiency, YAC provides object resource affinity capability in v23.5. Object resource metadata for table and partition objects can be specified to specific database instances through the [object_affinity_clause](../../Development Guide/SQL Reference Manual/SQL Statements/CREATE TABLE.md#objectaffinityclause) in CREATE TABLE:

  - default: Indicates affining object resources to the cluster instance currently executing the CREATE TABLE statement.

  - INSTANCE instance_number: Indicates affining object resources to the specified cluster instance.

  - auto: Automatically distributes object resources to cluster instances using hash algorithm.
