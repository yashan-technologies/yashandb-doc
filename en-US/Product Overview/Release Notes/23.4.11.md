## Version Positioning

YashanDB v23.4.11 enriches new features and continues performance optimization based on v23.4.10, serving as a version available for long-term service support.

## Version Information

**Version Number**: v23.4.11.100

**Release Date**: May 29, 2026

## New Features

YashanDB v23.4.11 inherits all functionalities released in YashanDB v23.4.10 and adds the following key features:

### Performance Optimization

- Transaction optimization:

    - Optimized the lock release mechanism during transaction commit, supporting asynchronous redo flushing. Changes become externally visible and row locks are released once redo is flushed to the global buffer, improving performance in scenarios where multiple transactions concurrently modify the same row.

    - Introduced a concurrent transaction scheduling strategy that can precisely wake queued transactions in order, avoiding unnecessary rereads and lock contention and resolving performance degradation in hot data concurrent update scenarios.
