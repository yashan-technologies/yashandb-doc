## Version Positioning

YashanDB v23.4.9 enriches new features and continues performance optimization based on v23.4.7, serving as a version available for long-term service support.

## Version Information

**Version Number**: v23.4.9.100

**Release Date**: April 22, 2026

## New Features

YashanDB v23.4.9 inherits all functionalities released in YashanDB v23.4.8 and adds the following key features:

### MySQL Compatibility

- YashanDB (mysql mode) supports JSON data type and JSON_CONTAINS, JSON_LENGTH, JSON_ARRAY functions: This release enhances JSON data processing capability in mysql mode by adding support for JSON data type and three JSON functions: JSON_CONTAINS, JSON_LENGTH, and JSON_ARRAY. Users can define JSON-type columns in tables in mysql mode, with a maximum JSON data length of 32M. It supports insertion, query, and index operations on JSON data. JSON_CONTAINS checks if a JSON document contains a specified value, JSON_LENGTH returns the length of a JSON document, and JSON_ARRAY creates a JSON array from a list of values. This provides more flexible data modeling options.

- Index handling for NULL values in YashanDB (mysql mode) aligned with MySQL: Supports creating composite unique indexes using NULL values, which will not trigger unique index conflict errors. This behavior is compatible with MySQL's index handling for NULL values.
