```ebnf+diagram
last_insert_id::= LAST_INSERT_ID "(" [expr] ")" 
```

The LAST_INSERT_ID function is used to retrieve the value of the AUTOINCREMENT column generated by the last INSERT in the current session. The return type is BIGINT UNSIGNED.

If the input parameter expr is added, the LAST_INSERT_ID function returns the value of expr converted to BIGINT UNSIGNED. If the conversion fails, it will return an Invalid number error.

>**Caution**:
>
> BIGINT UNSIGNED is a newly added data type in YashanDB 23.4. Successful execution of this function requires the client (including *yasql*, driver interfaces, etc.) to be above version 23.4 and compatible with version 23.4.

**expr**

[General Expression](../General SQL Syntax/expr), must be a type that can be converted to BIGINT UNSIGNED.

- When the value of expr is a floating-point type, the function will round it to the nearest integer.

- When the value of expr is NULL, the function returns NULL.

- When the value of expr is an empty string, the function returns 0.

- The BLOB and TEXT type are not allowed to calculate with this function.

***Example*** for Standalone Deployment Heap tables

```sql
DROP TABLE IF EXISTS product_export;


CREATE TABLE product_export (id BIGINT PRIMARY KEY auto_increment, name VARCHAR(20));


INSERT INTO product_export (name) VALUES('xiaoming');


SELECT LAST_INSERT_ID() res FROM dual;

                  res 
--------------------- 
                    1


SELECT id,name FROM product_export;

                   id name                                                             
--------------------- ---------------------------------------------------------------- 
                    1 xiaoming                                                        

```
