This view displays information about available character sets.

|Field |Type |Description |
|-----------------------|-------------|-----------------|
| CHARACTER_SET_NAME    | VARCHAR(32) | Name of the character set  |
| DEFAULT_COLLATE_NAME  | VARCHAR(32) | Default collation of the character set |
| DESCRIPTION           | VARCHAR(60) | Description of the character set |
| MAXLEN                | BIGINT(38)  | Maximum bytes required to store one character |
