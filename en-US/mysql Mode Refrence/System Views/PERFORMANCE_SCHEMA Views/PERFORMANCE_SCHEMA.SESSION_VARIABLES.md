This view displays information related to the [system variables](../../../All Manuals/Reference Manual of mysql Mode/系统变量/系统变量参考) for the current session.

|Field |Type |Description |
| --- | --- | --- |
| VARIABLE_NAME  | VARCHAR(64)  | The name of the variable  |
| VARIABLE_VALUE  | VARCHAR(1024)   | The value of the variable  |
