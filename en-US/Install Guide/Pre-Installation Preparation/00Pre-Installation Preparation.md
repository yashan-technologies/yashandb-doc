Preparation before installation includes the following items:

1. [Preparing the Servers](Preparing the Servers): We will provide the requirements and configuration recommendations for YashanDB installation resources, as well as the example server list used in the installation guide. Please prepare the servers and related resources to be installed according to the actual situation.

2. [Preparing the Networks](../../All Manuals/Installation and Upgrade/Installation and Deployment/Pre-Installation Preparation/网络准备): We will provide networking recommendations and IP planning suggestions for each deployment topology, and explain the ports that need to be opened. Please prepare the relevant network environment according to the actual situation.

3. [Preparing Dependencies](../../All Manuals/Installation and Upgrade/Installation and Deployment/Pre-Installation Preparation/依赖项准备): Some functions of YashanDB depend on certain system packages, some of which are already built into the installation package. For system packages that are not built-in, please check the versions or perform installation according to the documentation.

4. [Configuring the installation environment](../../All Manuals/Installation and Upgrade/Installation and Deployment/Pre-Installation Preparation/配置安装环境): Includes recommendations for adjusting some operating system parameters and switches. For development and testing environments, not making these adjustments generally will not affect installation, but for production environments, it is recommended to configure according to the documentation to avoid performance issues or various potential errors during database operation.

5. [Creating users and directories](../../All Manuals/Installation and Upgrade/Installation and Deployment/Pre-Installation Preparation/创建用户和目录): Creating an installation user and software directory for YashanDB software is a mandatory operation. Please refer to the documentation to execute this.

6. [Configuring the storage devices](../../All Manuals/Installation and Upgrade/Installation and Deployment/Pre-Installation Preparation/配置存储设备): For YAC Deployment and Distributed Cluster Deployment, we have proposed specific storage device requirements and provided operational step-by-step guidance for their configuration. Please refer to and execute these instructions.

Please refer to the corresponding documents in the above order and follow the provided examples to prepare for the product installation.

This chapter will provide example guidance for all pre-installation preparation steps once the server resources are ready. The listed IPs, users, folder directories, etc., are provided to create a prerequisite environment for the subsequent product installation. Users should adjust them based on their actual environment.
