YashanDB provides the following supporting tools for users:

- [*yasql*](../../All Manuals/Tools Guide/yasql/00yasql): Client connection management tool
- [*yaspwd*](../../All Manuals/Tools Guide/yaspwd): Password change tool
- [*yasldr*](../../All Manuals/Tools Guide/yasldr/00yasldr): Data import tool
- [*imp*](../../All Manuals/Tools Guide/imp/00imp): Data import tool  (YashanDB /<-> YashanDB only)
- [*exp*](../../All Manuals/Tools Guide/exp/00exp): Data export tool
- [*yasrman*](../../All Manuals/Tools Guide/yasrman/00yasrman): Backup and recovery tool
- [*yasboot*](../../All Manuals/Tools Guide/yasboot/00yasboot): Operation and maintenance management tool
- [*yaswrap*](../../All Manuals/Tools Guide/yaswrap/00yaswrap): PL source code encryption tool
- [*ycsctl*](../../All Manuals/Tools Guide/ycsctl/00ycsctl): YCS management tool
- [*yfscmd*](../../All Manuals/Tools Guide/yfscmd/00yfscmd): YFS management tool
