YashanDB provides the following supporting tools for users:

- [*yasql*](../../All Manuals/工具手册/yasql/00yasql): Client connection management and SQL command line tool
- [*yaspwd*](../../All Manuals/工具手册/yaspwd): Password change tool
- [*yasldr*](../../All Manuals/工具手册/yasldr/00yasldr): Data import tool
- [*imp*](../../All Manuals/工具手册/imp/00imp): Data import tool  (YashanDB /<-> YashanDB only)
- [*exp*](../../All Manuals/工具手册/exp/00exp): Data export tool
- [*yasrman*](../../All Manuals/工具手册/yasrman/00yasrman): Backup and recovery tool
- [*yasboot*](../../All Manuals/工具手册/yasboot/00yasboot): Operation and maintenance management tool
- [*yaswrap*](../../All Manuals/工具手册/yaswrap/00yaswrap): PL source code encryption tool
- [*ycsctl*](../../All Manuals/工具手册/ycsctl/00ycsctl): YCS management tool
- [*yfscmd*](../../All Manuals/工具手册/yfscmd/00yfscmd): YFS management tool
