YashanDB provides the following supporting tools for users:

- [yasql](../../All Manuals/Tools Guide/yasql/00yasql): SQL command line tool
- [yaspwd](../../All Manuals/Tools Guide/yaspwd): Password change tool
- [yasldr](../../All Manuals/Tools Guide/yasldr/00yasldr): SQLLOADER data import tool
- [imp](../../All Manuals/Tools Guide/imp/00imp): Data import tool
- [exp](../../All Manuals/Tools Guide/exp/00exp): Metadata and CSV data export tool
- [yasrman](../../All Manuals/Tools Guide/yasrman/00yasrman): Backup and recovery tool
- [yasbak](../../All Manuals/Tools Guide/yasbak/00yasbak): A tool provided by YashanDB for third parties to connect backup and recovery functionality
- [yasboot](../../All Manuals/Tools Guide/yasboot/00yasboot): Operation and maintenance management tool
- [yaswrap](../../All Manuals/Tools Guide/yaswrap/00yaswrap): PL source code encryption tool
- [ycsctl](../../All Manuals/Tools Guide/ycsctl/00ycsctl): Cluster service management tool
- [yfscmd](../../All Manuals/Tools Guide/yfscmd/00yfscmd): Cluster file system management tool
