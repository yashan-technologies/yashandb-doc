This view shows information about check constraints.

|Field |Type |Description |
| --- | --- | --- |
| CONSTRAINT_CATALOG  | VARCHAR(3)  | The name of the catalog to which the check constraint belongs; this value is always def |
| CONSTRAINT_SCHEMA   | VARCHAR(64) | The name of the schema in which the check constraint is located |
| CONSTRAINT_NAME     | VARCHAR(64) | The name of the check constraint                  |
| CHECK_CLAUSE        | VARCHAR(4000)| The text of the check condition for the check constraint |
