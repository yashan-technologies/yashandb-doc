This view displays user privilege information.

|Field |Type |Description |
|----------------|--------------|---------------------|
| GRANTEE          | VARCHAR(81)   | The name of the account that was granted the privilege           |
| TABLE_CATALOG    | VARCHAR(512)  | The name of the schema's catalog, this value is always def |
| PRIVILEGE_TYPE   | VARCHAR(64)   | The granted privilege                | 
| IS_GRANTABLE     | VARCHAR(3)    | Whether the privilege can be granted   |
