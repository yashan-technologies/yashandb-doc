The object privilege refers to the privilege that allows users to perform specific operations on specific objects. It narrows down the scope of privileges, facilitating the control of object access and ensuring data security.

|Privilege Name |Description |
| --- | --- |
| ALL             | Has all object-level privileges      |
| SELECT          | Query the table using SELECT statement |
| ALTER           | Modify operations on the table       |
| INSERT          | Insert operations on the table       |
| UPDATE          | Update data in the table            |
| DELETE          | Delete data in the table            |
| GRANT           | Grant the owned privileges           |
| INDEX           | Create and delete operations on indexes |
| REFERENCES      | Allows users to create foreign key constraints on the table |
