Geographic Information Processing Functions (GIS Functions) refer to a series of functions that process spatial geographic information. The constraints for using such functions are as follows:

- Except for the ST_DISTANCE_SPHERE function, which is applicable to all deployment forms and all table types, other functions are only applicable to HEAP tables in Standalone/YAC/Distributed Cluster Deployment.

- The YashanDB server must have the GIS plugin installed (this can be confirmed by checking if the gis folder exists in the $YASDB_HOME/third path).
