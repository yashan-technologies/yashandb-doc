|Interface Name |Interface Description |
|--------------------|--------------------------------------|
| [SQLBindCol](SQLBindCol) | Allocates storage for a result column and specifies the data type |
| [SQLColAttribute](SQLColAttribute) | Describes the attributes of columns in the result set |
| [SQLDescribeCol](SQLDescribeCol) | Describes the columns of the result set |
| [SQLFetch](SQLFetch) | Returns multiple result rows |
| [SQLFetchScroll](SQLFetchScroll) | Returns scrollable result rows. |
| [SQLGetData](SQLGetData) | Returns partial or all data for one column of a result set row |
| [SQLGetDiagField](SQLGetDiagField) | Returns additional diagnostics from a single field of the diagnostic data structure |
| [SQLGetDiagRec](SQLGetDiagRec) | Returns diagnostics from the diagnostic data structure (multiple fields) |
| [SQLNumResultCols](SQLNumResultCols) | Returns the number of columns in the result set |
| [SQLRowCount](SQLRowCount) | Returns the number of rows affected by insert, update, or delete requests |
