The YashanDB C driver example includes commonly used functionalities of the C driver:

1. Connect to the database.
2. Disconnect from the database.
3. Import single-row bound data.
4. Retrieve single-row data.
5. Import batch bound data.
6. Retrieve batch data.
7. Import single-row bound LOB data.
8. Retrieve single LOB data.
9. Import batch bound LOB data (using contiguous memory import).
10. Retrieve batch LOB data (using contiguous memory retrieval).
11. LOB interface to read and write LOB data (using LOB2 interface).
12. Retrieve cursor data for a single row.
