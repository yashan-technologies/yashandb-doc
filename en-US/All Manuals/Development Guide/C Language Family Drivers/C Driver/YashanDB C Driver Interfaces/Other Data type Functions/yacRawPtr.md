## Functionality Overview

Retrieve the binary string stored in yacRaw. The return value indicates the storage of the binary string.

## Function Declaration

```c
YacUint8* yacRawPtr(YacHandle hEnv, const YacRaw* yacRaw);
```

## Parameter Description

|Parameter Name |Description |
| -------------- | ---------- |
| hEnv (IN)       | Environment handle. |
| yacRaw (IN)     | Raw handle.         |
