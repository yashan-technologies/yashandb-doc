YashanDB OCI driver client program ociexample.c:

***Example*** includes commonly used functionalities of the OCI driver:

1. Connect to the database.
2. Disconnect from the database.
3. Single-row binding to import data.
4. Single-row data retrieval.
5. Batch binding to import data.
6. Batch data retrieval.
7. Single-row binding for LOB data import.
8. Single-row LOB data retrieval.
