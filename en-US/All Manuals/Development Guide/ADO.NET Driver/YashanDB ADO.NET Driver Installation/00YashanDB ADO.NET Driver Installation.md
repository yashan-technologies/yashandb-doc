This chapter provides instructions for installing the YashanDB ADO.NET driver on Windows and Linux platforms. For specific operations, please refer to:

- [YashanDB ADO.NET Installation Guide for Windows](./ADO.NET驱动安装（Windows）)

- [YashanDB ADO.NET Installation Guide for Linux](./ADO.NET驱动安装（Linux）)

> **Note**:
> 
> Using the YashanDB ADO.NET driver requires the YashanDB C driver library to be installed and configured first. The installation files for the YashanDB C driver are integrated into the YashanDB client installation package, and the corresponding client installation package must be obtained during installation.
