## Cursor Object

This is the database cursor object used to manage operations on specific content in the database, such as executing SQL statements and retrieving execution results.

The object is created through the cursor() method of the Connection.

### Attributes

|Attribute |
| ----------- |
| description |
| rowcount    |
| arraysize   |

### Supported Methods

|Method |
| ------------- |
| close()       |
| execute()     |
| executemany() |
| fetchone()    |
| fetchmany()   |
| fetchall()    |
| var()         |
