Using the [yasrman](../../../Tools Guide/yasrman/00yasrman) tool allows you to initiate database-related backup and recovery from the remote tool side:

- Full database backup and recovery: Applicable to all deployment forms, with the commands/usage being completely consistent for Standalone/YAC/Distributed Cluster Deployment.

- Tablespace backup and recovery: Applicable to Standalone Deployment.

- Archive log files backup and recovery: Applicable to both Standalone/YAC/Distributed Cluster Deployment, with the commands/usage being completely consistent.
