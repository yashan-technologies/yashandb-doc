Using the [yasrman](../../../Tools Guide/yasrman/00yasrman) tool allows you to initiate database-related backup and recovery from the remote tool side:

- Full database backup and recovery: Applicable to all deployment forms, with the commands/usage being completely consistent for Standalone Deployment and YAC Deployment.

- Tablespace backup and recovery: Applicable to Standalone Deployment.

- Archive log files backup and recovery: Applicable to both Standalone Deployment and YAC Deployment, with the commands/usage being completely consistent.
