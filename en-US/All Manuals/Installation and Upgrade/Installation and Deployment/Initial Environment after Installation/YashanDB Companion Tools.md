YashanDB provides the following supporting tools for users:

- [yasql](../../../Tools Guide/yasql/00yasql): SQL command line tool
- [yaspwd](../../../Tools Guide/yaspwd): Password change tool
- [yasldr](../../../Tools Guide/yasldr/00yasldr): SQLLOADER data import tool
- [imp](../../../Tools Guide/imp/00imp): Data import tool
- [exp](../../../Tools Guide/exp/00exp): Metadata and CSV data export tool
- [yasrman](../../../Tools Guide/yasrman/00yasrman): Backup and recovery tool
- [yasbak](../../../Tools Guide/yasbak/00yasbak): A tool provided by YashanDB for third parties to connect backup and recovery functionality
- [yasboot](../../../Tools Guide/yasboot/00yasboot): Operation and maintenance management tool
- [yaswrap](../../../Tools Guide/yaswrap/00yaswrap): PL source code encryption tool
- [ycsctl](../../../Tools Guide/ycsctl/00ycsctl): Cluster service management tool
- [yfscmd](../../../Tools Guide/yfscmd/00yfscmd): Cluster file system management tool
