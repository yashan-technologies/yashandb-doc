YashanDB provides the following supporting tools for users:

- [*yasql*](../../../工具手册/yasql/00yasql): Client connection management and SQL command line tool
- [*yaspwd*](../../../工具手册/yaspwd): Password change tool
- [*yasldr*](../../../工具手册/yasldr/00yasldr): Data import tool
- [*imp*](../../../工具手册/imp/00imp): Data import tool  (YashanDB \<-> YashanDB only)
- [*exp*](../../../工具手册/exp/00exp): Data export tool
- [*yasrman*](../../../工具手册/yasrman/00yasrman): Backup and recovery tool
- [*yasboot*](../../../工具手册/yasboot/00yasboot): Operation and maintenance management tool
- [*yaswrap*](../../../工具手册/yaswrap/00yaswrap): PL source code encryption tool
- [*ycsctl*](../../../工具手册/ycsctl/00ycsctl): YCS management tool
- [*yfscmd*](../../../工具手册/yfscmd/00yfscmd): YFS management tool
