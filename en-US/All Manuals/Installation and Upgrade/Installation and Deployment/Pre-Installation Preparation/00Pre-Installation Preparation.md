Please refer to the corresponding documents in the above order and follow the provided examples to prepare for the product installation. The [Preparing the Servers](Preparing the Servers) document only lists the requirements and configuration recommendations for installation resources by YashanDB, without specific operational examples. These should be prepared by the enterprise's backend management personnel. If you have questions about the information listed in the documents, please contact our technical support.

This chapter will provide example guidance for all pre-installation preparation steps once the server resources are ready. The listed IPs, users, folder directories, etc., are provided to create a prerequisite environment for the subsequent product installation. Users should adjust them based on their actual environment.

Additionally, the initial parameters, environment, and user operations on the server must all be performed as the root user. If the enterprise has a privilege division for the OS, all steps listed above, except for downloading software packages, should be performed by the system administrator. After completion, the installation user, storage directory, and other information should be handed over to the database installation user, who will perform the subsequent operations.
