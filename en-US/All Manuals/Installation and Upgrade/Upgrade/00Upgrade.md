This section provides guidance and examples for the upgrade process of the YashanDB product. Please follow the operation sequence below when upgrading the database:

1. Please complete the pre-upgrade preparations according to [Pre-Upgrade Preparation](Pre-Upgrade Preparation).
2. Please select the appropriate upgrade procedure and complete the operation according to [Upgrade Procedure](Upgrade Procedure/00Upgrade Procedure).
3. (Optional) If there are exceptions during the upgrade process, please roll back the database according to [Upgrade Issues Handling](Upgrade Issues Handling/00Upgrade Issues Handling).
