In ISC Distributed Cluster Deployment, users can expand configurations in an already running environment as needed:

- [CNs Scaling](CNs Scaling): Add/Remove CN nodes to the existing environment.

- [DN Groups Scaling](DN Groups Scaling): Add/Remove DN groups to the existing environment.

- [DN/MN Standby Nodes Scaling within a Group](Standby Nodes Scaling within a Group): Add/Remove standby nodes for DN groups or MN groups in the existing environment. Each operation can only scale the standby nodes of one group at a time.
