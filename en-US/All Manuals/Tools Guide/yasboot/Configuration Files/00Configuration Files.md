The toml configuration file is used to configure the environmental information for setting up YashanDB. YashanDB's operational services provided by *yasboot* are all based on toml files. 



>**Caution**:
>
> The sample content of the configuration files provided in this chapter is mainly used to introduce the composition and meaning of configuration items. To avoid introducing unnecessary errors, it is **not recommended** to directly copy the sample content to manually construct configuration files.



- The [Server Configuration File](Server Configuration File) (hosts.toml) and the cluster configuration file (cluster_name.toml, which may be [Standalone Deployment Configuration File](Standalone Deployment Configuration File), [YAC Deployment Configuration File](YAC Deployment Configuration File), [Distributed Cluster Deployment Configuration File](Distributed Cluster Deployment Configuration File), or [ISC Distributed Cluster Deployment Configuration File](ISC Distributed Cluster Deployment Configuration File) based on the deployment form) are a set of the most basic configuration files required by YashanDB, generated by the command yasboot package config gen.

- The [Server Check Configuration File](Server Check Configuration File) (yascheck.toml) is generated by the command yasboot config host gen for server check configuration (this file is not required if only the default check items are used).

- The [Database Scaling Configuration File](Database Scaling Configuration File) (cluster_name_add.toml) and the [Server Scaling Configuration File](Server Scaling Configuration File) (hosts_add.toml) are the scaling configuration files required by YashanDB, generated by yasboot config node/group gen.

- The [Database Topology File](Database Topology File) (cluster_name_topology.toml) is the database information configuration file required by YASOM, generated by the command yasboot cluster load.
