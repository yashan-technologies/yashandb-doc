The toml configuration file is used to configure the environmental information for setting up YashanDB. YashanDB's operational services provided by *yasboot* are all based on toml files. 

Configuration files are generated by the corresponding yasboot commands and can be mainly classified into the following categories:



>**Caution**:
>
> The sample content of the configuration files provided in this chapter is mainly used to introduce the composition and meaning of configuration items. To avoid introducing unnecessary errors, it is **not recommended** to directly copy the sample content to manually construct configuration files.



|Category     |Description      |Generation Command |File Name         |
| ------------------- | ------------------------ | ---------------- | --------------------- |
| Server Configuration File           | Mainly records information related to the database server, yasom - related information, etc. For an example of the file content, please refer to [Server Configuration File](Server Configuration File). | yasboot package se/ce/de gen    | hosts.toml                                                 |
| Cluster Configuration File          | Mainly records database - related configuration information, logical architecture information of the database cluster, etc. It varies according to different deployment forms. For an example of the file content, please refer to [Standalone Deployment Configuration File](./单机配置文件), [YAC Deployment Configuration File](./共享集群配置文件), [Distributed Cluster Deployment Configuration File](./分布式集群配置文件), or [ISC Distributed Cluster Deployment Configuration File](./存算一体分布式集群配置文件). | yasboot package se/ce/de gen    | {cluster_name}.toml, e.g., yashandb.toml                   |
| Server Scaling Configuration File   | Mainly records information related to the newly added servers for expansion. For an example of the file content, please refer to [Server Scaling Configuration File](./服务器扩容配置文件). | yasboot config node/group gen   | hosts_add.toml                                             |
| Database Scaling Configuration File | Mainly records the relevant configuration information of the newly added nodes/groups for expansion. For an example of the file content, please refer to [Database Scaling Configuration File](./集群扩容配置文件). | yasboot config node/group gen   | {cluster_name}_add.toml, e.g., yashandb_add.toml           |
| Server Check Configuration File     | Mainly records the [check items](../yasboot命令介绍/yasboot collection.html#CheckItems) when checking the database server. For an example of the file content, please refer to [Server Check Configuration File](./服务器检查配置文件). | yasboot config host gen         | yascheck.toml                                              |
| Database Topology File              | Mainly records the logical topology information of the database cluster. For an example of the file content, please refer to [Database Topology File](./数据库拓扑文件). | yasboot cluster load            | {cluster_name}_topology.toml, e.g., yashandb_topology.toml |
| YAC Upgrade Configuration File      | Only used in the scenario where YAC is upgraded from version 23.2.x.x and earlier to version 23.4.x.x and above.<br />Mainly records the disk information planned for the new - version shared cluster. For an example of the file content, please refer to [YAC Upgrade Configuration File](./共享集群升级配置文件). | Manually created                | disk_config.toml                                           |
