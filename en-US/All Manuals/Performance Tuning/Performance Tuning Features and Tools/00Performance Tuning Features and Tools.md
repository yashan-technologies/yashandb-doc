Effective information collection and analysis are crucial for identifying and fixing performance issues. YashanDB offers the following features or tools to help users obtain this information:

- [Statistics](Statistics): Used to collect a series of basic information about the current database. This can provide users with information support to assess current performance bottlenecks and can also serve as a basis for the optimizer to choose the best execution path.
- [Performance Reports](Performance Reports): Used to collect performance-related statistical data and generate easy-to-view reports. Users can analyze performance bottlenecks through the report content and make corresponding adjustments.
- [Performance Views](Performance Views): Presents internal performance data of the database to users through views.
- [Execution Plans](Execution Plans): An important auxiliary tool in the SQL optimization process. The execution plan can determine whether the optimizer has chosen the optimal plan and whether the additional indexes are effective.
- [AUTOTRACE](AUTOTRACE): Can trace performance data at the statement level.

In addition, users can perform database process-level performance analysis using operating system tools such as top, iostat, and netstat.
