The main ports required during the operation of YashanDB database are shown below. The default values for each port are the initial values from the configuration file. You can plan and open ports according to actual network requirements during installation and deployment [plan and open ports](../Installation and Upgrade/Installation and Deployment/Pre-Installation Preparation/Configuring the Pre-Installation Environment).

> **Note**:
>
> - To access the database cluster externally, the database listening port and yasom port must be opened.
> - It is recommended that listening port numbers be less than 30000, and refer to [Tuning OS Parameters](../Installation and Upgrade/Installation and Deployment/Pre-Installation Preparation/Tuning OS Parameters) to set the automatically allocated port range, avoiding conflicts with listening ports.
> - If a visual web service is to be used, the corresponding server's 9001 port must be opened.

## Standalone Deployment

|Port |Port Number |Description |Connection and Authentication |Network Security |
| ---------- | ----------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ----------------------- |
| Database Listening (LISTEN_ADDR) | Default value: 1688<br/>Range: 1024-65535                       | Provides database services to the outside.                 | <ul><li>Remote connection: TCP long connection with AEC+SHA256 password authentication</li><li>UDS local connection: IPC connection based on OS authentication</li></ul> | Supports configuring [Trusted Channel](../Product Security/Encryption/Trusted Channel), default not enabled |
| Communication between primary and standby databases (REPLICATION_ADDR) | Default value: 1689<br/>Range: 1024-65535 | Required for primary/standby deployment, internal communication port for data replication between primary and standby databases, ensuring data consistency. | Internal servers communicate using Trust mode, establishing TCP long connections based on IP address authentication | Supports configuring [Trusted Channel](../Product Security/Encryption/Trusted Channel), default not enabled |
| yasom      | Default value: 1675<br/>Range: 1024-65535                       | Used to receive and respond to *yasboot* commands.          | TCP short connection with AEC+SHA256 password authentication   | Supports configuring [Trusted Channel](../Product Security/Encryption/Trusted Channel), default not enabled |
| yasagent   | Default value: 1676<br/>Range: 1024-65535                       | Internal communication port for receiving and responding to yasom commands. | TCP short connection with AEC+SHA256 password authentication   | Supports configuring [Trusted Channel](../Product Security/Encryption/Trusted Channel), default not enabled |
