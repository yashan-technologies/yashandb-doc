This view describes the comment information related to all tables or views in the database.

|Field |Type |Description |
| --- | --- | --- |
| OWNER       | VARCHAR(64) | The username of the object owner |
| TABLE_NAME  | VARCHAR(64) | The name of the object  |
| TABLE_TYPE  | VARCHAR(5)  | The type of the object<br>*   TABLE<br>*   VIEW |
| COMMENTS    | VARCHAR(4000) | The comment content     |
