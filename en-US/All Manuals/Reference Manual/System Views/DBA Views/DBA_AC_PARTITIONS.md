This view displays the partition information of all partitions of AC.

|Field |Type |Description |
| --- | --- | --- |
| AC_OWNER           | VARCHAR(64) | The username of the AC              |
| AC_NAME            | VARCHAR(64) | The name of the AC to which the partition belongs |
| PARTITION_NAME     | VARCHAR(64) | The name of the AC partition         |
| TABLESPACE_NAME    | VARCHAR(64) | The name of the tablespace where the AC partition is located |
