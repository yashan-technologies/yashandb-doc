This view shows the sorting information for all tables.

|Field |Type |Description |
| --- | --- | --- |
| OWNER         | VARCHAR(64)  | Table owner's username   |
| TABLE_NAME    | VARCHAR(64)  | Table name              |
| SORT_METHOD    | VARCHAR(4)   | Sorting method<br>*   DESC<br>*   ASC<br> |
| NULLS_FIRST   | VARCHAR(1)   | Whether nulls are first  |
| SORT_TYPE     | VARCHAR(11)  | Sorting method<br/>*   SORT_NORMAL<br/>*   SORT_ZSORT<br/>*   SORT_HSORT<br/> |
| SORT_MCOL     | VARCHAR(1)   | Whether sorted           |
