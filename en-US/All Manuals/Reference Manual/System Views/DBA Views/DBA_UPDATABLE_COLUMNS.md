This view displays operational information for all columns.

|Field |Type |Description |
|-----------------------|-------------|--------------------------------------------------------|
| OWNER                 | VARCHAR(64) | The username to which the column belongs               |
| TABLE_NAME            | VARCHAR(64) | The name of the table or view to which the column belongs|
| COLUMN_NAME           | VARCHAR(64) | The name of the column                                  |
| UPDATABLE             | VARCHAR(3)  | Whether the column is updatable                         |
| INSERTABLE            | VARCHAR(3)  | Whether the column is insertable                        |
| DELETABLE             | VARCHAR(3)  | Whether the column is deletable                         |
