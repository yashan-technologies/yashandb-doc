This view shows the comments information for columns.

|Field |Type |Description |
| --- | --- | --- |
| OWNER        | VARCHAR(64) | Username of the object to which the column belongs |
| TABLE_NAME   | VARCHAR(64) | Name of the object to which the column belongs     |
| COLUMN_NAME  | VARCHAR(64) | Column name                         |
| COMMENTS     | VARCHAR(4000)| Comments content                   |
