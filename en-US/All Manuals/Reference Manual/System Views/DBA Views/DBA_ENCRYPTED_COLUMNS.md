This view shows the encryption information of the columns.

|Field |Type |Description |
| --- | --- | --- |
| OWNER        | VARCHAR(64) | The username of the object owner     |
| TABLE_NAME   | VARCHAR(64) | The name of the object               |
| COLUMN_NAME  | VARCHAR(64) | The name of the column               |
| ENC_ALG      | VARCHAR(6)  | The column encryption algorithm       |
| ENC_KEYVER   | INTEGER     | The version of the column encryption key |
