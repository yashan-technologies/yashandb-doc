This view displays all additional log information.

|Field |Type |Description |
| --- | --- | --- |
| OWNER           | VARCHAR(64)  | The username of the additional log   |
| LOG_GROUP_NAME  | VARCHAR(64)  | The name of the corresponding constraint for the additional log |
| TABLE_NAME      | VARCHAR(64)  | The name of the table the additional log belongs to |
| LOG_GROUP_TYPE  | VARCHAR(11)  | The type of the additional log       |
| INDEX_NAME      | VARCHAR(64)  | The name of the index corresponding to the additional log |
