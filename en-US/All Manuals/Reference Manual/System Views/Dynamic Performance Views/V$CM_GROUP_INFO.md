This view displays the list of GROUP INFO information stored in the CM module.

|Field |Type |Description |
| --- | --- | --- |
| TYPE| VARCHAR(16) | Group type, such as CN, DN, etc. |
| ID | INTEGER | Group ID |
| NAME| VARCHAR(64) | Group name |
| VERSION | INTEGER | Group static information version number |
| NEXT_NODE_ID | INTEGER | ID of the next node in the group |
| CREATE_TIME | TIMESTAMP(6) | Group creation time |
| LAST_UPDATE_TIME | TIMESTAMP(6) | Last update time of the group information |
