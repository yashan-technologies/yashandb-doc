This view displays information about the BASE section of the current node's MEX memory pool.

|Field |Type |Description |
|-----------------------|--------|----------------|
| HOLD_SIZE            | BIGINT | Held memory (in bytes)          |
| USING_SIZE           | BIGINT | Memory in use (in bytes)        |
| UNUSED_SIZE          | BIGINT | Unused memory (in bytes)        |
| FILL_TIMES           | BIGINT | Number of fills (buffer misses)  |
| MAX_CONTINUOUS_SIZE | BIGINT | Maximum contiguous memory (in bytes) |
