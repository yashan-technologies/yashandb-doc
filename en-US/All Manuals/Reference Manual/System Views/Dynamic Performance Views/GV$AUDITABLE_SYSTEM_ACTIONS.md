This view displays the audit item information for all system behaviors.

|Field |Type |Description |
|---------------| --- | --- |
| GROUP_ID       | NUMBER  | Group ID          |
| GROUP_NODE_ID  | NUMBER  | Node ID within group |
| INST_ID        | NUMBER  | Instance ID       |
| COMMAND_TYPE  | INTEGER | SQL Type ID       |
| COMMAND_NAME  | VARCHAR(64) | SQL Type Name   |
