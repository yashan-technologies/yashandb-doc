This view displays all the dynamic view names provided by the current system.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID     | NUMBER  | Group ID            |
| GROUP_NODE_ID| NUMBER  | Node ID within group |
| INST_ID      | NUMBER  | Instance ID         |
| ID           | INTEGER | Dynamic view serial number |
| NAME         | VARCHAR(64) | Dynamic view name  |
