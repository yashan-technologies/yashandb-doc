This view displays information about all current control files.

|Field |Type |Description |
| --- | --- | --- |
| ID     | INTEGER | File Identifier           |
| NAME   | VARCHAR(255) | File Name (Full Path) |
| BLOCK_SIZE | INTEGER | Block Size of the File (Units: Bytes) |
| FILE_SIZE_BLKS | INTEGER | Number of Blocks in the File |
| BYTES  | BIGINT  | File Size (Units: Bytes) |
