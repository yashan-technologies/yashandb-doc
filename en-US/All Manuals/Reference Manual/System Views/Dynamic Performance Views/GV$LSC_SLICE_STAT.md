This view displays the storage-related statistics of the LSC table on all primary nodes. When there is a partition, it is divided and displays information for each slice accordingly.

|Field |Type |Description |
|------------------|---------|----------------------------------------------------------------|
| GROUP_ID         | NUMBER    | Group ID                                                    |
| GROUP_NODE_ID    | NUMBER    | Node ID within the group                                    |
| INST_ID          | NUMBER    | Instance ID                                                 |
| BO               | BIGINT    | Parent table ID                                            |
| OBJ              | BIGINT    | This table ID (partition ID)                               |
| DATAOBJ          | BIGINT    | Data object ID of this table                               |
| SLICE_ID         | BIGINT    | Logical ID of slice                                       |
| STATUS           | INTEGER   | Slice status, 0: invalid, 1: active, 2: full, 3: stale, 4: free, 5: stable |
| SORTED           | BOOLEAN   | Whether sorted                                             |
| COMPACTED        | BOOLEAN   | Whether compacted                                          |
| SCN              | BIGINT    | SCN when active slice becomes full, SCN generated by stable slice |
| SPACE_ID         | INTEGER   | Tablespace to which the slice belongs                      |
| BUCKET_ID        | INTEGER   | Data bucket to which the slice belongs; for non-stable slices, this field is NULL |
| SLICE_FILE_ID    | BIGINT    | Unique ID of the slice; for non-stable slices, this field is NULL |
| FILE_SIZE        | BIGINT    | File size of the slice (including data file and meta data file); for non-stable slices, this field is NULL |
| DATA_SIZE        | BIGINT    | Final data size after encoding and compression (excluding metadata size); for non-stable slices, this field is NULL |
| ORIGINAL_SIZE    | BIGINT    | Original written data size corresponding to the slice; for non-stable slices, this field is NULL |
| ROW_COUNT        | BIGINT    | Number of rows stored in the slice; for non-stable slices, this field is NULL |
| ROW_GROUP_NUM    | BIGINT    | Number of row groups in the slice; for non-stable slices, this field is NULL |
