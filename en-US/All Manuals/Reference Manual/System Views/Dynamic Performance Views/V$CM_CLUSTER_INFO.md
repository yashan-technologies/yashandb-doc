This view displays the CLUSTER INFO information stored in the CM module.

|Field |Type |Description |
| --- | --- | --- |
| ID | VARCHAR(64) | Cluster ID |
| NAME | VARCHAR(64) | Cluster Name |
| VERSION | INTEGER | Cluster static information version number |
| NEXT_GROUP_ID | INTEGER | ID of the next group in the cluster |
| CREATE_TIME | TIMESTAMP(6) | Cluster creation time |
| LAST_UPDATE_TIME | TIMESTAMP(6) | Last update time of cluster information |
| MAX_ENDPOINT | SMALLINT | Maximum value of endpoints in the cluster |
