This view displays the version information of the database.

|Field |Type |Description |
| --- | --- | --- |
| GROUP_ID      | NUMBER     | Group ID                   |
| GROUP_NODE_ID  | NUMBER     | Node ID within the group   |
| INST_ID       | NUMBER     | Instance ID                |
| BANNER        | VARCHAR(64)| Full name of the database version |
| VERSION_NUMBER | VARCHAR(16)| Database version number     |
