This view displays information about the YFS failure group (Failgroup).

|Field |Type |Description |
|-------|------|------|
| ID           | INTEGER | The ID of the disk within its associated Diskgroup |
| GLOBAL_ID    | INTEGER | The global ID of the disk                      |
| NAME         | VARCHAR(32) | The name                                   |
| GROUP_NUMBER  | INTEGER | The ID of the associated DiskGroup           |
