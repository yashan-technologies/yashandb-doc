This view shows the resource management information of the current node.

|Field |Type |Description |
|----------------| --- | --- |
| RESNAME         | VARCHAR(256) | Resource group |
| USER            | VARCHAR(256) | User mode |
| SYSTEM          | VARCHAR(256) | System mode |
| NR_PERIODS      | VARCHAR(256) | Periods |
| NR_THROTTLED    | VARCHAR(256) | Number of throttles |
| THROTTLED_TIME  | VARCHAR(256) | Throttle time |
