This view displays information about all built-in functions provided by the current system. For a detailed list, refer to the development manual [Built-in Function](../../../Development Guide/SQL Reference Manual/Built-in Functions/00Built-in Functions).

|Field |Type |Description |
| --- | --- |---------------------------|
| GROUP_ID      | NUMBER    | Group ID                          |
| GROUP_NODE_ID | NUMBER    | Node ID within the group          |
| INST_ID       | NUMBER    | Instance ID                       |
| ID            | SMALLINT  | ID of the function                |
| NAME          | VARCHAR(64) | Name of the function             |
| ISAGGR        | VARCHAR(8)  | Is it an aggregate function? <br>\*  Y: Yes<br>\*  N: No |
