The CONTEXT buffer view displays all CONTEXT buffer information for the current session settings.

|Field |Type |Description |
| -- |--------------| --------------------------------------------- |
| GROUP_ID        | NUMBER            | Group ID                                             |
| GROUP_NODE_ID   | NUMBER            | Node ID within the group                             |
| INST_ID         | NUMBER            | Instance ID                                         |
| NAMESPACE       | VARCHAR(64)       | Context name                                        |
| ATTRIBUTE       | VARCHAR(128)      | Context buffer attribute                             |
| VALUE           | VARCHAR(4000)     | Corresponding value of the context buffer attribute  |
