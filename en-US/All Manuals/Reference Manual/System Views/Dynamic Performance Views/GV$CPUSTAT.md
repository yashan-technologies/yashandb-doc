This view displays the summary information of resource management for all nodes in the cluster.

|Field |Type |Description |
|----------------|--------------| --- |
| GROUP_ID         | NUMBER        | Group ID     |
| GROUP_NODE_ID    | NUMBER        | Node ID within the group |
| INST_ID          | NUMBER        | Instance ID  |
| RESNAME          | VARCHAR(256)  | Resource Group |
| USER             | VARCHAR(256)  | User mode    |
| SYSTEM           | VARCHAR(256)  | System mode  |
| NR_PERIODS       | VARCHAR(256)  | Period       |
| NR_THROTTLED     | VARCHAR(256)  | Throttle count |
| THROTTLED_TIME   | VARCHAR(256)  | Throttle time |
