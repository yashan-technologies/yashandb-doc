This view displays session information created by all nodes in the ISC distributed cluster.

|Field |Type |Description |
|-------------------------|--------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUP_ID               | INTEGER      | Group ID                                                                                                                                                                                                                |
| GROUP_NODE_ID         | INTEGER      | Node ID within the group                                                                                                                                                                                               |
| SID                     | SMALLINT     | Session ID                                                                                                                                                                                                               |
| GLOBAL_SESSION_ID     | INTEGER      | Global session ID in a distributed environment                                                                                                                                                                         |
| SERIAL#                 | INTEGER      | Assigned sequence number                                                                                                                                                                                               |
| PADDR                   | BIGINT       | Memory address allocated for the session                                                                                                                                                                              |
| XID                     | BIGINT       | Transaction ID associated with the session at this moment                                                                                                                                                             |
| XRMID                   | INTEGER      | XRM ID bound to the session                                                                                                                                                                                            |
| LOCKWAIT                | BIGINT       | Waiting lock ID                                                                                                                                                                                                        |
| WAIT_EVENT             | VARCHAR(32)  | Name of the wait event, the field value refers to the description in the [Wait Events](../../Wait Events) document.                                                                                                  |
| WAIT_CLASS             | VARCHAR(32)  | Type of the wait event<br>\*   APPLICATION<br>\*   CONCURRENCY<br>\*   COMMIT<br>\*   USER I/O<br>\*   SYSTEM I/O<br>\*   OTHER<br>\*   IDLE<br>\*   NETWORK<br>\*   CONFIGURATION<br>\*   CLUSTER<br>\*   DISTRIBUTED |
| USER#                   | INTEGER      | Database user ID                                                                                                                                                                                                       |
| USERNAME                | VARCHAR(64)  | Database username                                                                                                                                                                                                      |
| STATUS                  | VARCHAR(8)   | Session status<br>\* ACTIVE: active<br>\* INACTIVE: inactive<br>\* KILLED: interrupted                                                                                                                                 |
| CLI_OSUSER             | VARCHAR(68)  | Client username                                                                                                                                                                                                         |
| CLI_PROGRAM            | VARCHAR(256) | Client program name (e.g., *yasql*, JDBC Driver, C Driver, Go Driver...)                                                                                                                                              |
| CLI_HOSTNAME           | VARCHAR(256) | Client server name                                                                                                                                                                                                      |
| COMMAND                 | INTEGER      | SQL command type value, which can be queried from V$SQLCOMMAND for the corresponding SQL command name. Example: `select command_name from V$SQLCOMMAND where command_type = 1`                                      |
| SQL_HASH_VALUE        | BIGINT       | SQL hash value of the statement currently being executed by the session (calculated from SQL text)                                                                                                                   |
| SQL_ID                 | VARCHAR(13)  | SQL ID of the statement currently being executed by the session (hash/encryption result of SQL text)                                                                                                                  |
| TYPE                    | VARCHAR(16)  | Session type<br>\* USER: user session<br>\* BACKGROUND: background or parallel session                                                                                                                                |
| SERVER                  | VARCHAR(10)  | Session connection mode                                                                                                                                                                                                |
| LOGON_TIME              | TIMESTAMP    | Client login time                                                                                                                                                                                                      |
| IP_ADDRESS             | VARCHAR(45)  | Client IP address                                                                                                                                                                                                        |
| IP_PORT                 | INTEGER      | Client port number                                                                                                                                                                                                      |
| EXEC_START_TIME       | TIMESTAMP    | Execution time of the current SQL statement                                                                                                                                                                             |
| RETRY_CNT               | INTEGER      | Number of retries for the current command                                                                                                                                                                               |
| RETRY_INFO              | INTEGER      | Error code for the current command retry                                                                                                                                                                               |
| EXEC_STATUS             | INTEGER      | Execution status                                                                                                                                                                                                         |
| AUDSID                  | BIGINT       | Auditing session ID                                                                                                                                                                                                      |
| CLIENT_INFO             | VARCHAR(64)  | Client information set by calling the DBMS_APPLICATION_INFO.SET_CLIENT_INFO procedure                                                                                                                                  |
| MODULE                  | VARCHAR(64)  | The name of the currently executing module set by calling the DBMS_APPLICATION_INFO.SET_MODULE procedure                                                                                                                 |
| MODULE_HASH             | BIGINT       | Hash value of the MODULE column                                                                                                                                                                                        |
| ACTION                  | VARCHAR(64)  | The name of the operation currently being performed, set by calling the related procedures in the DBMS_APPLICATION_INFO package                                                                                         |
| ACTION_HASH             | BIGINT       | Hash value of the ACTION column                                                                                                                                                                                        |
| CLIENT_PROTOCAL_VERSION  | BIGINT      | Client protocol version                                                                                                                                                                                                 |
| CLIENT_VERSION          | VARCHAR(256) | Client software version                                                                                                                                                                                                 |
| CLIENT_DRIVER           | VARCHAR(256) | Client driver name                                                                                                                                                                                                      |
| PORT                    | INTEGER      | Client port number                                                                                                                                                                                                      |
| PROCESS                 | VARCHAR(8)   | Client operating system PID                                                                                                                                                                                            |
| MACHINE                 | VARCHAR(256) | Client operating system name                                                                                                                                                                                            |
| TERMINAL                | VARCHAR(256) | Client operating system terminal name                                                                                                                                                                                  |
| SPA_USE_MEM             | BIGINT       | Current SPA memory size used by the session (unit: bytes)                                                                                                                                                             |
| SPA_USE_QUOTA           | BIGINT       | Current quota occupied by the session (unit: bytes)                                                                                                                                                                   |
| SPA_MAX_USE_MEM         | BIGINT       | Maximum SPA memory size used by the session (unit: bytes)                                                                                                                                                             |
| RESOURCE_CONSUMER_GROUP | VARCHAR(68)  | Resource group to which the session belongs                                                                                                                                                                             |
