This view displays information about YFS failure groups (Failgroup).

|Field |Type |Description |
|---------------|-------------|----------------|
| GROUP_ID       | NUMBER      | Group ID                              |
| GROUP_NODE_ID  | NUMBER      | Node ID within the group              |
| INST_ID        | NUMBER      | Instance ID                           |
| ID             | INTEGER     | ID within the Diskgroup that the Failgroup belongs to |
| GLOBAL_ID      | INTEGER     | Global ID of the Failgroup            |
| NAME           | VARCHAR(32) | Name                                  |
| GROUP_NUMBER   | INTEGER     | ID of the associated DiskGroup        |
