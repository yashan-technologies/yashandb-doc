## 23.4.7.100

The following lists the major and notable changes in version 23.4.7.100 of YashanDB compared to version 23.4.6.100. If you discover any changes during your use that are not listed in this document but impact your company's business, please consult our technical support for detailed explanations.

### Upgrade Notes

The following table shows the range of old versions that support offline upgrades to the current version.

|Deployment Type       |Old Version Range                             |
| ---------------------------------- | ------------------------------------------------------------ |
| Standalone Deployment              | 22.2.16 and earlier<br/>23.1.5 and earlier<br/>23.2.13 and earlier<br/>23.3.3 and earlier<br/>23.4.6 and earlier |
| YAC Deployment                     | 23.1.5 and earlier<br/>23.2.13 and earlier<br/>23.3.3 and earlier<br/>23.4.6 and earlier |
| ISC Distributed Cluster Deployment | 23.1.5 and earlier<br/>23.2.12 and earlier<br/>23.3.3 and earlier<br/>23.4.6 and earlier |

### Installation and Upgrade

|Change Item |Change |Content                                             |
| ---------------------- | --------------- | ------------------------------------------------------------ |
| YAC Instance Scaling Down | New Feature     | Supports online scaling down of instances within YAC Deployment |

### System Views

|View Name |Change Item |New Value (Meaning) |
| --- | --- | --- |
| GV$ACTIVE_INSTANCES<br />V$ACTIVE_INSTANCES | NEW VIEW | Display all valid instance IDs in YAC |
| GV$PARAMETER<br />V$PARAMETER<br />GV$SYSTEM_PARAMETER<br />V$SYSTEM_PARAMETER | NEW COLUMN: `CLUSTER_CONSISTENT` | Whether all instance parameter values must remain consistent in YAC/Distributed Cluster Deployment <br>* TRUE: Requires consistency. When this parameter is modified and set to take effect immediately, the database automatically synchronizes the change to all instances to ensure global consistency.  <br>* FALSE: Does not require consistency. Each instance can be configured independently without automatic synchronization. |
| DBA_TAB_COLS                                                 | NEW COLUMN: `VIRTUAL_COLUMN`       | Whether the column is a virtual column<br/>\*  YES<br/>\*  NO |

| DBA_TAB_COLS                                                 | NEW COLUMN: `CHAR_COL_DECL_LENGTH` | The declared length of character-type columns<br/>\*   CHAR, VARCHAR2, CLOB type columns: byte length<br/>\*   NCHAR, NVARCHAR2, NCLOB type columns: character length<br/>\*   Non-character type columns: NULL |
| DBA_TAB_COLUMNS                                              | NEW COLUMN: `CHAR_COL_DECL_LENGTH` | The declared length of character-type columns<br/>\*   CHAR, VARCHAR2, CLOB type columns: byte length<br/>\*   NCHAR, NVARCHAR2, NCLOB type columns: character length<br/>\*   Non-character type columns: NULL |
