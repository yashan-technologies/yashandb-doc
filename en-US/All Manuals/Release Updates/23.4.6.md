## 23.4.6.100

The following lists the major and notable changes in version 23.4.6.100 of YashanDB compared to version 23.4.4.100. If you discover any changes during your use that are not listed in this document but impact your company's business, please consult our technical support for detailed explanations.

### Upgrade Notes

The following table shows the range of old versions that support offline upgrades to the current version.

|Deployment Type       |Old Version Range                             |
| ---------------------------------- | ------------------------------------------------------------ |
| Standalone Deployment              | 22.2.16 and earlier<br/>23.1.5 and earlier<br/>23.2.12 and earlier<br/>23.3.3 and earlier<br/>23.4.4 and earlier |
| YAC Deployment                     | 23.1.5 and earlier<br/>23.2.12 and earlier<br/>23.3.3 and earlier<br/>23.4.4 and earlier |
| ISC Distributed Cluster Deployment | 23.1.5 and earlier<br/>23.2.12 and earlier<br/>23.3.3 and earlier<br/>23.4.4 and earlier |

### Installation and Upgrade

|Change Item |Change |Content                                             |
| ---------------------- | --------------- | ------------------------------------------------------------ |
| Primary/Standby YAC Deployment           |  Rolling upgrade | Supports rolling upgrades from versions greater than 23.4.4.0 to all newer versions.  |

### Product Specifications

|Category |Specification Name |Change Item |Old Value |New Value (Meaning) |
| --- | --- | --- | --- | --- |
| Data Type | TIMESTAMP | Effective behavior of microsecond precision | Microsecond precision is uniformly treated as 6, but metadata records the user-specified actual precision (specifiable range: 0 ~ 9)  | Microsecond precision effective range is 0 ~ 6 (specifiable range remains 0 ~ 9 unchanged; values exceeding 6 are treated as 6), and metadata is now consistent with actual effective behavior |

>**Note**:
>
> To ensure backward compatibility, during upgrade, all existing TIMESTAMP data with microsecond precision not equal to 6 will be updated to 6 digits in metadata, ensuring consistency between metadata and the actual effective precision in system tables.
