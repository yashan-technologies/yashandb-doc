## 23.4.3.100

The following lists the major and notable changes in version 23.4.3.100 of YashanDB compared to version 23.4.2.100. If you discover any changes during your use that are not listed in this document but impact your company's business, please consult our technical support for detailed explanations.

### Functionality Items

This release adds the following features in distributed cluster deployment mode:

1. YFS supports disk path discovery.

2. The Intelligent Storage Service provides disk monitoring for Data Nodes (DN).
