The YashanDB C driver provides an interface (C API) for connecting to and operating the database through C applications.

Each version of the YashanDB product package includes a C driver software package, which contains header files for interface declarations and dynamic libraries that implement all interfaces. After developers obtain and install the driver package, they can start using YashanDB through standard C and SQL languages. For specific steps, please refer to the [YashanDB C driver installation instructions](./C Driver Installation/00C Driver Installation).

Supported OS + CPU Architecture Combinations for C Driver:

- Windows 7~11 + x64

- Windows 7~10 + x86

- Linux + ARM64

- Linux + LoongArch64

- Linux + x86_64
