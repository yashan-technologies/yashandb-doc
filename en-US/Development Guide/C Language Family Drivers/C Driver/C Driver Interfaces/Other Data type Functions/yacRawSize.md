## Functionality Introduction

Get the size of the binary string stored in yacRaw. The return value indicates the size of the binary string.

## Function Declaration

```c
YacUint32 yacRawSize(YacHandle hEnv, const YacRaw* yacRaw);
```

## Parameter Description

|Parameter Name |Description |
| -------------- | ------------ |
| hEnv (IN)       | Environment handle. |
| yacRaw (IN)     | yacRaw handle.     |
