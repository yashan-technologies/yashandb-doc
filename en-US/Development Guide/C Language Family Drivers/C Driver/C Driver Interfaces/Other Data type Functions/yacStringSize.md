## Functionality Introduction

  This function obtains the size of the string stored in yacString. The return value indicates the size of the stored string.

## Function Declaration

```c
YacUint32 yacStringSize(YacHandle hEnv, const YacString* yacString);
```

## Parameter Description

|Parameter Name |Description |
| ----------------- | --------------- |
| hEnv (IN)         | Environment handle. |
| yacString (IN)    | yacString handle. |
