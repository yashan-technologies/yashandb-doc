|Interface Name |Interface Description |
|--------------------|--------------------------------------|
| [SQLCancel](SQLCancel) | Cancels the processing of a statement      |
| [SQLCloseCursor](SQLCloseCursor) | Closes the cursor that is open on the statement handle  |
| [SQLEndTran](SQLEndTran) | Commits or rolls back a transaction        |
| [SQLFreeStmt](SQLFreeStmt) | Ends statement processing, discards any pending results, and frees all resources associated with the statement handle as needed |
