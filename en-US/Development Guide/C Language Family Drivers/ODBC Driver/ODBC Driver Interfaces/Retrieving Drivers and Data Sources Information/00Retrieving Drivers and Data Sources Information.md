|Interface Name |Interface Description |
|--------------------|--------------------------------------|
| [SQLDataSources](SQLDataSources) | Returns a list of available data sources.  |
| [SQLGetFunctions](SQLGetFunctions) | Returns the support status of driver functions. |
| [SQLGetInfo](SQLGetInfo) | Returns information about a specific driver and data source. |
| [SQLGetTypeInfo](SQLGetTypeInfo) | Returns information about the data types supported by the data source. |
| [SQLTables](SQLTables) | Returns a list of table, catalog, or schema names and table types stored in a specific data source. |
| [SQLColumns](SQLColumns) | Returns a list of column names in the specified table. |
