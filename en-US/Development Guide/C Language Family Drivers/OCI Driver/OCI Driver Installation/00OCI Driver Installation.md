This section provides operational guidance for installing the YashanDB OCI driver on Windows and Linux platforms, including:

- [YashanDB OCI Windows Installation Guide](Installing OCI Driver (Windows))
- [YashanDB OCI Linux Installation Guide](Installing OCI Driver (Linux))

> **Note**:
> 
> Using the YashanDB OCI driver requires the installation and configuration of the YashanDB C driver library first. The YashanDB C driver installation files are integrated into the YashanDB client installation package, and the corresponding client installation package must be obtained during installation.
