This section introduces various connection configurations supported by YashanDB JDBC. For scenarios with the following business requirements, please refer to the corresponding documentation for configuration guidance after understanding the [basic connection configuration](Basic Connection Configuration) operations: 

- When information security requires clients to establish trusted connections with the server, please refer to [configuring secure connections](Configuring Secure Connections). 
- For high availability requirements involving multi-IP connection configuration, and further requirements for transparent application failover, please refer to [configuring high availability connections](Configuring High Availability Connections). 
- When the server is in mysql mode and requires the client to connect in mysql mode, please refer to [configuring mysql mode connections](./Configuring mysql Mode Connections).
