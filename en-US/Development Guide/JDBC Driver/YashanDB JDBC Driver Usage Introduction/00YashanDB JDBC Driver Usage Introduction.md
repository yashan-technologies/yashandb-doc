The advanced features of YashanDB JDBC refer to a series of configuration guidelines and usage operation introductions provided for specific business scenarios, in addition to the standard connection and SQL functions. 

For example, to effectively reduce application interruptions caused by database connection failures due to instance or network failures, the Transparent Application Failover (TAF) feature can be used to achieve seamless switching of application-side connections. To free users from learning some database-specific syntax, advanced features also provide operation interfaces for GIS data types, JSON data types, and date-time types that comply with common JDBC syntax escape format specifications.

Please choose whether to configure these features based on actual needs, and  read the rules and requirements listed in the corresponding documentation.
