This chapter describes the advanced functions and features of YashanDB JDBC, helping developers use JDBC for database development more efficiently.  

This chapter is suitable for developers who have mastered basic JDBC usage and need to use advanced features.

This chapter includes:

- **Using JSON**: Introduces methods for storing and querying JSON data types in YashanDB

- **Using GIS**: Introduces JDBC operations for Geographic Information System (GIS) data

- **Handling XML Documents with JDBC**: Introduces methods for storing, retrieving, and processing XML documents

- **Handling Escaping with JDBC**: Introduces escape syntax handling for date and time data

- **JDBC Logs Management**: Introduces configuration and usage of JDBC logs

- **Support for Data Sharding with In Memory Database**: Introduces JDBC configuration methods for data sharding scenarios in distributed in-memory databases

- **Handling Result Sets**: Introduces how to use result sets

- **Handling Transactions**: Introduces how to commit changes with transactions

- **Calling Stored Procedures**: Introduces methods for calling stored procedures

- **Handling Large Objects**: Introduces operations for large objects such as BLOB and CLOB

- **Transparent Application Failover**: Introduces transparent failover functionality in HA scenarios
