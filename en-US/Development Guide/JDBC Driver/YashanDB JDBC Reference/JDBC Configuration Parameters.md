This document describes the configuration parameters of the YashanDB JDBC driver.

> **Note**
>
> All the following parameters are JDBC connection URL parameters, which can be configured in the connection string in the form of `key=value`.

### allowMultiStmt

*   Parameter Type: String

*   Default Value: FALSE

*   Value Range/Format: [TRUE|FALSE]

*   Parameter Description: Whether to enable support for multiple SQL. TRUE means enabled, FALSE means disabled. When enabled, multiple SQL statements can be passed in simultaneously, separated by semicolons, with the trailing semicolon of the last SQL statement being optional. The input SQL statements will be executed in order, stopping and returning an error if an error occurs, while the JDBC interface will always only return the execution result of the first SQL statement. Currently, only non-parameterized SQL statements are supported, and autoGeneratedKey is not allowed during execution.

<span id="apara" name="apara"></span>

### allowSemicolonTerminator

*   Parameter Type: String

*   Default Value: FALSE

*   Value Range/Format: [TRUE|FALSE]

*   Parameter Description: Whether to allow SQL statements to end with a semicolon. TRUE means allowed, FALSE means not allowed.

<span id="apara" name="apara"></span>

### autoCommit

*   Parameter Type: String

*   Default Value: TRUE

*   Value Range/Format: [TRUE|FALSE]

*   Parameter Description: Whether to enable automatic transaction commit. TRUE means enabled, FALSE means disabled. In mysql mode, whether transactions are auto-committed is also controlled by the database server system variable AUTOCOMMIT. If the server is not configured to auto-commit but the client is, the final behavior will still be non-auto-commit.

<span id="cpara" name="cpara"></span>

### cancelSignalTimeout

*   Parameter Type: Int

*   Default Value: 10

*   Value Range/Format: Unit is seconds, positive integer

*   Parameter Description: Timeout for sending cancel command. The timeout value used for sending cancel command.

<span id="cpara" name="cpara"></span>

### clientPrepare

*   Parameter Type: String

*   Default Value: FALSE

*   Value Range/Format: [TRUE|FALSE]

*   Parameter Description: Enable or disable directExecute with bind parameters. FALSE means the client will firstly send prepare sql, then send bind parameters; TRUE means send them together to server.

<span id="cpara" name="cpara"></span>

### compatVector

*   Parameter Type: String

*   Default Value: yashan

*   Value Range/Format: [mysql|yashan]

*   Parameter Description: Compatibility mode setting. When set to mysql, the username is case-sensitive, and the return value of DatabaseMetaData.getDatabaseProductName will be mysql. When set to yashan, the username is case-insensitive and the return value is YashanDB.

<span id="cpara" name="cpara"></span>

### convertNcharLiterals

*   Parameter Type: String

*   Default Value: TRUE

*   Value Range/Format: [TRUE|FALSE]

*   Parameter Description: Whether to convert NCHAR literals. TRUE means enabled, FALSE means disabled.

<span id="dpara" name="dpara"></span>

### defaultRowFetchSize

*   Parameter Type: Int

*   Default Value: 10

*   Value Range/Format: Positive integer

*   Parameter Description: Positive number of rows that should be fetched from the database when more rows are needed for ResultSet by each fetch iteration.

<span id="dpara" name="dpara"></span>

### connectTimeout

*   Parameter Type: Int

*   Default Value: 10

*   Value Range/Format: Unit is seconds, positive integer

*   Parameter Description: Timeout for creating socket connection when establishing connection, in seconds. Default is 10 seconds when not configured, configured via info attribute or URL.

<span id="fpara" name="fpara"></span>

### failover

*   Parameter Type: String

*   Default Value: OFF

*   Value Range/Format: [ON|OFF]

*   Parameter Description: Whether to enable Transparent Application Failover (TAF). ON indicates TAF is enabled, and the application will automatically switch to the other configured database nodes in case of a failure. OFF indicates TAF is disabled, and automatic reconnection to the current database node is not supported in OFF state.

<span id="fpara" name="fpara"></span>

### failoverDelay

*   Parameter Type: Int

*   Default Value: 1

*   Value Range/Format: Unit is seconds, positive integer

*   Parameter Description: Time interval for retries. The wait time between retry attempts after a failover failure.

<span id="fpara" name="fpara"></span>

### failoverMethod

*   Parameter Type: String

*   Default Value: BASIC

*   Value Range/Format: BASIC

*   Parameter Description: The method of failover, which will determine the speed of failover from the primary node to the standby node. BASIC indicates that a new connection is established during failover.

<span id="fpara" name="fpara"></span>

### failoverRetries

*   Parameter Type: Int

*   Default Value: 5

*   Value Range/Format: Positive integer

*   Parameter Description: Number of retry attempts. The number of retry attempts after a failover failure.

<span id="fpara" name="fpara"></span>

### failoverType

*   Parameter Type: String

*   Default Value: NONE

*   Value Range/Format: [NONE|SESSION|SELECT]

*   Parameter Description: Type of failover. NONE indicates no failover is used. SESSION indicates reconnecting and resetting the Statement handle after a failure. SELECT indicates re-executing the failed SELECT statement (the SELECT statement cannot be a query with LOB-type binding parameters) after switching the connection, but it does not support secondary operations on previously obtained objects.

<span id="hpara" name="hpara"></span>

### heartbeatSwitch

*   Parameter Type: String

*   Default Value: ON

*   Value Range/Format: [ON|OFF]

*   Parameter Description: Heartbeat connection switch. ON indicates enabling heartbeat connections, OFF indicates disabling. Enabling heartbeat connections allows the program to detect network anomalies faster on active connections, triggering subsequent operations such as fault recovery.

<span id="hpara" name="hpara"></span>

### heartbeatSchedulePeriod

*   Parameter Type: Int

*   Default Value: 20

*   Value Range/Format: Unit is seconds, positive integer

*   Parameter Description: Heartbeat connection keep-alive interval. The interval for sending heartbeat probes.

<span id="hpara" name="hpara"></span>

### heartbeatSocketTimeout

*   Parameter Type: Int

*   Default Value: 60

*   Value Range/Format: Unit is seconds, positive integer

*   Parameter Description: Heartbeat connection keep-alive timeout. The timeout for waiting for a response after sending a heartbeat probe.

<span id="lpara" name="lpara"></span>

### logServerErrorDetail

*   Parameter Type: String

*   Default Value: TRUE

*   Value Range/Format: [TRUE|FALSE]

*   Parameter Description: Include full server error detail in exception messages. If disabled then only the error itself will be included.

<span id="lpara" name="lpara"></span>

### loggerFile

*   Parameter Type: String

*   Default Value: None

*   Value Range/Format: String

*   Parameter Description: File name output of the Logger.

<span id="lpara" name="lpara"></span>

### loggerLevel

*   Parameter Type: String

*   Default Value: None

*   Value Range/Format: [OFF|DEBUG|TRACE]

*   Parameter Description: Logger level of the driver.

<span id="lpara" name="lpara"></span>

### logUnclosedConnections

*   Parameter Type: String

*   Default Value: FALSE

*   Value Range/Format: [TRUE|FALSE]

*   Parameter Description: When connections that are not explicitly closed are garbage collected, log the stacktrace from the opening of the connection to trace the leak source.

<span id="lpara" name="lpara"></span>

### loginTimeout

*   Parameter Type: Int

*   Default Value: 300

*   Value Range/Format: Unit is seconds, positive integer

*   Parameter Description: Login authentication timeout. Timeout for client waiting for server return data during login authentication after socket is successfully created.

<span id="mpara" name="mpara"></span>

### mapDateToTimestamp

*   Parameter Type: String

*   Default Value: FALSE

*   Value Range/Format: [TRUE|FALSE]

*   Parameter Description: Date-to-timestamp conversion switch. TRUE means enabled, FALSE means disabled. When enabled, DATE-type columns will return Timestamp-type column attributes in some interfaces. Affected interfaces include: ResultSet.getString(int columnIndex) will return a string in Timestamp format; ResultSet.getObject(int columnIndex) will return a Timestamp class; ResultSetMetaData.getColumnClassName(int column) will return Timestamp.class.

<span id="npara" name="npara"></span>

### netTimeoutForStreamingResults

*   Parameter Type: Int

*   Default Value: 600

*   Value Range/Format: Unit is seconds, positive integer

*   Parameter Description: The timeout for network operations when streaming results.

<span id="ppara" name="ppara"></span>

### poolTimeout

*   Parameter Type: Int

*   Default Value: 300

*   Value Range/Format: Unit is seconds, positive integer. Can only be used with primary or standby types.

*   Parameter Description: Multi-address connection timeout. During the entire connection process, even if all addresses are quickly traversed and none of them result in a successful connection, the system will still wait for the duration of poolTimeout before prompting a connection failure.

<span id="ppara" name="ppara"></span>

### productName

*   Parameter Type: String

*   Default Value: YashanDB

*   Value Range/Format: String

*   Parameter Description: (Hidden parameter) Specify the identifier for the database product name. When omitted, it is defaulted to be recognized as YashanDB. If specified, it can bypass the automatic recognition and take effect according to the specified value.

<span id="rpara" name="rpara"></span>

### readOnlyResultSetInsensitive

*   Parameter Type: String

*   Default Value: FALSE

*   Value Range/Format: [TRUE|FALSE]

*   Parameter Description: All read only resultSet is insensitive. TRUE means insensitive, FALSE means sensitive.

<span id="rpara" name="rpara"></span>

### receiveBufferSize

*   Parameter Type: Int

*   Default Value: -1

*   Value Range/Format: Integer, -1 means use system default

*   Parameter Description: Socket read buffer size.

<span id="spara" name="spara"></span>

### sendBufferSize

*   Parameter Type: Int

*   Default Value: -1

*   Value Range/Format: Integer, -1 means use system default

*   Parameter Description: Socket write buffer size.

<span id="spara" name="spara"></span>

### serverMode

*   Parameter Type: String

*   Default Value: shared

*   Value Range/Format: [shared|dedicated]

*   Parameter Description: Specify the connection mode. shared indicates the connection to shared server mode, allowing client connections to use a shared thread pool (actual use of a shared thread pool depends on relevant YashanDB server configuration parameter MAX_REACTOR_CHANNELS). dedicated indicates the connection to the dedicated server mode, meaning each client connection request must allocate a separate thread (not affected by relevant YashanDB server configurations).

<span id="spara" name="spara"></span>

### socketTimeout

*   Parameter Type: Int

*   Default Value: 0

*   Value Range/Format: Unit is seconds, positive integer. 0 means waiting indefinitely.

*   Parameter Description: TCP communication timeout. Timeout for client waiting for server return data during TCP communication after obtaining connection.

<span id="spara" name="spara"></span>

### SQL statement execution timeout

*   Parameter Type: Int

*   Default Value: 0

*   Value Range/Format: Unit is seconds, positive integer. 0 means no timeout limit.

*   Configured via the Statement interface setQueryTimeout. Default has no timeout (waiting indefinitely) when not configured.

<span id="spara" name="spara"></span>

### sslRootCer

*   Parameter Type: String

*   Default Value: None

*   Value Range/Format: Certificate file path, can be absolute or relative path

*   Parameter Description: Standard path to the root certificate for SSL encrypted communication. If the server has enabled SSL encrypted communication, the JDBC must configure this parameter.

<span id="tpara" name="tpara"></span>

### tcpKeepAlive

*   Parameter Type: String

*   Default Value: TRUE

*   Value Range/Format: [TRUE|FALSE]

*   Parameter Description: Enable or disable TCP keep-alive. The default is TRUE.

<span id="tpara" name="tpara"></span>

### tlcpCacertFile

*   Parameter Type: String

*   Default Value: None

*   Value Range/Format: Certificate file path, can be absolute or relative path

*   Parameter Description: Standard path to the root certificate for TLCP encrypted communication. If the server enables TLCP encrypted communication, the JDBC must configure this parameter.

<span id="tpara" name="tpara"></span>

### tlcpCertFile

*   Parameter Type: String

*   Default Value: None

*   Value Range/Format: Certificate file path, can be absolute or relative path

*   Parameter Description: Standard path to the client certificate for TLCP encrypted communication. If the server enables TLCP encrypted communication, the JDBC must configure this parameter.

<span id="tpara" name="tpara"></span>

### tlcpClientKeyFile

*   Parameter Type: String

*   Default Value: None

*   Value Range/Format: Key file path, can be absolute or relative path

*   Parameter Description: Standard path to the client key file for TLCP encrypted communication. If the server enables TLCP encrypted communication, the JDBC must configure this parameter.

<span id="tpara" name="tpara"></span>

### tlcpClientKeyPass

*   Parameter Type: String

*   Default Value: None

*   Value Range/Format: Password string

*   Parameter Description: Password for the client key for TLCP encrypted communication. If the server enables TLCP encrypted communication, the JDBC must configure this parameter.

<span id="upara" name="upara"></span>

### useNativeType

*   Parameter Type: String

*   Default Value: TRUE

*   Value Range/Format: [TRUE|FALSE]

*   Parameter Description: Use native type. TRUE means use native type, FALSE means not use.

<span id="upara" name="upara"></span>

### ukeyName

*   Parameter Type: String

*   Default Value: None

*   Value Range/Format: [DBA|SECURITY_ADMIN|AUDIT_ADMIN]

*   Parameter Description: UKEY device name. If the user's role is DBA, the UKEY device name must be DBA. If the user's role is Security Administrator, the UKEY device name must be SECURITY_ADMIN. If the user's role is Auditor, the UKEY device name must be AUDIT_ADMIN. The device name must correspond to the user's role name. If the server enables UKEY secure login, the JDBC must configure this parameter.

<span id="upara" name="upara"></span>

### ukeyPin

*   Parameter Type: String

*   Default Value: None

*   Value Range/Format: Password value less than 64 bits

*   Parameter Description: User password for UKEY. If the server enables UKEY secure login, the JDBC must configure this parameter.
