The lexical units of PL are its smallest single components, including:

-  Delimiters
- Identifiers
- Literals
- Compilation instructions
- Comments

## Delimiters

Delimiters are used to separate lexical elements and can be a single character or a combination of multiple characters. The following delimiters are included in PL:

|Delimiter |Meaning |
| --- | ---|
| + | Addition operator |
| := | Assignment operator |
| % | Attribute identifier |
| ' | String delimiter |
| . | Object delimiter |
| &#124;&#124; | Concatenation operator |
| / | Division operator |
| ( | Left parenthesis |
| ) | Right parenthesis |
| , | Comma separator |
| << | Left tag delimiter |
| >> | Right tag delimiter | 
| /* | Multi-line comment start delimiter |
| */ | Multi-line comment end delimiter |
| * | Multiplication operator |
| " | Double quote |
| .. | Range operator |
| = | Equals sign |
| <> | Not equal sign |
| != | Not equal sign |
| < | Less than sign |
| > | Greater than sign |
| <= | Less than or equal to sign |
| >= | Greater than or equal to sign |
| -- | Single line comment delimiter |
| ; | Semicolon |
| - | Subtraction operator |

## Identifiers

Identifiers are used to identify PL syntax units, including:

- Literals
- Cursors
- Exceptions
- Keywords
- Labels
- Packages
- Reserved keywords
- Subroutine bodies
- Types
- Variables

For more details, refer to [Identifiers](../../SQL Reference Manual/Basic SQL Elements/Identifiers).

## Literals

Literals refer to constant values that appear directly as strings in SQL and PL statements. For more details, refer to [Literals](../../SQL Reference Manual/Basic SQL Elements/Literals).

## Compilation Instructions

Compilation instructions (PRAGMA) are used to indicate directives for the compilation stage.

## Comments

Comments are used to enhance the readability of PL programs and are ignored during the compilation process.

**Single Line Comments**

Marked with "--" before the comment text.

**Multi-line Paragraph Comments**

The comment text is enclosed with "/*...*/".
