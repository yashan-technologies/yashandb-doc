The YashanDB Perl driver is implemented through the combination of YashanDB ODBC and Perl-related modules, providing the Perl API for YashanDB. For specific Perl interface specifications, refer to the [DBI module for Perl](https://metacpan.org/pod/DBI).

This driver supports connections only when YashanDB is deployed in yashan mode.

For specific installation steps, refer to the section [YashanDB Perl Driver Installation](YashanDB Perl Driver Installation).

To learn about the simple process of connecting and operating YashanDB in a Perl application, see the section [YashanDB Perl Driver Usage Examples](YashanDB Perl Driver Usage Examples).
