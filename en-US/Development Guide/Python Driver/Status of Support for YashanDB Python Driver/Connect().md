## Functionality Introduction

This is a constructor function used to create a database connection, returning a connection object (Connection) after the connection is established.

### Parameter List

|Parameter |Description |Supported |
| -------- | ---------------- | -------- |
| dsn       | Database connection descriptor    | Supported |
| user      | Database username                 | Supported |
| password  | Database password                 | Supported |
| host      | IP address of the database server | Supported |
| database  | Database name                     | Not Supported |
