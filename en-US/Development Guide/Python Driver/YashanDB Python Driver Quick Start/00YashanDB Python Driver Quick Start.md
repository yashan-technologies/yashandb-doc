The Python Quick Start will help you quickly master the core usage of the YashanDB Python driver, covering the entire workflow of database connection, cursor operations, and CRUD operations — the sample code is ready to run out of the box.


This chapter includes:

- [Connecting to YashanDB](./Connecting to YashanDB): Introduces how to use the yaspy module to connect to YashanDB databases, including standalone connections and pooled connections

- [Creating Cursor Objects](./Creating Cursor Objects): Introduces how to create and use cursor objects

- [Creating Tables](./Creating Tables): Introduces how to create tables, add constraints and indexes

- [Inserting Data](./Inserting Data): Introduces single insert, batch insert, and parameterized insert

- [Updating Data](./Updating Data): Introduces how to update data in tables

- [Deleting Data](./Deleting Data): Introduces how to delete data from tables

- [Querying Data](./Querying Data): Introduces methods for querying data, including fetchone, fetchall, fetchmany, etc.

- [Committing Transactions](./Committing Transactions): Introduces usage of auto-commit and manual commit transactions

- [Closing Connections](./Closing Connections): Introduces how to properly close cursors and connections
