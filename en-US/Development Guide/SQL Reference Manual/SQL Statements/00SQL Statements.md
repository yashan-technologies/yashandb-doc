DML (Data Manipulation Language)
-------------------------------

Data Manipulation Language is used to manipulate the data contained within database objects, i.e., records. YashanDB provides the following DML statements:

[SELECT](SELECT)

[INSERT](INSERT)

[UPDATE](UPDATE)

[DELETE](DELETE)

[MERGE](MERGE)

DCL (Data Control Language)
--------------------------

Data Control Language is used to control privileges on database objects and manage transactions. YashanDB provides the following DCL statements:

[COMMIT](COMMIT)

[GRANT](GRANT)

[RELEASE SAVEPOINT](RELEASE SAVEPOINT)

[REVOKE](REVOKE)

[ROLLBACK](ROLLBACK)

[SAVEPOINT](SAVEPOINT)

[SET TRANSACTION](SET TRANSACTION)
