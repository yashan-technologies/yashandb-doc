General Description
----

The TRANSPORT statement is used to migrate related objects after migrating the tablespace. When transporting objects, only the definitions need to be created, and there is no need to create storage objects. Subsequently, the ALTER-related object's RECLAIM clause must be executed to specify the physical location of the storage object.

> **Warn**:
> 
> After scaling nodes/node groups in ISC Distributed Cluster Deployment, migration-related statements will be automatically generated by the database. **It is not recommended for users to manually execute TRANSPORT statements**, as doing so may lead to system crashes or other unpredictable results.

Statement Definition
----

**transport object::=**

```ebnf
= TRANSPORT 
[transport_table_clause] [transport_index_clause] [transport_ac_clause] [transport_view_clause]
[transport_comment_clause] [transport_alter_table_clause] [transport_user_clause] [transport_role_clause]
[transport_profile_clause] [transport_grant_clause]
[transport_tablespace_clause] [transport_alter_tablespace_clause].
```

**transport_table_clause**

```ebnf
= [ SHARED | DUPLICATE] TABLE [schema "."] table_name [OBJNO object_id VERSION version GLOBAL_CHUNKS chunk DSID ds_id DSVERSION ds_version] create_table_clause.
```
**transport_index_clause**

```ebnf
= [UNIQUE|COLUMNAR|RTREE] INDEX [schema"."] index_name create_index_clause.
```

**transport_ac_clause**

```ebnf
= ACCESS CONSTRAINT [OBJNO object_id ] [schema "."] ac_name  create_access_constraint_clause.
```

**transport_view_clause**

```ebnf
= VIEW [OBJNO object_id VERSION version] [schema "."] view_name  create_view_clause.
```

**transport_comment_clause**

```ebnf
= COMMENT ON  comment_clause.
```

**transport_alter_table_clause**

```ebnf
= ALTER TABLE [schema "."] table_name alter_table_clause.
```

**transport_user_clause**

```ebnf
= USER [OBJNO object_id VERSION version USERNO user_no EXPTIME exp_date] user_name create_user_clause.
```

**transport_role_clause**

```ebnf
= ROLE [OBJNO object_id VERSION version USERNO user_no] role_name create_role_clause.
```

**transport_profile_clause**

```ebnf
= PROFILE [OBJID object_id VERSION version PROFILEID profile_id] create_profile_clause.
```

**transport_grant_clause**

```ebnf
= GRANT GRANTOR grantor_name grant_clause.
```

**transport_tablespace_clause**

```ebnf
= create_tablespace_clause.
```

**transport_alter_tablespace_clause**

```ebnf
= alter_tablespace_clause.
```
