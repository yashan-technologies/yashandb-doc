Schema objects include:

|Type |SQL Keyword |Description |
| ------------ | --------- | ------------------------------------------ |
| Table            | Table       | A table stores data in rows and columns                  |
| AC               | AC          | AC implements model transformation to reduce large data   |
| Index            | Index       | An index is an accelerated structure built on a table     |
| Partition        | Partition   | Partition manages tables by dividing them into multiple parts according to specific rules |
| View             | View        | A view is a persistent declaration of a query statement as an object |
| Sequence         | Sequence    | A Sequence is an object defined by the user, maintained automatically by the database, used to generate integers |
| Synonym          | Synonym     | A synonym is an alias created by users for a schema object |
| UDT              | UDT         | A complex data type created by users based on basic data types or other custom data types in the database |
| UDF              | Function     | A function written by users using PL languages or programming languages like C, Java |
| Procedure        | Procedure    | A set of statements written by users using PL languages or programming languages like C, Java |
| Package          | Package      | A package is a collection created by users, consisting of a group of stored procedures, functions, and variables |
