*yasboot* tool generates three different running logs based on different processes during its usage.

## yasboot Log

It mainly records key information generated locally during the execution of *yasboot* command (if the process has reached the yasom process or yasagent process, the logs of the corresponding process should be checked), helping operation and maintenance personnel locate and address issues that arise during command execution.

**Log Level**

The log level of *yasboot* is DEBUG.

**Log File Size Limit**

The maximum file size limit for *yasboot* logs is 100M and cannot be adjusted. When the file size reaches the limit, it will be split into multiple log files.

**Number of Log Files**

A maximum of 30 *yasboot* logs will be retained, and this cannot be adjusted. When the number of files reaches the limit, earlier files will be automatically deleted.

**Log Storage Path**

The default storage path for *yasboot* log files is {path of yasboot tool}/om/yasboot.log:

- The *yasboot* tool initially resides in the YashanDB installation path (i.e., the unpacking location of the installation package, at this time the log storage path is /home/yashan/install/om/yasboot.log).

- After the YashanDB installation is completed and the environment variables are configured, logs generated by the *yasboot* tool will be stored in $YASDB_HOME/om/yasboot.log.

Example of *yasboot* log storage path:

```shell
# Assuming *yasboot* tool is initially located in YashanDB installation path
$ cd /home/yashan/install
$ ll bin/
total 0
lrwxrwxrwx 1 yashan yashan 17 Apr 17 00:15 yasboot -> ../om/bin/yasboot
# yasboot.log will appear in om directory
# om directory before executing the command:
$ ll om/
total 0
drwxrwxr-x 2 yashan yashan  135 Apr 17 00:14 bin
drwxrwxr-x 2 yashan yashan  156 Apr 17 00:14 conf
drwxrwxr-x 2 yashan yashan   30 Apr 17 00:14 monit
drwxrwxr-x 3 yashan yashan   38 Apr 17 00:14 static
# Execute *yasboot* command
$ ./bin/yasboot package se gen -c yashandb -L
# om directory after executing the command, yasboot.log has appeared
$ ll om/
total 16
drwxrwxr-x 2 yashan yashan  135 Apr 17 00:14 bin
drwxrwxr-x 2 yashan yashan  156 Apr 17 00:14 conf
drwxrwxr-x 2 yashan yashan   30 Apr 17 00:14 monit
drwxrwxr-x 3 yashan yashan   38 Apr 17 00:14 static
-rw-rw-r-- 1 yashan yashan 4294 Apr 22 18:06 yasboot.log
```

## yasom Log

It primarily records key information during the task processing of the yasom process, helping operation and maintenance personnel identify and resolve issues that occur during command execution.

**Log Level**

The default log level for yasom is DEBUG.

**Log File Size Limit**

The maximum file size limit for yasom logs is 100M. When the file size reaches the limit, it will be split into multiple log files.

**Number of Log Files**

A maximum of 30 yasom logs will be retained. When the number of files reaches the limit, earlier files will be automatically deleted.

**Log Storage Path**

The default storage path for yasom log files is {$YASDB_HOME parent directory}/log/om/{cluster name}/yasom.log:

The log storage path can be [planned](../../Installation and Upgrade/Installation and Deployment/Pre-Installation Preparation/Creating Users and Directories.md#run_log_path) as needed, ways to specify/adjust the storage path include:

- Method 1: During the YashanDB installation process (before executing yasboot package install), specify the log storage path using the --log-path parameter when generating the deployment file. This operation will also specify the storage directories for the database's run.log, slow.log, yasom log, and yasagent log; adjustments should be made according to the actual needs if separate storage is required.

- Method 2: During the YashanDB installation process (after generating the deployment file and before executing yasboot package install), modify the log_path parameter under [host] in the hosts.toml file to specify the log storage path. This operation will also specify the storage directories for the yasom log and yasagent log; adjustments should be made according to actual needs if separate storage is required.

    ```toml
    # Sample file content
    [[host]]
    hostid = "host0001"
    user = "yashan"
    password = "password"
    ip = "192.168.1.2"
    port = 22
    path = "/data/yashan/yasdb_home"
    log_path = "/data/yashan/log"       # Logs for yasom and yasagent
    [host.yasagent]
        [host.yasagent.config]
        LISTEN_ADDR = "192.168.1.2:1676"
    ```

- Method 3: After the YashanDB installation is completed (after executing yasboot package install), modify the log_path parameter under [log] in the $YASDB_HOME/om/{cluster name}/conf/yasom.toml file to specify the log storage path, and restart yasom for the configuration to take effect.

    ```toml
    # Sample file content
    [log]
      level = 0
      max_age = 7s
      max_size = 104857600
      max_backups = 30
      path = "/data/yashan/log/om/yashandb"
      log_path = "/data/yashan/log/om/yashandb/yasom.log"
      err_log_path = "/data/yashan/log/om/yashandb/yasom-panic.log"
      start_log = "/data/yashan/log/om/yashandb/yasom-start.log"
      console = true
    ```
