YAC configuration file lists the YashanDB server database-related information as well as the logical cluster architecture composed of multiple instances.

Among them, the parameter-related configuration information is divided into the following two parts:

- [Database Creation Parameters](../Database Creation Parameters): These parameters are used to control the relevant information when creating a database instance and are configured at the [[group]] instance group level, ensuring that multiple instances within each instance group create consistent databases.
- [Configuration Parameters](../../../Reference Manual/Configuration Parameters): Configuration parameter information for each database instance, configured at the [[group.node]] instance level.



>**Caution**:
>
> The sample content of the configuration files provided in this chapter is mainly used to introduce the composition and meaning of configuration items. To avoid introducing unnecessary errors, it is **not recommended** to directly copy the sample content to manually construct configuration files.
