The toml configuration file is used to configure the environmental information for setting up YashanDB. YashanDB's operational services provided by *yasboot* are all based on toml files. 

Configuration files are generated by the corresponding yasboot commands and can be mainly classified into the following categories:



>**Caution**:
>
> The sample content of the configuration files provided in this chapter is mainly used to introduce the composition and meaning of configuration items. To avoid introducing unnecessary errors, it is **not recommended** to directly copy the sample content to manually construct configuration files.



|Category     |Description      |Generation Command |File Name         |
| ------------------- | ------------------------ | ---------------- | --------------------- |
| Server Configuration File           | Mainly records information related to the database server, yasom - related information, etc. For an example of the file content, please refer to [Server Configuration File](Server Configuration File). | yasboot package se/ce/de gen    | hosts.toml                                                 |
| Cluster Configuration File          | Mainly records database - related configuration information, logical architecture information of the database cluster, etc. It varies according to different deployment forms. For an example of the file content, please refer to [Standalone Deployment Configuration File](./Standalone Deployment Configuration File), [YAC Deployment Configuration File](./YAC Deployment Configuration File), [Distributed Cluster Deployment Configuration File](./Distributed Cluster Deployment Configuration File), or [ISC Distributed Cluster Deployment Configuration File](./ISC Distributed Cluster Deployment Configuration File). | yasboot package se/ce/de gen    | {cluster_name}.toml, e.g., yashandb.toml                   |
| Server Scale-out Configuration File   | Mainly records information related to the newly added servers for scale-out. For an example of the file content, please refer to [Server Scale-out Configuration File](./Server Scale-out Configuration File). | yasboot config node/group gen   | hosts_add.toml                                             |
| Database Scale-out Configuration File | Mainly records the relevant configuration information of the newly added nodes/groups for scale-out. For an example of the file content, please refer to [Database Scaling Configuration File](./Database Scale-out Configuration File). | yasboot config node/group gen   | {cluster_name}_add.toml, e.g., yashandb_add.toml           |
| Server Check Configuration File     | Mainly records the [check items](../Introduction to yasboot Command/yasboot collection.md#CheckItems) when checking the database server. For an example of the file content, please refer to [Server Check Configuration File](./Server Check Configuration File). | yasboot config host gen         | yascheck.toml                                              |
| Database Topology File              | Mainly records the logical topology information of the database cluster. For an example of the file content, please refer to [Database Topology File](./Database Topology File). | yasboot cluster load            | {cluster_name}_topology.toml, e.g., yashandb_topology.toml |
| YAC Upgrade Configuration File      | Only used in the scenario where YAC is upgraded from version 23.2.x.x and earlier to version 23.4.x.x and above.<br />Mainly records the disk information planned for the new - version YAC. For an example of the file content, please refer to [YAC Upgrade Configuration File](./YAC Upgrade Configuration File). | Manually created                | disk_config.toml                                           |
