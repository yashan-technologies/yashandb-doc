The distributed configuration file lists the database-related information for each node in the YashanDB server and the logical cluster architecture composed of multiple nodes.

Among them, the configuration information related to parameters is divided into the following two parts:

- [Database Creation Parameters](../Database Creation Parameters): These parameters are used to control the relevant information when creating database instances, configured at the [[group]] node group level, meaning that multiple nodes within each node group create consistent database instances.
- [Configuration Parameters](../../../Reference Manual/Configuration Parameters): The configuration parameter information for each database instance is configured at the [[group.node]] node level.



>**Caution**:
>
> The sample content of the configuration files provided in this chapter is mainly used to introduce the composition and meaning of configuration items. To avoid introducing unnecessary errors, it is **not recommended** to directly copy the sample content to manually construct configuration files.
