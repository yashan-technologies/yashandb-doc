## View Help

Use the command `yasrman -h` to view help information.

```shell
$ yasrman -h
```

## Command Format

```shell
yasrman <user>/<password>@<IP>:<port> -c <command> [-D <catalog_path>]
yasrman -c <command> [-D <catalog_path>]
```

**<user>/<password>@<IP>:<port>**

Connection information pointing to the database instance (Standalone Deployment) or CN node (ISC Distributed Cluster Deployment), supporting remote TCP connections and local UDS connections. The IP address supports IPv4 and IPv6.

Different commands have different privilege requirements for database users:

- Full database RESTORE can only be executed by the SYS user.
- BACKUP, RECOVER, and tablespace RESTORE require either a SYS superuser or a user with SYSDBA or SYSBACKUP privileges to execute.

> **Note**: 
>
> - The BACKUP and RESTORE commands must specify connection information to execute.
> - Other statements do not interact with the database and will not validate the correctness of the username, password, and IP, only for maintaining command format consistency.

**-C <command>**

The -C parameter is used to specify the specific command statements, including:

- [CREATE CATALOG](CREATE CATALOG): Used to create a catalog path. Before using *yasrman* for backup and recovery for the first time, this command must be used to create the catalog.

- [CONFIGURE and SHOW ALL](CONFIGURE): CONFIGURE is used to create or modify persistent configurations affecting *yasrman* backups and restores on the database. The SHOW ALL command provides detailed information about the aforementioned configurations.

- [BACKUP](BACKUP): Used to back up the primary database/standby database, tablespaces, and archive files. It also partially supports backup functionality for YACs and distributed clusters.

- [DELETE](DELETE): Used to delete specified backup sets.

- [LIST](LIST): Used to display information about backup sets recorded in the *yasrman* repository.

- [RECOVER](RECOVER): Used to perform consistent recovery on tablespace object files.

- [RESTORE](RESTORE): The RESTORE command can be used to recover based on backup sets generated by *yasrman*, including full database restore, restoration of a specific tablespace, and archive file recovery operations.

- [VALIDATE](VALIDATE): Used to check whether the backup set files recorded in the catalog are complete, thereby determining if they can be used for recovery.

**-D <catalog_path>**

The -D parameter is used to specify the catalog path and must be specified as an absolute path. If the -D command is omitted, the catalog_path defaults to the current path.

- When the command is CREATE CATALOG, the catalog_path must be a new path for creating the catalog.

- When the command is something else, the catalog_path must be an existing catalog path.
