YashanDB provides the following supporting tools for users:

- [*yasql*](../../../Tools Guide/yasql/00yasql): Client connection management and SQL command line tool
- [*yaspwd*](../../../Tools Guide/yaspwd): Password change tool
- [*yasldr*](../../../Tools Guide/yasldr/00yasldr): Data import tool
- [*imp*](../../../Tools Guide/imp/00imp): Data import tool  (YashanDB <-> YashanDB only)
- [*exp*](../../../Tools Guide/exp/00exp): Data export tool
- [*yasrman*](../../../Tools Guide/yasrman/00yasrman): Backup and recovery tool
- [*yasboot*](../../../Tools Guide/yasboot/00yasboot): Operation and maintenance management tool
- [*yaswrap*](../../../Tools Guide/yaswrap/00yaswrap): PL source code encryption tool
- [*ycsctl*](../../../Tools Guide/ycsctl/00ycsctl): YCS management tool
- [*yfscmd*](../../../Tools Guide/yfscmd/00yfscmd): YFS management tool
