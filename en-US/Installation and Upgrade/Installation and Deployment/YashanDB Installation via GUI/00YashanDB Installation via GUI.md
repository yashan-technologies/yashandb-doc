YashanDB provides various deployment forms. The installation process for different forms, especially the initial installation parameter configuration, varies significantly. Please choose the appropriate operating instructions based on actual needs.

- [Standalone (Primary-Standby) Deployment](Standalone (Primary-Standby) Deployment)

    The standalone (primary/standby) deployment installation guide is used to set up a single-instance single-database database management system, suitable for centralized trading business. Refer to the [Database Instance](../../../Product Concepts/Instance Architecture/00Instance Architecture) section on Standalone Deployment to understand the system architecture and capabilities provided by YashanDB standalone (primary/standby).

- [YAC Deployment](YAC Deployment)

    The YAC Deployment installation guide is used to set up a multi-instance single-database database management system, suitable for YAC trading business. Refer to the [Database Instance](../../../Product Concepts/Instance Architecture/00Instance Architecture) section on YAC Deployment to understand the system architecture and capabilities provided by YashanDB YAC.

- [ISC Distributed Cluster Deployment](ISC Distributed Cluster Deployment)

    The ISC Distributed Cluster Deployment installation guide is used to set up a ISC distributed database management system, suitable for distributed analysis business. Refer to the [Database Instance](../../../Product Concepts/Instance Architecture/00Instance Architecture) section on ISC Distributed Cluster Deployment to understand the system architecture and capabilities provided by YashanDB distributed.

Before performing the installation operations, please ensure that you have followed all the items listed in the [Pre-Installation Preparation](../Pre-Installation Preparation/00Pre-Installation Preparation) document in order. Otherwise, it may lead to installation deployment failure or an improperly/stably constructed environment, which may severely impact the business operating in this environment.

Using the web service for installation deployment restricts remote deployment scenarios, that is, the machine that starts the web service must be included in the list of deployment servers.
