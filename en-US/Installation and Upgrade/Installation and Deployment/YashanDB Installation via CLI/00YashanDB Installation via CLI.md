YashanDB offers multiple deployment forms. The installation process varies greatly among different forms, especially in the configuration of initial installation parameters. Please choose the appropriate operation guide based on actual needs.

- [Standalone (Primary-Standby) Deployment](Standalone (Primary-Standby) Deployment)

    The installation guide for standalone (primary/standby) deployment is used to set up a single-instance single-database, primary/standby, or cascade backup, which can serve as a centralized database management system for transaction business. Refer to the [Database Instance](../../../Product Concepts/Instance Architecture/00Instance Architecture) chapter on Standalone Deployment to understand the system architecture and capabilities provided by YashanDB for standalone (primary/standby).

- [YAC Deployment](YAC Deployment)

    The YAC Deployment installation guide is used to set up a multi-instance single-database, which can serve as a database management system for YAC transaction business. Refer to the [Database Instance](../../../Product Concepts/Instance Architecture/00Instance Architecture) chapter on YAC Deployment to understand the system architecture and capabilities provided by YashanDB for YACs.

- [ISC Distributed Cluster Deployment](ISC Distributed Cluster Deployment)

    The ISC Distributed Cluster Deployment installation guide is used to set up a ISC distributed database that can serve as a database management system for distributed analytical business. Refer to the [Database Instance](../../../Product Concepts/Instance Architecture/00Instance Architecture) chapter on ISC Distributed Cluster Deployment to understand the system architecture and capabilities provided by YashanDB for distributed environments.

Before executing the installation operations, please ensure that you have sequentially completed all items listed in the [Pre-Installation Preparation](../Pre-Installation Preparation/00Pre-Installation Preparation) document. Otherwise, it may lead to installation deployment failures or an incorrect/unreliable environment, which can seriously impact the business running in this environment.
