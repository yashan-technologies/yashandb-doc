This section provides guidance and examples for upgrading the YashanDB product from an old version to a new version. The upgrade path must meet the requirement that the version number of the old version is less than that of the new version, and the release date of the old version is earlier than that of the new version.

- [Rolling Upgrade](Rolling Upgrade): The entire database cluster will not be stopped, and the primary database remains available to users.

- [Offline Upgrade](Offline Upgrade): The entire database cluster needs to be stopped, during which it is completely unavailable.
