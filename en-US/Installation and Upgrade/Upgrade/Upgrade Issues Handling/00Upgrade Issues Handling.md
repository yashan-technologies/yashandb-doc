This section describes the rollback methods after an upgrade failure. Once the upgrade is successful, rollback is not possible.

When an exception occurs during the upgrade, users can refer to the following rollback operations to restore the environment. If the rollback still fails, please contact YashanDB technical support for assistance.

- [Rolling Upgrade Rollback](Rolling Upgrade Rollback): Used to handle exceptions that occur during a rolling upgrade.

- [Offline Upgrade Rollback](Offline Upgrade Rollback): Used to handle exceptions that occur during an offline upgrade.
