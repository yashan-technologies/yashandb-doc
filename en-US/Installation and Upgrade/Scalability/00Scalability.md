YashanDB supports dynamic scaling, enabling linear expansion of database service capabilities and resource adjustment without impacting service availability.

- [Standalone primary/standby scaling](Scaling for Standalone Deployment/00Scaling for Standalone Deployment): performs scale-out/scale-in for standby databases or cascade standby databases in Standalone Deployment.

- [YAC scaling](Scaling for YAC Deployment/00Scaling for YAC Deployment): performs scale-out/scale-in for instances within the cluster or standby clusters in YAC Deployment.

- [Distributed cluster scaling](Scaling for Distributed Cluster Deployment/00Scaling for Distributed Cluster Deployment): performs scale-out/scale-in for CN nodes or DN nodes in Distributed Cluster Deployment.

- [ISC distributed cluster scaling](Scaling for ISC Distributed Cluster Deployment/00Scaling for ISC Distributed Cluster Deployment): performs scale-out/scale-in for CN nodes, DN groups, and standby nodes within DN or MN groups in ISC Distributed Cluster Deployment.
