YashanDB supports dynamic scaling, enabling linear expansion of database service capabilities and resource adjustment without impacting service availability.

- [Standalone primary/standby scaling](Scaling for Standalone Deployment/00Scaling for Standalone Deployment): Scaling for the standby database and cascade standby database in Standalone Deployment.

- [YAC scaling](Scaling for YAC Deployment/00Scaling for YAC Deployment): Online scaling of instances within the cluster in YAC Deployment.

- [Distributed cluster scaling](Scaling for Distributed Cluster Deployment/00Scaling for Distributed Cluster Deployment): Allows scaling for CN nodes, DN nodes.

- [ISC distributed cluster scaling](Scaling for ISC Distributed Cluster Deployment/00Scaling for ISC Distributed Cluster Deployment): Allows scaling for CN nodes, DN groups, and standby nodes within DN or MN groups.
