## 23.4.10.100

The following lists the major and notable changes in version 23.4.10.100 of YashanDB compared to version 23.4.9.100. If you discover any changes during your use that are not listed in this document but impact your company's business, please consult our technical support for detailed explanations.

### Upgrade Notes

The following table shows the range of old versions that support offline upgrades to the current version.

|Deployment Form       |Old Version Range                             |
| ---------------------------------- | ------------------------------------------------------------ |
| Standalone Deployment              | 22.2.16 and earlier<br/>23.1.5 and earlier<br/>23.2.13 and earlier<br/>23.3.3 and earlier<br/>23.4.9 and earlier |
| YAC Deployment                     | 23.1.5 and earlier<br/>23.2.13 and earlier<br/>23.3.3 and earlier<br/>23.4.9 and earlier |
| ISC Distributed Cluster Deployment | 23.1.5 and earlier<br/>23.2.12 and earlier<br/>23.3.3 and earlier<br/>23.4.9 and earlier |

### System Parameters

|Category |Parameter Name |Change Item |Old Value |New Value (Meaning) |
| --- | --- | --- | --- | --- |
| Kernal Configuration Parameters | CS_LOGIN_TIMEOUT | NEW PARAMETER | - | Specifies the maximum time (in seconds) that the database waits for the login message from the client tool |
| Kernal Configuration Parameters | LISTENER_LOG_ENABLED | NEW PARAMETER | - | Specifies whether to enable automatic cleanup of listener logs |
| Kernal Configuration Parameters | PLSQL_ACCESS_CACHE_OPT | NEW PARAMETER | - | Specifies whether to enable the PL local variable cache optimization functionality |
