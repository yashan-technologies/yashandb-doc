## 23.5.4.100

The following lists the main and significant changes of YashanDB v23.5.4.100 release compared to v23.5.2.100 release. If you encounter any changes during usage that are not listed in this chapter but have an impact on your business, please contact our technical support for detailed explanation.

### Upgrade Description

The range of old versions that support offline upgrade to the current version is shown in the table below.

| Deployment Form | Range of Old Versions |
|--------------------|---------------------|
| Standalone Deployment | 22.2.16 and earlier<br/>23.1.5 and earlier<br/>23.2.12 and earlier<br/>23.3.3 and earlier<br/>23.4.10 and earlier<br/>23.5.2 and earlier   |
| YAC Deployment | 23.1.5 and earlier<br/>23.2.12 and earlier<br/>23.3.3 and earlier<br/>23.4.10 and earlier<br/>23.5.2 and earlier |
| ISC Distributed Cluster Deployment | 23.1.5 and earlier<br/>23.2.12 and earlier<br/>23.3.3 and earlier<br/>23.4.10 and earlier<br/>23.5.2 and earlier |

### Installation and Upgrade

| Change Item | Change | Content |
| ---------------------- | --------------- | ------------------------------------------------------------ |
| Standalone Deployment | New Feature        | Adds support for branch databases. |

### System Parameters

| Category | Parameter Name | Change Item | Old Value | New Value (Meaning) |
| --- | --- | --- | --- | --- |
| Kernel Configuration Parameter | ENABLE_BRANCH | New Parameter | - | Indicates whether the current database is a branch database. |
| Kernel Configuration Parameter | YASFS_AS_DEFAULT | New Parameter | - | Specifies whether the default file creation path is a YASFS path. |

### System Views

| View Name | Change Item | New Value (Meaning) |
| --- | --- | --- |
| DBA_AI_MODELS | New View | Displays information about all registered AI models. |
| DBA_BRANCH_RSRC_PLAN_DIRECTIVES | New View | Displays information about resource plan directives for all branch databases. |
| GV$RSRC_BRANCH <br/> V$RSRC_BRANCH | New View | Displays resource usage of each branch in the branch database environment. |
