## 23.4.8.100

The following lists the major and notable changes in version 23.4.8.100 of YashanDB compared to version 23.4.7.100. If you discover any changes during your use that are not listed in this document but impact your company's business, please consult our technical support for detailed explanations.

### Upgrade Notes

The following table shows the range of old versions that support offline upgrades to the current version.

|Deployment Form       |Old Version Range                             |
| ---------------------------------- | ------------------------------------------------------------ |
| Standalone Deployment              | 22.2.16 and earlier<br/>23.1.5 and earlier<br/>23.2.13 and earlier<br/>23.3.3 and earlier<br/>23.4.7 and earlier |
| YAC Deployment                     | 23.1.5 and earlier<br/>23.2.13 and earlier<br/>23.3.3 and earlier<br/>23.4.7 and earlier |
| ISC Distributed Cluster Deployment | 23.1.5 and earlier<br/>23.2.12 and earlier<br/>23.3.3 and earlier<br/>23.4.7 and earlier |

### System Parameters

|Category |Parameter Name |Change Item |Old Value |New Value (Meaning) |
| --- | --- | --- | --- | --- |
| Kernal Configuration Parameters | CURSOR_SHARING | CHANGED Value Range | * SIMILAR implies implicit partial constant replacement and standardization<br />*  FORCE implies explicit constant replacement and standardization | [EXACT, FORCE]<br />* FORCE means enabling explicit literal replacement and standardization<br />* SIMILAR is obsolete, effect is the same as EXACT (not enabled) |
