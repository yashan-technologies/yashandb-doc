YashanDB provides a series of system views that present users with various static data about the database and real-time dynamic data during operation. And in adition, YashanDB (mysql Mode) also support **INFORMATION_SCHEMA**, *mysql*, **PERFORMANCE_SCHEMA** system views.

*   INFORMATION_SCHEMA：
The INFORMATION_SCHEMA views are system-provided views that begin with INFORMATION_SCHEMA. They are used to record metadata information in mysql mode.

*   MYSQL：
The MySQL views provided by the system, starting with MYSQL., are used to display information related to the entire database and user privileges in mysql mode, which includes object information for all users.

*   PERFORMANCE_SCHEMA：
The PERFORMANCE_SCHEMA views are system-provided views that begin with PERFORMANCE_SCHEMA. They are used to display system variables in mysql mode.
