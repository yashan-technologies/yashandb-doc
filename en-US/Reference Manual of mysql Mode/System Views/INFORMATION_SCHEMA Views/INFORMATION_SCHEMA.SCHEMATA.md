This view displays information related to the database.

|Field |Type |Description |
|----------------------------|-------------|-----------------------|
| CATALOG_NAME               | VARCHAR(3)   | The catalog name of the schema, this value is always def |
| SCHEMA_NAME                | VARCHAR(64)  | The name of the schema         |
| DEFAULT_CHARACTER_SET_NAME | VARCHAR(32)  | The default character set name of the schema |
| DEFAULT_COLLATION_NAME     | VARCHAR(32)  | The default collation name of the schema |
| SQL_PATH                   | VARCHAR(1)   | This value is always NULL      |
