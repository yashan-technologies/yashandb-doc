```ebnf+diagram
string_to_array::= STRING_TO_ARRAY "(" src_string "," split_string [ "," replace_string ] ")"
```

The STRING_TO_ARRAY function splits the string src_string using split_string as the delimiter to generate an array. If a split member matches replace_string, that member is replaced with NULL before generating the array ([array variable](../../All Manuals/Development Guide/PL Reference Manual/PL Language Fundamentals/Variables/Collection Variables), [array object](../../All Manuals/Development Guide/PL Reference Manual/PL Objects/User-Defined Types), [array type](../../All Manuals/Development Guide/SQL Reference Manual/Data Types/User-Defined Types) and returned.

This function follows these rules:

* This function does not support vectorization calculation.
* The final returned array is an implicitly defined array variable, with a maximum member count limit equal to the INT type limit (2147483647), and the member data type is VARCHAR(n), where n is the length of the longest member generated in the array.
* This function can be used in PL as an array initialization function, but there are limitations on the assignment object. The assignment object must be able to accommodate the array generated by this function, meaning its member limit should be greater than or equal to the member limit of the returned array, and member length should be greater than or equal to the length of the returned array.

**src_string**

[General expression](../../All Manuals/Development Guide/SQL Reference Manual/General SQL Syntax/expr), must be of character type or another type that can be implicitly converted to character type (LOB types support implicit conversion). When src_string is NULL, the function returns NULL.

**split_string**

[General expression](../../All Manuals/Development Guide/SQL Reference Manual/General SQL Syntax/expr), must be of character type or another type that can be implicitly converted to character type (LOB types support implicit conversion). When split_string is NULL, the function splits src_string by each individual character.

**replace_string**

[General expression](../../All Manuals/Development Guide/SQL Reference Manual/General SQL Syntax/expr), must be of character type or another type that can be implicitly converted to character type (LOB types support implicit conversion).

***Example***

```sql
SET serveroutput ON

DECLARE
  TYPE arr_type IS VARRAY(10) OF CHAR(10);
  a arr_type;
BEGIN
  a := STRING_TO_ARRAY('a,b,c,d,e', ',');
  FOR i IN 1 .. a.COUNT LOOP
    DBMS_OUTPUT.PUT_LINE(i||' is: '||a(i));
  END LOOP;
END;
/
1 is: a
2 is: b
3 is: c
4 is: d
5 is: e

DECLARE
  TYPE arr_type IS VARRAY(10) OF CHAR(5);
  -- Use STRING_TO_ARRAY FUNCTION TO initialize the array
  a arr_type := STRING_TO_ARRAY(',a,b,c,', ',','b');
BEGIN
  FOR i IN 1 .. a.COUNT LOOP
    IF a(i) IS NULL THEN
	  DBMS_OUTPUT.PUT_LINE(i||' is NULL');
    ELSE
      DBMS_OUTPUT.PUT_LINE(i||' is: '||a(i));
    END IF;
  END LOOP;
END;
/
1 is NULL
2 is: a
3 is NULL
4 is: c
5 is NULL
```
