The DBMS_CM package provides a set of built-in stored procedures/functions for *yasboot* to call for maintaining metadata information of a distributed cluster in specific functionality scenarios.

> **Caution**:
>
> - Users are advised not to call the DBMS_CM advanced package directly to avoid uncontrollable effects.
>
> - The DBMS_CM advanced package is applicable only for ISC Distributed Cluster Deployment.

## CREATE\_CLUSTER

```plsql
DBMS_CM.CREATE_CLUSTER(
   CLUSTER_ID   IN VARCHAR,
   CLUSTER_NAME IN VARCHAR,
   MN_HOST      IN VARCHAR
   );
```

This function is used to create cluster-level metadata information of a distributed cluster, and the corresponding information will be written to the buffer and system tables.

|Parameter |Description |
| -------- | ------------------------------------------------------------ |
|CLUSTER_ID    | The unique UUID of the distributed cluster, automatically generated by *yasboot* during deployment. |
|CLUSTER_NAME  | The name of the distributed cluster.                        |
|MN_HOST       | The server address of the first MN node during initial deployment. |

## UPDATE\_CLUSTER\_ID

```plsql
DBMS_CM.UPDATE_CLUSTER_ID();
```

This function is used to update cluster-level metadata information of a distributed cluster by loading the corresponding information from the configuration parameter file into memory and system tables.

## CREATE\_GROUP

```plsql
DBMS_CM.CREATE_GROUP(
   GROUP_ID   OUT INT,
   GROUP_NAME IN VARCHAR,
   GROUP_TYPE IN VARCHAR
   );
```

This function is used to create node group-level metadata information for the distributed cluster, and the corresponding information will be written to the buffer and system tables.

|Parameter |Description |
| -------- | ------------------------------------------------------------ |
|GROUP_ID      | The ID of the node group.                                  |
|GROUP_NAME    | The name of the node group.                                |
|GROUP_TYPE    | The type of node group, mainly including: CN (Coordinating Node), DN (Data Node), MN (Management Node). |

## DELETE\_GROUP

```plsql
DBMS_CM.DELETE_GROUP(
   GROUP_ID   IN INT,
   IS_FORCE   IN BOOL
   );
```

This function is used to delete node group-level metadata information of the distributed cluster from the system tables and buffer.

|Parameter |Description |
| -------- | ------------------------------------------------------------ |
|GROUP_ID      | The ID of the node group.                                  |
|IS_FORCE      | Whether to forcefully delete the group if the specified node group is the last/only one of its type. |

## CREATE\_NODE

```plsql
DBMS_CM.CREATE_NODE(
   GROUP_NODE_ID    OUT INT,
   ENDPOINT         OUT INT,
   GROUP_ID         IN  INT,
   NODE_TYPE        IN  VARCHAR,
   HOST             IN  VARCHAR,
   SERVICE_ADDR     IN  VARCHAR,
   REPLICA_ADDR     IN  VARCHAR,
   DATA_ADDR        IN  VARCHAR,
   IS_SYNC_METADATA IN  BOOL
   );
```

This function is used to create node-level metadata information for the distributed cluster, and the related information will be written to the buffer and system tables.

|Parameter |Description |
| -------- | ------------------------------------------------------------ |
|GROUP_NODE_ID   | The ID of the node within the group.                       |
|ENDPOINT        | The endpoint of the node.                                  |
|GROUP_ID        | The ID of the node group.                                  |
|NODE_TYPE       | The type of the node.                                     |
|HOST            | The server address of the node.                            |
|SERVICE_ADDR    | The service address of the node.                           |
|REPLICA_ADDR    | The replication address of the node.                       |
|DATA_ADDR       | The data transmission address of the node.                |
|IS_SYNC_METADATA | Whether to synchronize the metadata information of the first node of the DN group or the newly expanded CN node. |

## DELETE\_NODE

```plsql
DBMS_CM.DELETE_NODE(
   GROUP_ID      IN INT,
   GROUP_NODE_ID IN INT
   );
```

This function is used to delete node-level metadata information of the distributed cluster from the buffer and system tables.

|Parameter |Description |
| -------- | ------------------------------------------------------------ |
|GROUP_ID        | The ID of the node group.                                  |
|GROUP_NODE_ID   | The ID of the node within the group.                       |

## UPDATE\_DATA\_URL

```plsql
DBMS_CM.UPDATE_DATA_URL(
   GROUP_ID      IN INT,
   GROUP_NODE_ID IN INT,
   URL           IN VARCHAR,
   DATA_ADDR     IN VARCHAR,
   REPLICA_ADDR  IN VARCHAR,
   DATA_PATH     IN VARCHAR,
   HOST          IN VARCHAR
   );
```

This function is used to update the URL information and data path of the nodes in the distributed cluster, and the corresponding information will be written to the buffer and system tables.

|Parameter |Description |
| -------- | ------------------------------------------------------------ |
|GROUP_ID        | The ID of the node group.                                  |
|GROUP_NODE_ID   | The ID of the node within the group.                       |
|SERVICE_ADDR    | The service address.                                       |
|DATA_ADDR       | The data address.                                         |
|REPLICA_ADDR    | The replication address.                                   |
|DATA_PATH       | The data path.                                            |
|HOST            | The server address.                                       |

## UPDATE\_DATA\_PATH

```plsql
DBMS_CM.UPDATE_DATA_URL(
   GROUP_ID      IN INT,
   GROUP_NODE_ID IN INT,
   DATA_PATH     IN VARCHAR
   );
```

This function is used to update the data path of the nodes in the distributed cluster, and the corresponding information will be written to the buffer and system tables.

|Parameter |Description |
| -------- | ------------------------------------------------------------ |
|GROUP_ID        | The ID of the node group.                                  |
|GROUP_NODE_ID   | The ID of the node within the group.                       |
|DATA_PATH       | The data path of the node.                                 |

## TRIGGER\_PUSH

```plsql
DBMS_CM.TRIGGER_PUSH();
```

This function is used to actively trigger the synchronization mechanism when the metadata of the distributed cluster is not synchronized.
