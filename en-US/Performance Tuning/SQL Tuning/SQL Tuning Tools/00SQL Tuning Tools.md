The tools related to SQL tuning mainly include explain, autotrace, hint, and outline. Among them, explain and autotrace are used to analyze execution plans, while hint and outline can directly act on SQL statements.

- For an introduction to the use of hints, please refer to [Hint](Hint).

- For an introduction to the use of explain, please refer to [Execution Plans](../../Performance Tuning Features and Tools/Execution Plans).

- For an introduction to the use of autotrace, please refer to [AUTOTRACE](../../Performance Tuning Features and Tools/AUTOTRACE).

- For an introduction to the use of outlines, please refer to [Outline](Outline).
