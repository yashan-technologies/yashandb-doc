YashanDB已与多家服务器和操作系统厂商实现了兼容认证，具体可查阅官网所列[YashanDB兼容列表](https://yashandb.com/compatible_certified_partner)。

本文将列示在部署不同形态的YashanDB时，我们所建议或要求的环境相关配置。后续手册中所展示的操作步骤和示例命令也主要适配于这些配置环境，若在其他兼容环境中的实际步骤、命令等存在细微差异，建议参考对应操作系统的官方指引或联系系统服务商解决。

>  **Caution**:
>
> 若使用虚拟机安装YashanDB，必须将虚拟机的硬盘设置为独立-永久模式（例如，VMware中需在虚拟机的【硬盘高级设置】中勾选模式为【独立】-【永久】，具体配置方法请以各虚拟机平台实际为准），否则在断电等场景下会出现磁盘文件破坏的情况。

## 存储设备配置

在部署共享集群或分布式集群时，除服务器外，还需准备专门的存储设备。其中，共享集群要求至少准备1台SAN共享存储或1套可搭建NVMe-oF分布式存储的NVMe SSD；分布式集群则要求1套可搭建NVMe-oF分布式存储的NVMe SSD。

<span id="Storage" name="Storage"></span>

### SAN共享存储 

仅共享集群部署可能会使用到SAN共享存储。

|  项目| 推荐配置|
| ---- | ------------------------------------------------------------ |
| 硬盘 | SSD、HDD均可，品牌和介质不得交叉组合                      |
| LUN  | 4个或6个LUN及以上，分为系统盘和数据盘：<br/>* 系统盘：3个或5个LUN，容量1G及以上（当系统盘仅规划1个LUN且其AU Size配置需为32M时，容量至少为2G）<br/>* 数据盘：1个LUN及以上，容量50G及以上 |
| 接口 | 存储设备及操作系统支持Direct IO，支持512字节内存对齐和IO大小对齐<br>存储设备支持通过 `pread64`、`pwrite64` 接口一次性读写512字节整倍数，<br/>即支持一次性读写如下所有大小：512字节、1024字节、1536字节...32M |
| 协议 | 如需使用[基于SCSI持久预留的I/O Fencing](../../../数据库管理/集群管理/IO Fencing/基于SCSI持久预留的IO Fencing.md)，要求支持SCSI-3协议（及以上）和SPC-3命令集（SCSI Primary Commands-3，及以上），且支持类型5的持久预留（Write Exclusive – Registrants Only）|

> **Caution**:
>
> 共享集群（使用SAN共享存储时）支持两种[I/O Fencing](../../../数据库管理/集群管理/IO Fencing/00IO Fencing)方法，推荐使用[基于SCSI持久预留的I/O Fencing](../../../数据库管理/集群管理/IO Fencing/基于SCSI持久预留的IO Fencing.md)，但该方法对共享存储的能力有一定要求。在安装部署过程会自动调用[fenceScsiCheck脚本](../../../数据库管理/集群管理/IO Fencing/基于SCSI持久预留的IO Fencing.md#fenceScsiCheck_usage)检测共享存储等设备/环境是否符合要求。
>
> fenceScsiCheck脚本检测报错时，并不会阻塞安装部署，但共享集群的I/O Fencing方法将被配置为[在途I/O保护算法](../../../数据库管理/集群管理/IO Fencing/在途IO保护算法.md)。如仍需使用基于SCSI持久预留的I/O Fencing，请根据相应的错误提示进行调整。
>
> 如果不使用基于SCSI持久预留的I/O Fencing，共享集群存在脑裂风险。

### NVMe-oF分布式存储 

共享集群部署可能会使用NVMe-oF分布式存储；分布式集群部署要求必须使用NVMe-oF分布式存储。

|  项目| 推荐配置|
| ---- | ------------------------------------------------------------ |
| 硬盘 | NVMe SSD，品牌不得交叉组合              |
| NVMe-oF盘 | 4个或6个NVMe-oF盘及以上，分为系统盘和数据盘：<br/>* 系统盘：3个或5个命名空间，容量1G及以上（当系统盘仅规划1个NVMe-oF盘且其AU Size配置需为32M时，容量至少为2G）<br/>* 数据盘：1个命名空间及以上，容量50G及以上 |
| 传输类型 | 支持以下类型：<br/>* NVMe over TCP：要求Linux内核版本为5.0及以上<br/>* NVMe over RDMA：要求使用RDMA网卡并正确安装相应的驱动 |

> **Note**:
>
> 共享集群（使用 NVMe-oF分布式存储时）仅支持[在途I/O保护算法](../../../数据库管理/集群管理/IO Fencing/在途IO保护算法.md)。
>
> 但在安装部署过程仍会自动调用[fenceScsiCheck脚本](../../../数据库管理/集群管理/IO Fencing/基于SCSI持久预留的IO Fencing.md#fenceScsiCheck_usage)检测是否符合基于SCSI持久预留的I/O Fencing硬件要求，检测报错不会阻塞安装部署。
