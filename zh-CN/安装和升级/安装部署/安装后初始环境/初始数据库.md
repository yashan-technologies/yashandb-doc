## （可选）删除初始数据库（yashan模式非容器数据库）

初始数据库可能无法满足生产环境的实际需要，可按需将其删除并创建生产数据库。

该操作不适用于存算一体分布式集群部署和mysql模式的单机部署。

1. 以sys用户登录数据库。
    
    ```shell
    # 本地登录时可以使用操作系统认证方式登录
    $ yasql / as sysdba

    # 使用密码认证方式登录
    $ yasql sys/********@192.168.1.2:1688

    YashanDB SQL Enterprise Edition Release {version_number} x86_64

    Connected to:
    YashanDB Server Enterprise Edition Release {version_number} x86_64 - Linux

    SQL> 
    ```
    

2. 使用[SHUTDOWN](../../../开发手册/SQL参考手册/SQL语句/SHUTDOWN)语句关闭初始数据库。

3. 重启实例至NOMOUNT模式，具体操作请参考[数据库实例启停](../../../数据库管理/实例管理/实例启停)。

4. 执行[DROP DATABASE](../../../开发手册/SQL参考手册/SQL语句/DROP DATABASE)语句删除初始数据库。

5. 执行[CREATE DATABASE](../../../开发手册/SQL参考手册/SQL语句/CREATE DATABASE)语句新建数据库。

6. （可选）新建用户并授予合适的权限，具体操作请参考[管理用户](../../../产品安全/身份标识与鉴别/管理用户.md)、[特权与角色管理](../../../产品安全/数据访问控制/特权与角色管理/00特权与角色管理.md)。

## 创建PDB（租户模式） 

若部署为容器数据库（指定了--enable-pluggable-database），则还需创建PDB。  

1. 以sys用户登录YashanDB，即登录根容器。

2. （可选）新建用户并授予合适的权限，具体操作请参考[CDB中的用户与角色体系](../../../产品安全/CDB中的用户与角色体系.md)、[管理用户](../../../产品安全/身份标识与鉴别/管理用户.md)以及[特权与角色管理](../../../产品安全/数据访问控制/特权与角色管理/00特权与角色管理.md)。

3. （可选）以新用户登录根容器。

4. 执行[CREATE PLUGGABLE DATABASE](../../../开发手册/SQL参考手册/SQL语句/CREATE PLUGGABLE DATABASE.md)语句新建PDB。

## 新建业务数据库（mysql模式）

1. 以sys用户登录数据库，若为容器数据库则应登录目标PDB。

2. （可选）新建用户并授予合适的权限，具体操作请参考[管理用户](../../../mysql模式参考手册/产品安全/管理用户.md)、[权限授予与收回](../../../mysql模式参考手册/产品安全/特权管理/权限授予与收回.md)。

3. （可选）以新用户重新登录。  

4. 执行[CREATE DATABASE](../../../mysql模式参考手册/SQL参考手册/SQL语句/CREATE DATABASE)语句新建数据库，后续使用中，可通过[USE](../../../mysql模式参考手册/SQL参考手册/SQL语句/USE)语句选择某个会话需要操作的数据库。

## 开始使用YashanDB

在开发人员或其他用户能使用YashanDB前，系统管理员还需执行下述相关操作：

- 如需依照本手册学习使用YashanDB，请先创建sales样例用户并授予合适的权限。

    :::tabs
    == 默认示例场景

```sql 
CREATE USER sales IDENTIFIED BY 'Yr_pswd0';
GRANT DBA TO sales;
```
    == 租户模式

```shell
-- 在根容器上创建全局DBA样例用户c##sales
SQL> CREATE USER c##sales IDENTIFIED BY 'Yr_pswd0';
SQL> GRANT DBA TO c##sales CONTAINER = ALL;
SQL> exit

# 登录目标PDB，创建sales样例用户
$ yasql c##sales/********@192.168.1.2:1688/pdb1
SQL> CREATE USER sales IDENTIFIED BY 'Yr_pswd0';
SQL> GRANT DBA TO sales;
```

    == mysql模式

```sql
CREATE USER sales IDENTIFIED BY 'Yr_pswd0';
GRANT DBA TO sales;
GRANT ALL ON *.* to sales;
conn "sales"/********
CREATE DATABASE IF NOT EXISTS sales DEFAULT CHARACTER SET `utf8` DEFAULT collate `utf8mb4_general_ci`;
use sales;
```

    :::

- 参考[数据库管理](../../../数据库管理/实例管理/00实例管理.md)的各项数据库管理内容，例如建立表空间管理体系。

- 参考[产品安全](../../../产品安全/YashanDB安全体系概述)所述建立数据库安全体系。

- 采用共享集群部署或分布式集群部署时，还需参考[集群管理](../../../数据库管理/集群管理/00集群管理.md)的各项管理内容。

- 若部署为容器数据库（指定了--enable-pluggable-database命令选项），还需参考[租户管理](../../../数据库管理/租户管理/00租户管理.md)。
