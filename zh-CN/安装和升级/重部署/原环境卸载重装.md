通常，执行原环境卸载重装时数据库安装环境已满足产品要求，且不涉及初始环境及相关配置变更、数据库版本变化，即无需重复执行安装前的准备工作。

## 步骤1：卸载YashanDB服务端

在卸载YashanDB前，建议您先进行[数据备份](../../数据库管理/备份恢复/00备份恢复)，确保数据的完整性和安全性，以便需要时拥有完整的数据副本进行还原或迁移。

1. 单机一主一备部署或存算一体分布式高可用部署（DN组内节点为一主一备），请先检查并关闭yasom仲裁选主：

    ```shell
    $ yasboot election config show -c yashandb
    group 1
    Protection Mode: MAXIMUM PROTECTION
    Members:
        [1-1:1] - Primary database
        [1-2:2] - Physical standby database

    ……

    Automatic Failover: Enabled in Zero Data Loss Mode 

    # Enabled表示已开启yasom仲裁选主，需将其关闭再进行后续操作
    $ yasboot election enable off -c yashandb
    ```

2. 卸载数据库。

    ```shell
    $ yasboot cluster clean --cluster yashandb --purge
    ```

3. 卸载yasom与yasagent。

    ```shell
    $ yasboot package uninstall --cluster yashandb
    ```

    > **Note**:
    >
    > 若启用过[资源管理](../../数据库管理/资源管理/00资源管理)的CPU管理功能，本命令中须使用`-t`参数才能清理CPU资源管理功能的开机自启动配置。

## 步骤2：清理环境

1. 采用共享集群部署时，必须清理（或归档）安装路径下的\<集群名>.toml和hosts.toml文件，否则重装时可能会出现YAS-05528报错。

2. 若为23.4.x.x及以上版本的共享集群，还需额外执行以下清理操作。

    
- 清理残留进程：在每个服务器上执行如下命令清理ycsrootagent进程。

  ```shell
  $ sudo pkill -9 ycsrootagent
  ```

- 清理残留VIP：如果规划了[VIP](../安装部署/安装前准备/服务器准备.html#vip_planning)，需在每个服务器上执行如下命令清理VIP。

  ```shell
  # IP地址、子网掩码以及网卡名称均为示例值，请替换为实际值

  # 1. 获取网卡信息，在显示结果中找到VIP所在网卡的名称
  $ ip addr show
  2: ens192: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc mq state UP group default qlen 1000
      inet 192.168.1.62/24 scope global ens192
        valid_lft forever preferred_lft forever

  # 2. 清理残留VIP
  $ sudo ip addr del 192.168.1.62/24 dev ens192
  ```


## 步骤3：重新安装YashanDB服务端

1. 如需调整安装环境，可参考[安装前准备](../安装部署/安装前准备/00安装前准备)按需调整相应配置。

2. 选择合适的方法重新[安装YashanDB服务端](../安装部署/00安装部署)。
