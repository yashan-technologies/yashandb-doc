本视图显示存算一体分布式集群中所有节点的CPU资源管理的汇总信息。

|  字段| 类型| 说明|
|----------------| --- | --- |
| GROUP\_ID | INTEGER | 组ID |
| GROUP\_NODE\_ID | INTEGER | 组内节点ID |
| RESNAME        | VARCHAR(256) | 资源组 |
| USER           | VARCHAR(256) | 用户态 |
| SYSTEM         | VARCHAR(256) | 系统态 |
| NR\_PERIODS    | VARCHAR(256)| 周期 |
| NR\_THROTTLED  | VARCHAR(256) | 阻断次数 |
| THROTTLED\_TIME | VARCHAR(256) | 阻断时间|
