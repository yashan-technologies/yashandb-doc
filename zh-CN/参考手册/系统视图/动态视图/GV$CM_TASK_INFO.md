本视图显示CM模块存储的TASK INFO信息。

|  字段| 类型| 说明|
| --- | --- | --- |
| GROUP_ID      | NUMBER     | 组ID |
| GROUP_NODE_ID | NUMBER     | 组内节点ID |
| INST_ID       | NUMBER      | 实例ID|
| TASK\_TYPE | VARCHAR(16) | 任务名字 |
| SEND\_TIMES | INTEGER | 发送次数 |
| TASK\_INFO | VARCHAR(256) | 任务消息 |
| TARGET\_NODES | VARCHAR(128) | 目标节点 |
