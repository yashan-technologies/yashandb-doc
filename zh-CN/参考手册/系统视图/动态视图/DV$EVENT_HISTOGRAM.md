本视图显示各[等待事件](../../等待事件)从建库至今的等待次数、最大等待时间和总等待时间的直方图，等待时间单位为毫秒。

|  字段| 类型| 说明|
| --- | --- | --- |
| GROUP\_ID | INTEGER | 组ID |
| GROUP\_NODE\_ID | INTEGER | 组内节点ID |
| EVENT\_ID | INTEGER | 等待事件ID |
| EVENT | VARCHAR(32) | 等待事件名称 |
| WAIT\_TIME\_MILLI | BIGINT | 对应事件的等待时间分布，根据该值确定等待事件计入直方图的具体时间段（匹配时间段的右边界），时间段包括`(0,1)`、`[1,2)`、`[2,4)`、`[4,8)`、……、`[2<sup>n-1</sup>,2<sup>n</sup>)`、……、`[2<sup>21</sup>,2<sup>22</sup>)`和`[2<sup>22</sup>,∞)`，单位为毫秒<br/>例如该值为2表示当前事件计入直方图的`[1,2)`区间 |
| WAIT\_COUNT | BIGINT | 表示对应事件的等待时间分布在当前时间段的次数 |
| LAST\_UPDATE\_TIME | TIMESTAMP(6) | 上一次获取当前视图数据的时间，即最后一次对应事件的等待时间分布在当前时间段的结束时间戳 |
