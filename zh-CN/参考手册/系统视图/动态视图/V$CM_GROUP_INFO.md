本视图显示CM模块存储的GROUP INFO信息列表。

|  字段| 类型| 说明|
| --- | --- | --- |
| TYPE| VARCHAR(16) | 组类型，例如CN、DN等 |
| ID | INTEGER | 组ID |
| NAME| VARCHAR(64) | 组名 |
| VERSION | INTEGER | 组静态信息版本号 |
| NEXT\_NODE\_ID | INTEGER | 组中下一个节点的ID |
| CREATE\_TIME | TIMESTAMP(6) | 组创建时间 |
| LAST\_UPDATE\_TIME | TIMESTAMP(6) | 组信息最后更新时间 |
