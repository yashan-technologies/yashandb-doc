本视图显示AWR存储库中捕获的历史SQL执行计划。该视图与DBA_HIST_SQLSTAT视图一起使用，可按时间顺序查看历史SQL的执行计划情况。

| 字段  | 类型  | 说明 |
| --- | --- | --- |
| DBID | NUMBER | 数据库ID |
| SQL_ID | VARCHAR(13) | SQL标识符 |
| PLAN_HASH_VALUE | NUMBER | 执行计划哈希值 |
| ID | NUMBER | 计划行ID |
| OPERATION | VARCHAR(30) | 操作名称 |
| OPTIONS | VARCHAR(30) | 操作选项 |
| OBJECT_NODE | VARCHAR(128) | 对象节点 |
| OBJECT# | NUMBER | 对象编号 |
| OBJECT_OWNER | VARCHAR(128) | 对象所有者 |
| OBJECT_NAME | VARCHAR(128) | 对象名称 |
| OBJECT_ALIAS | VARCHAR(261) | 对象别名 |
| OBJECT_TYPE | VARCHAR(20) | 对象类型 |
| OPTIMIZER | VARCHAR(20) | 优化器模式 |
| PARENT_ID | NUMBER | 父操作ID |
| DEPTH | NUMBER | 深度 |
| POSITION | NUMBER | 位置 |
| SEARCH_COLUMNS | NUMBER | 搜索列数 |
| COST | NUMBER | 成本 |
| CARDINALITY | NUMBER | 基数 |
| BYTES | NUMBER | 字节数 |
| OTHER_TAG | VARCHAR(35) | 其他标签 |
| PARTITION_START | VARCHAR(64) | 分区起始 |
| PARTITION_STOP | VARCHAR(64) | 分区结束 |
| PARTITION_ID | NUMBER | 分区ID |
| OTHER | VARCHAR(4000) | 其他信息 |
| CPU_COST | NUMBER | CPU成本 |
| IO_COST | NUMBER | IO成本 |
| TEMP_SPACE | NUMBER | 临时空间 |
| ACCESS_PREDICATES | VARCHAR(4000) | 访问谓词 |
| FILTER_PREDICATES | VARCHAR(4000) | 过滤谓词 |
| PROJECTION | VARCHAR(4000) | 投影列 |
| TIME | NUMBER | 预计时间 |
| QBLOCK_NAME | VARCHAR(128) | 查询块名称 |
| REMARKS | VARCHAR(4000) | 备注 |
| TIMESTAMP | DATE | 时间戳 |
