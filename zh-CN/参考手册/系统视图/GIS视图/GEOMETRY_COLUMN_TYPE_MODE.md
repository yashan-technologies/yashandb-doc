本视图显示当前用户可访问的所有对子类型有限制条件的ST_GEOMETRY类型的列信息。

|  字段| 类型| 说明|
| --- |-------------|-------------------------------------------------------------------------------------|
| OWNER | VARCHAR(64)   | 该列所在表的所有者用户名                                              |
| TABLE_NAME   | VARCHAR(64)   | 该列所在的表名                                                    |
| COLUMN_NAME  | VARCHAR(64)   | 列名                                                |
| SUBTYPE      | VARCHAR(18)   | 列数据的子类型，POINT等                                      |
| HAS_Z        | TINYINT        | 列数据是否包含Z轴                                      |
| HAS_M        | TINYINT       | 列数据是否包含M轴                                            |
| SRID         | INTEGER   | 列数据的空间参考系标识号 |
