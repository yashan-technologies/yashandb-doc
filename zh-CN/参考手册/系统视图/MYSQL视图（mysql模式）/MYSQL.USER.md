本视图显示所有用户的权限信息。

|  字段| 类型| 说明|
| --- | --- | --- |
| HOST | VARCHAR(60) | 数据库实例所在服务器的名称 |
| USER | VARCHAR(64) | 数据库用户的用户名 |
| SELECT_PRIV | VARCHAR(1) | SELECT权限 |
| INSERT_PRIV | VARCHAR(1) | INSERT权限 |
| UPDATE_PRIV | VARCHAR(1) | UPDATE权限 |
| DELETE_PRIV | VARCHAR(1) | DELETE权限 |
| CREATE_PRIV | VARCHAR(1) | CREATE权限 |
| DROP_PRIV | VARCHAR(1) | DROP权限 |
| RELOAD_PRIV | VARCHAR(1) | RELOAD权限 |
| SHUTDOWN_PRIV | VARCHAR(1) | SHUTDOWN权限 |
| PROCESS_PRIV | VARCHAR(1) | PROCESS权限 |
| FILE_PRIV | VARCHAR(1) | FILE权限 |
| GRANT_PRIV | VARCHAR(1) | GRANT权限 |
| REFERENCES_PRIV | VARCHAR(1) | REFERENCES权限 |
| INDEX_PRIV | VARCHAR(1) | INDEX权限 |
| ALTER_PRIV | VARCHAR(1) | ALTER权限 |
| SHOW_DB_PRIV | VARCHAR(1) | SHOW DB权限 |
| SUPER_PRIV | VARCHAR(1) | SUPER权限 |
| CREATE_TMP_TABLE_PRIV | VARCHAR(1) | CREATE TMP TABLE权限 |
| LOCK_TABLES_PRIV | VARCHAR(1) | LOCK TABLES权限 |
| EXECUTE_PRIV | VARCHAR(1) | EXECUTE权限 |
| REPL_SLAVE_PRIV | VARCHAR(1) | REPL SLAVE权限 |
| REPL_CLIENT_PRIV | VARCHAR(1) | REPL CLIENT权限 |
| CREATE_VIEW_PRIV | VARCHAR(1) | CREATE VIEW权限 |
| SHOW_VIEW_PRIV | VARCHAR(1) | SHOW VIEW权限 |
| CREATE_ROUTINE_PRIV | VARCHAR(1) | CREATE ROUTINE权限 |
| ALTER_ROUTINE_PRIV | VARCHAR(1) | ALTER ROUTINE权限 |
| CREATE_USER_PRIV | VARCHAR(1) | CREATE USER权限 |
| EVENT_PRIV | VARCHAR(1) | EVENT权限 |
| TRIGGER_PRIV | VARCHAR(1) | TRIGGER权限 |
| CREATE_TABLESPACE_PRIV | VARCHAR(1) | CREATE TABLESPACE权限 |
| SSL_TYPE | VARCHAR(0) | SSL/TLS协议类型 |
| SSL_CIPHER | VARCHAR(0) | SSL/TLS加密算法或密码套件 |
| X509_ISSUER | VARCHAR(0) | X.509证书中的一个字段，用于表示证书颁发机构（CA）的身份信息 |
| X509_SUBJECT | VARCHAR(0) | X.509证书中的一个字段，用于表示证书持有者（Subject）的身份信息 |
| MAX_QUESTIONS | BIGINT | 最大查询次数 |
| MAX_UPDATES | BIGINT | 最大更新次数 |
| MAX_CONNECTIONS | BIGINT | 最大连接数（所有用户） |
| MAX_USER_CONNECTIONS | BIGINT | 最大连接数（单个用户）|
| PLUGIN | VARCHAR(64) | 插件 |
| AUTHENTICATION_STRING | VARCHAR(4000) | 加密密码或身份验证字符串 |
| PASSWORD_EXPIRED | VARCHAR(1) | 密码是否已过期 |
| PASSWORD_LAST_CHANGED | TIMESTAMP | 最近一次修改密码的时间 |
| PASSWORD_LIFETIME | BIGINT | 密码的有效期 |
| ACCOUNT_LOCKED | VARCHAR(1) | 账户是否被锁定 |
