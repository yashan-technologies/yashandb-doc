## 23.4.2.100

以下将列出YashanDB所发布23.4.2.100版本相对于23.4.1.100版本的主要和明显的变化点，如您在使用过程中发现未在本文中列出，但对贵公司业务产生了影响的变化点，请咨询我们的技术支持获取详细解释说明。

### 升级说明

支持离线升级至当前版本的旧版本范围如下表所示。

|  部署形态| 旧版本范围|
|--------------------|---------------------|
| 单机部署 |22.2.16及以前<br/>23.1.5及以前<br/>23.2.12及以前<br/>23.3.3及以前<br/>23.4.1   |
| 共享集群部署 | 23.1.5及以前<br/>23.2.12及以前<br/>23.3.3及以前<br/>23.4.1 |
| 存算一体分布式集群部署 | 23.1.5及以前<br/>23.2.12及以前<br/>23.3.3及以前<br/>23.4.1 |

### 安装和升级

|  变化项| 变化| 内容|
|--------|------------|---------------------|
| 命令行交互式部署 | 适用范围扩展 | 支持使用交互式安装yasboot init命令部署共享集群，涉及以下参数：<br/>* -t, --yas-type：指定数据库部署的部署形态，可选值[SE&#124;CE]。<br/>* --ce-data：指定共享集群数据盘。<br/>* --disk-found-path：指定共享集群磁盘发现路径。<br/>* --system-data：指定共享集群系统数据盘。<br/>* --group：指定共享集群组的个数，例如部署主备集群。<br/>* --standby-node：指定共享集群类型备集群节点的部署规模。<br/>* -fg,--failgroup：指定共享集群磁盘组的故障组数量。<br/>* --yfs-force-create：指定YFS强制创建diskgroup。 |
| 滚动升级 | 适用范围扩展  | 共享集群部署从v23.4.2.x开始支持兼容版本（即版本号前三位相同但第四位不同的版本）之间的在线滚动升级。 |
| 部署共享集群 | 支持VIP | 如需在部署时直接为共享集群节点指定VIP（也可以部署完成后再单独配置VIP），只能采用命令行安装的手动部署方式，涉及以下变更：<br/>* 在安装前准备阶段，需要为每台服务器多规划1个IP地址作为节点VIP。<br/>* 在安装部署过程中，yasboot package ce gen命令新增--vips参数，用于指定VIP配置信息。若部署主备集群，备集群的VIP需手动编辑{集群名称}.toml文件进行配置。  |

### 产品规格

以下产品规格在本版本中发生变化，具体改动见下表所示：

|  规格名称| 变化项| 旧值| 新值（含义）|
|--------|------------|--------|-------------|
| 数据类型（yashan模式） | 新增类型 | - | BFILE |
| 索引键值长度（含内部格式） | 最大值 | 6000Bytes | 取决于数据块大小（即DB_BLOCK_SIZE）：<br>* 8K：6400Bytes<br>* 16K：12960Bytes<br>* 32K：26510Bytes |
| SQL语句中常量字符串输入长度 | 最大值 | 16000 | 65534 |
| 表函数单行长度规格 | 最大值 | - | 32KB |
| 单个会话内上下文缓存数量 | 最大值 | - | 10000 |

### 配置参数

下表列示配置参数或配置参数属性的变化点：

|  参数名称| 变化项| 旧值| 新值（含义）|
|--------|------------|--------|-------------|
| ARCHIVELOG\_DELETION\_POLICY | 新增参数 | - | 用于指定归档日志文档的清理策略 |
| DB\_BLOCK\_PRELOADERS | 新增参数 | - | 用于指定异步预读线程数量，设置为0时不开启异步预读 |
| ENABLE\_SECURE\_ERASE | 新增参数 | - | 用于控制是否开启剩余信息保护 |
| FAST\_START\_MTTR\_TARGET | 新增参数 | - | 用于指定共享集群恢复操作的目标时间 |
| NESTLOOP\_JOIN\_OPTIMIZE\_OPTION | 新增参数 | - | 用于控制是否将JOIN扩展为NL的模式 |
| PUSH_DOWN_ROWNUM | 新增参数 | - | 用于控制是否开启rownum下推加速查询 |
| SLOW\_LOG\_PARAM\_MAX\_LEN | 新增参数 | - | 用于指定慢日志记录的单个绑定参数的最大长度值 |
| STANDBY\_RECOVER\_ONLY | 新增参数 | - | 用于指定物理备库是否为不可读的容灾副本 |
| SLOW\_LOG\_SQL\_MAX\_LEN | 值域变更 | \[20,2000\] | 0或\[20,2000\]<br/>SLOW_LOG_SQL_MAX_LEN = 0表示不限制慢日志记录的SQL语句长度 |
