## 23.5.2.100

以下将列出YashanDB所发布v23.5.2.100版本相对于v23.5.1.100版本的主要和明显的变化点，如您在使用过程中发现未在本文中列出，但对贵公司业务产生了影响的变化点，请咨询我们的技术支持获取详细解释说明。

### 升级说明

支持离线升级至当前版本的旧版本范围如下表所示。

| 部署形态| 旧版本范围|
| ---------------------------------- | ------------------------------------------------------------ |
| 单机部署                           | 22.2.16及以前<br/>23.1.5及以前<br/>23.2.14及以前<br/>23.3.3及以前<br/>23.4.6及以前 |
| 共享集群部署                       | 23.1.5及以前<br/>23.2.14及以前<br/>23.3.3及以前<br/>23.4.6及以前 |
| 存算一体分布式集群部署             | 23.1.5及以前<br/>23.2.14及以前<br/>23.3.3及以前<br/>23.4.6及以前 |

### 安装和升级

| 变化项| 变化| 内容|
| ---------------------- | --------------- | ------------------------------------------------------------ |
| 共享集群部署 | 新增功能        | 租户模式下支持SCAN功能 |
| 主备共享集群部署 | 新增功能 | 支持部署为租户模式 |
| 分布式集群部署                                | 新增功能        | 支持可视化部署         |
| 主备共享集群部署（yashan模式） | 新增功能 | 支持滚动升级 |
