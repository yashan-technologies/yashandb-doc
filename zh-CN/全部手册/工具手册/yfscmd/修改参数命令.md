yfscmd的`exec`子命令可以在线修改部分YFS参数的配置，具体可修改的参数列表可通过[show param](./状态查看命令.html#show_param)命令查看。

### 命令格式

- 在yfscmd非交互模式下，修改参数语句必须用引号包围，作为1个独立的参数传入，且无需分号`;`结尾，命令格式为`yfscmd exec "alter system ..."`。

- 在yfscmd交互模式下，命令格式为`exec alter system set ...;`，交互模式下`exec`子命令支持多行输入，直到遇到`;`结束。
### 语句定义

**ALTER_SYSTEM::=**

```ebnf+diagram
syntax::= ALTER SYSTEM SET param_name "=" param_value
```

示例

```shell
# 在非交互模式下，更新触发资源回收上阈值
$ yfscmd exec "ALTER SYSTEM SET RECY_UPPER_THRESHOLD = 90"

# 进入交互模式
$ yfscmd -D $YASCS_HOME

-- 更新终止资源回收下阈值（单行输入）
YFSCMD >  exec ALTER SYSTEM SET RECY_LOWER_THRESHOLD = 50;
-- 调整本地内存上限（多行输入）
YFSCMD >  exec 
>  ALTER SYSTEM SET 
>  SYS_AREA_SIZE = 1G; 
```
