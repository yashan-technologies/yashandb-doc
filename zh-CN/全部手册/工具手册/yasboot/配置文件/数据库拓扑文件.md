数据库拓扑文件列示YashanDB服务端数据库相关信息以及逻辑拓扑信息。

示例：（yashandb_topology.toml）

## 存算一体分布式集群部署

```toml
# 以下内容以实际展示结果为准
 [[group]]
  group_type = "mn"  #节点组类型
  group_id = 1  #节点组ID
  group_name = "mng1"  #节点组名称

  [[group.node]]
    nodeid = "1-1:1"  #节点ID
    hostid = "host0001"  #节点所在服务器标识
    data_path = "/data/yashandb/yashandb/data/yashandb/mn-1-1"  #为DATA目录
    home_path = ""  #YASDB_HOME目录，若路径和服务器的yasboot数据库安装路径一致，则不需要填写。

[[group]]
  group_type = "cn"
  group_id = 2
  group_name = "cng1"

  [[group.node]]
    nodeid = "2-1:2"
    hostid = "host0001"
    data_path = "/data/yashandb/yashandb/data/yashandb/cn-2-1"
    home_path = ""

[[group]]
  group_type = "dn"

  [[group.node]]
    nodeid = "3-1:3"

    home_path = ""
```
