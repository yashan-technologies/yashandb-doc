```ebnf+diagram
oct::= OCT "(" (str|N) ")"
```

OCT函数将对输入的字符串或数字进行八进制转换，函数返回字符串转换成数值后的八进制形式或直接返回数值的八进制。

本函数遵循如下规则：

- 对不能直接以bigint表示的数据报错或强制转换成bigint后统一处理。
- 字符串转换成数值过程中进行非法字符截断，不支持科学计数法。
- 将N视为BIGINT（小数四舍五入），实际有效上界2^64-1，实际有效下界-2^63，超过上界后输出对应二进制全为1，超过下界后输出对应二进制除符号位外全0。正数输出无符号整数对应二进制的八进制，负数输出补码对应二进制的八进制。
- 入参若为NULL，则函数返回NULL。

示例（单机HEAP表）

```sql

SELECT OCT(8);

oct(8)
------
10


SELECT OCT('12a');

oct('12a')
----------
14

```
