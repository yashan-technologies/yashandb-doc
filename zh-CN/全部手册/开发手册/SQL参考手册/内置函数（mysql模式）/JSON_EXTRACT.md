```ebnf+diagram
json_extract::= JSON_EXTRACT "(" (json_value|expr) "," (json_path) {"," (json_path)} ")"
```

JSON_EXTRACT函数将从JSON路径中获取与指定路径参数匹配的部分数据，函数返回值由路径参数匹配的所有值组成，存在多个匹配值时，函数会自动将其封装为一个数组（数组中各个值的顺序与其产生顺序相对应）后再返回。

本函数遵循如下规则：

- 当任何参数为NULL或json_path查找结果为空时，函数返回NULL。
- 如果json_value参数或expr的值所转换而来的二进制json数据不是有效的json数据，或任何路径参数不是有效的路径表达式，则会发生错误。
- 返回值由路径参数匹配的所有值组成。如果这些参数可能返回多个值，则匹配值会自动封装为一个数组，顺序与产生这些值的路径相对应。否则，返回值就是单个匹配值。
- 函数的入参个数范围为[1,65535]。

**json_value**

json_value为一个二进制[json](../通用SQL语法/json)数据，可通过[JSON函数](../内置函数（yashan模式）/JSON JSON_PARSE)获取。

当json_value为NULL时，函数返回NULL。

**json_path**

路径表达式，为一个常量字符串，其格式定义请参考[json](../通用SQL语法/json)文档中描述。

示例（单机HEAP表）

```sql
SELECT JSON_EXTRACT('[1, 2, {"x": 3}]', '$[2]', '$[1]', '$[0]') RES1, JSON_EXTRACT(JSON('[1, 2, {"x": 3}]'), '$[2]', '$[1]', '$[0]') RES2;

RES1                                                             RES2                                                             
---------------------------------------------------------------- ---------------------------------------------------------------- 
[{"x":3},2,1]                                                    [{"x":3},2,1]                                                   
```
