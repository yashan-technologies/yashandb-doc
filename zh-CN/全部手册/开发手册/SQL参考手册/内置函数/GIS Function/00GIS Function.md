地理信息处理函数（GIS Function）是指对空间地理信息进行处理的一系列函数，使用此类函数的前提约束如下：

- 除ST_DISTANCE_SPHERE函数适用于所有部署形态和所有表类型外，其他函数仅适用于单机/共享集群/分布式集群部署中的HEAP表。

- YashanDB服务端需安装gis插件（可通过查看$YASDB_HOME/third路径下是否存在gis文件夹确认）。
