YashanDB JDBC驱动里面定义了YasonDate对象模型，用来表示JSON里面日期数据，是对java的java.util.Date的包装类型。一般是作为YasonObject或者YasonArray的一个value使用，但是也可以单独存在。

它包含三个构造方法：

|  方法| 备注|
|--------------------------------------|--------------------------|
| YasonDate(Date value)           | 创建一个值为指定日期的YasonDate对象   |
| YasonDate(LocalDateTime localDateTime) | 根据localDateTime创建YasonDate对象 |
| YasonDate(LocalDate localDate)  | 根据localDate创建YasonDate对象 |

它包含如下方法：

|  返回类型| 方法| 备注|
|---------------|----------------------|---------------------|
| Date          | getDate()            | 获取Date类型的值          |
| Date          | DateValue()          | 获取Date类型的值          |
| LocalDateTime | getLocalDateTime()   | 获取LocalDateTime类型的值 |
| LocalDateTime | localDateTimeValue() | 获取LocalDateTime类型的值 |
| LocalDate     | getLocalDate()       | 获取LocalDate类型的值     |
| LocalDate     | localDateValue()     | 获取LocalDate类型的值     |
 
```java

        YasonDate yasonDate = new YasonDate(LocalDateTime.of(2022,8,12,15,35,55));
        System.out.println(yasonDate.getLocalDate()); // 2022-08-12
        System.out.println(yasonDate.getDate()); // Fri Aug 12 15:35:55 CST 2022
        System.out.println(yasonDate.getLocalDateTime()); // 2022-08-12T15:35:55

        // 作为json的一个值使用
        YasonObject json = new YasonObject();
        json.put("date1",yasonDate);
        System.out.println(json); // {"date1":"2022-08-12T15:35:55"}

```
