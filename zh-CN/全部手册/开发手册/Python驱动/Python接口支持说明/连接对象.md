连接对象（Connection Object）用于表示和管理Python应用程序与数据库的单个连接。

## 对象创建方式

连接对象需通过[connect\(\)](python-yaspy模块)或[poolname\.acquire\(\)](连接池对象)创建。

## 连接方法 

|  方法| 说明 |
| ---------- | ------ |
| Connection.close()    | 立即关闭连接。 |
| Connection.commit()   | 提交处理中的事务。 |
| Connection.rollback() | 回滚处理中的事务。 |
| Connection.cursor()   | 创建一个新的[游标对象](游标对象)。|
