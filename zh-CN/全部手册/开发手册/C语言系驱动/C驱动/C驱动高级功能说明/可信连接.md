可信连接是指通过公/私钥各类证书在应用客户端和YashanDB服务端之间建立安全、可靠和加密的数据传输通道，满足企业的信息安全要求。

YashanDB C驱动存在两层级的可信连接方式：

1. 在YashanDB客户端环境配置文件yasc_env.ini中配置ssl_root_cer变量的值为与要连接的服务器匹配的CA证书路径，应用程序发起数据库连接时读取该证书，建立与服务端的可信连接。
2. 在数据库连接信息句柄中设定与要连接的服务器匹配的CA证书路径，之后发起的数据库连接即可读取该证书，建立与服务端的可信连接。

其中，第2种方式要求数据库服务端所配置证书的加密协议类型为SSL。

如应用客户端同时启用了上述两种方式，则优先使用在当前连接信息句柄中所配置的证书。均不启用，但数据库服务端已启用SSL可信信道时，仍会建立加密通信连接，但可能存在中间人攻击等风险。

## 配置ssl\_root\_cer变量方式

本方式只需在数据库服务端配置和启用可信信道，以及在应用客户端下载和配置证书，即可实现可信连接，应用程序本身无需任何处理。

1. 由DBA在数据库服务端安装SSL或TLCP类型的证书，安装证书的操作指导请查阅[管理证书文档](../../../../产品安全/加密支持/可信信道/管理证书)。如服务端已有证书，则跳过此步。
2. 由DBA参照[配置可信信道文档](../../../../产品安全/加密支持/可信信道/配置可信信道)中的服务端配置部分开启可信信道。如服务端已开启，则跳过此步。
3. 由应用客户端管理员从数据库服务端下载CA根证书，保存至本地。
4. 由应用客户端管理员参照[配置可信信道文档](../../../../产品安全/加密支持/可信信道/配置可信信道)中的客户端配置部分，将本地证书路径添加到YashanDB的环境配置文件yasc_env.ini中。
5. 上述操作完成后，在该应用端使用YashanDB C驱动发起到该服务端的连接，将均建立为可信连接。请注意建立连接时驱动程序将会对本地证书进行验证，包括正确性和有效性等，验证失败则抛出错误，无法连接数据库服务端。
6. 如出现证书过期错误，请通知DBA重新生成证书并下载至本地，将新证书覆盖至已有证书。

## 设置连接信息句柄方式

本方式仍需在数据库服务端配置和启用可信信道，以及在应用客户端下载证书，但无需在本机进行ssl_root_cer变量配置。可下载不同服务器的多套CA证书，在应用程序中对指定的服务端设定相应的证书路径，即可实现与该服务端的可信连接。当应用客户端的一个连接周期内需要连接多个数据库服务端（例如配置了TAF），而服务端的证书信息并不相同时，使用本方式可以消除ssl_root_cer变量只能为固定路径的限制。

需注意的是，本方式中下载的服务器证书必须为采用SSL加密协议生成的根证书，且服务端存在主备形态时，应同时开启主备可信通道。

1. 由DBA在数据库服务端安装SSL类型的证书，安装证书的操作指导请查阅[管理证书文档](../../../../产品安全/加密支持/可信信道/管理证书)。如服务端已有证书，则跳过此步。
2. 由DBA参照[配置可信信道文档](../../../../产品安全/加密支持/可信信道/配置可信信道)中的服务端配置部分开启可信信道。如服务端已开启，则跳过此步。
3. 若服务端为主备形态，需由DBA参照[配置可信信道文档](../../../../产品安全/加密支持/可信信道/配置可信信道)中的主备复制网络可信信道部分开启主备复制网络可信信道开关。如服务端已开启，则跳过此步。
4. 由应用客户端管理员从数据库服务端下载CA根证书，保存至本地。多份服务器证书存放于不同的路径。
5. 由应用开发人员在应用程序中调用[yacSetConnAttr](../C驱动接口说明/句柄属性设置与查询函数/yacSetConnAttr)接口，设置YAC_ATTR_SSL_ROOT_CER属性的值为本机上该服务端对应的CA根证书路径。示例语句如下：
   ```c
   const YacChar* gSrvStr = "192.168.1.2:1688?FAILOVER = ON & FAILOVER_TYPE = SESSION & FAILOVER_RETRIES = 10 & FAILOVER_DELAY = 1";
   const YacChar* user = "sys";
   const YacChar* pwd = "password";
   const YacChar* sslpath = "/data/yashan/ssl/root.crt";
    
   YacHandle env;
   YacHandle conn;
   YAC_CALL(yacAllocHandle(YAC_HANDLE_ENV, NULL, &env));
   YAC_CALL(yacAllocHandle(YAC_HANDLE_DBC, env, &conn));
   YAC_CALL(yacSetConnAttr(conn, (YacConnAttr)YAC_ATTR_SSL_ROOT_CER, (YacVoid*)sslpath, sizeof(CodPointer)))
   YAC_CALL(yacConnect(conn, gSrvStr, YAC_NULL_TERM_STR, user, YAC_NULL_TERM_STR, pwd, YAC_NULL_TERM_STR));
   ```

   通过以上示例语句可实现与服务端建立可信连接，在设置YAC_ATTR_SSL_ROOT_CER属性值后，驱动程序将会忽略ssl_root_cer变量值，而使用所设置路径的CA证书与数据库服务端进行通信认证，如证书错误或过期，将会抛出错误，该次数据库连接失败。

 6. 由应用开发人员在应用程序中调用[yacDisconnect](../C驱动接口说明/连接、授权和初始化函数/yacDisconnect)接口断开数据库连接，驱动程序在此时会将yacSetConnAttr所设置YAC_ATTR_SSL_ROOT_CER属性值进行置空处理。
