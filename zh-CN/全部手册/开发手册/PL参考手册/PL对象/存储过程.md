存储过程是数据库里的一种PL对象。

存储过程不适用于存算一体分布式集群部署。

创建存储过程
------

使用[CREATE PROCEDURE](../../SQL参考手册/SQL语句/CREATE PROCEDURE)语句创建存储过程，其语法定义为：

**create procedure::=**

```ebnf+diagram
syntax::= CREATE [OR REPLACE] [EDITIONABLE|NONEDITIONABLE] PROCEDURE procedure_head_clause (IS|AS) procedure_body_clause ";"
```

**procedure_head_clause::=**

```ebnf+diagram
syntax::= [schema "."] procedure_name ["(" (argument_define) {"," (argument_define)} ")"] [invoker_rights_clause]
```

**invoker_rights_clause::=**

```ebnf+diagram
syntax::= AUTHID (CURRENT_USER|DEFINER)
```

**procedure_body_clause::=**

```ebnf+diagram
syntax::= [variable_declare] BEGIN plsql_statements END [procedure_name]
```

### 1. OR REPLACE

当要创建的存储过程已经存在时，将其进行重建。

### 2. EDITIONABLE | NONEDITIONABLE

用于语法兼容，无实际含义。

### 3. procedure\_name

存储过程的名称，不可省略，且需符合YashanDB的[对象命名规范](../../SQL参考手册/基本SQL元素/标识符)。

### 4. argument\_define

定义存储过程的参数（形参），可省略，此时procedure_name()=procedure_name。最多可以指定4095个参数。

更多详情请查阅[PL参数描述](../参数/00参数)。

### 5. invoker\_rights\_clause

详情请查阅[invoker_rights_clause](./00PL对象.html#invoker)相关描述。

### 6. variable\_declare

声明PL过程体的全局变量，可省略。

更多详情请查阅[PL声明](../PL语言基础/变量/00变量)。

### 7. plsql\_statements

定义过程体中的执行语句，为[PL语句](../PL语句/00PL语句)中的一项或多项。

示例（单机/共享集群/分布式集群部署）

```plsql
CREATE OR REPLACE PROCEDURE ya_proc(i INT) IS
BEGIN
CASE i
WHEN 1 THEN
DBMS_OUTPUT.PUT_LINE('hello');
WHEN 2 THEN
DBMS_OUTPUT.PUT_LINE('world');
END CASE;
END ya_proc;
/
```

运行存储过程
------

### SQL语句中调用

通过CALL、EXEC语句调用存储过程，其语法定义为：

```ebnf+diagram
syntax::= (CALL|EXEC) procedure_name ["(" arguments ")"]
```

arguments为与argument_define一一对应的实参。

示例（单机/共享集群/分布式集群部署）

```plsql
exec ya_proc(1);

--result
hello
```

### 过程体中调用

格式为：_procedure_name(arguments);_。

arguments为与argument_define一一对应的实参。

示例（单机/共享集群/分布式集群部署）

```plsql
BEGIN
  ya_proc(1);
  ya_proc(2);
END;
/

--result
hello
world
```
