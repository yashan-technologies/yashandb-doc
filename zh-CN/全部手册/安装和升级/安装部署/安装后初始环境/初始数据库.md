## 删除初始数据库（yashan模式）

初始数据库可能无法满足生产环境的实际需要，可按需将其删除并创建生产数据库。

该操作不适用于存算一体分布式集群部署和mysql模式的单机部署。

1. 以sys用户登录数据库。
    
    ```shell
    $ yasql sys/********@192.168.1.2:1688
    YashanDB SQL Enterprise Edition Release {版本号} x86_64

    Connected to:
    YashanDB Server Enterprise Edition Release {版本号} x86_64 - Linux

    SQL> 
    ```
    
2. 使用[SHUTDOWN](../../../开发手册/SQL参考手册/SQL语句（yashan模式）/SHUTDOWN)语句关闭初始数据库。

3. 重启实例至NOMOUNT模式，具体操作请参考[数据库实例启停](../../../数据库管理/基本数据库管理/实例启停)。

4. 执行[DROP DATABASE](../../../开发手册/SQL参考手册/SQL语句（yashan模式）/DROP DATABASE)语句删除初始数据库。

5. 执行[CREATE DATABASE](../../../开发手册/SQL参考手册/SQL语句（yashan模式）/CREATE DATABASE)语句新建数据库。

## 新建业务数据库（mysql模式）

1. 以sys用户登录YashanDB。

2. 新建用户并授予合适的权限，具体操作请参考[用户](../../../产品安全/身份标识与鉴别/用户/管理用户（mysql模式）)、[权限授予与收回](../../../产品安全/数据访问控制/特权管理（mysql模式）/权限授予与收回)。

3. 以新用户登录YashanDB。

4. 执行[CREATE DATABASE](../../../开发手册/SQL参考手册/SQL语句（mysql模式）/CREATE DATABASE)语句新建数据库，后续使用中，可通过[USE](../../../开发手册/SQL参考手册/SQL语句（mysql模式）/USE)语句选择某个会话需要操作的数据库。

## 开始使用YashanDB

在开发人员或其他用户能使用YashanDB前，系统管理员还需执行下述相关操作：

- 如需依照本手册学习使用YashanDB，请先创建sales样例用户并授予合适的权限。
  
  ```sql
  CREATE USER sales IDENTIFIED BY 'Yr_pswd0';
  GRANT DBA TO sales;

  -- mysql模式下，还需执行以下操作
  GRANT ALL ON *.* TO sales;
  conn "sales"/********
  CREATE DATABASE IF NOT EXISTS sales DEFAULT CHARACTER SET `utf8` DEFAULT collate `utf8mb4_general_ci`;
  use sales;
  ```

- 参考[数据库管理](../../../数据库管理/基本数据库管理/00基本数据库管理)的各项数据库管理内容，例如建立表空间管理体系。

- 参考[产品安全](../../../产品安全/YashanDB安全体系概述)所述建立数据库安全体系。

- 共享集群部署时，还需参考[共享集群](../../../共享集群/YashanDB共享集群概述)的各项管理内容。

- 分布式集群部署时，请参考[分布式集群](../../../分布式集群/用户使用指导)中的指导开始使用YashanDB
