为提高业务隔离性，减少误操作，建议为YashanDB产品创建独立的安装用户，以下操作须在所有服务器上执行。

1. 创建安装用户。

    本安装手册中，以yashan作为数据库安装用户名称。

    ```shell
    # useradd -d /home/yashan -m yashan
    # passwd yashan
    ```

2. 新建YASDBA用户组并将安装用户加入该组。

    ```shell
    # groupadd YASDBA
    # usermod -a -G YASDBA yashan
    ```

3. 为安装用户配置sudo免密。

    ```shell
    # cd /etc
    # ll sudoers
    ## 若root用户不具备sudoers文件编辑权限，需先授权
    # chmod +w sudoers
    # vi /etc/sudoers

    ## 在sudoers文件文件末尾添加如下内容，保存并退出
    yashan  ALL=(ALL)NOPASSWD:ALL

    ## 若调整过sudoers文件的权限，应还原
    # chmod -w sudoers
    ```
