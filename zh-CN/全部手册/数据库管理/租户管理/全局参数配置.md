## 配置参数分类



在容器数据库中，配置参数根据其生效属性可分为：

- CDB全局参数：整个CDB级别的配置，仅允许连接根容器进行修改，仅对根容器生效。

- CDB私有参数：每个容器（根容器、PDB）独立的参数，只能直连目标容器进行自定义配置，仅对自身生效。

- 普通参数：每个容器可自定义配置也可直接继承根容器的参数（PDB中对应参数的旧值与根容器旧值一致表示属于继承关系），其生效范围取决于执行实例和指定的container属性。


通过[V$PARAMETER](../../参考手册/系统视图/动态视图/V$PARAMETER)视图中的ISPDB_MODIFIABLE和ISPDB_PRIVATE字段可以判断参数的作用域属性。

## 配置继承与补偿机制

PDB的普通参数类配置默认继承于根容器，若PDB中某个普通参数的值与根容器中的值一致，则视作具备继承关系。是否具备继承关系将会直接影响批量下发调整PDB配置的操作方式：

- 具备继承关系：在根容器指定CONTAINER=current修改配置参数时，PDB仍会继承该类变更。

- 继承关系已解除：必须在根容器指定CONTAINER=all进行修改，且修改完成后继承关系恢复。

配置补偿机制主要是指PDB启动时如何正确应用最新普通参数类配置：

- 新建PDB时，直接继承并应用根容器中最新的已生效的相应配置。

- 启动已有PDB时，需补偿应用PDB关闭期间内根容器批量下发的配置调整。

## 参数值修改方式

在容器数据库中，根据实际运维需求，配置参数可以从CDB级别进行集中化管理，也可以由各个PDB自行独立管理。

### 使用SQL语句修改

#### 全局批量修改

CDB管理员可以登录根容器对普通参数类配置进行全局批量修改，将变更指令下发至所有PDB或具备继承关系的PDB。

1. 以DBA用户连接并登录根容器。
    ```shell
    $ yasql c##sales/********@192.168.1.2:1688
    YashanDB SQL Enterprise Edition Release {version_number} x86_64

    Connected to:
    YashanDB Server Enterprise Edition Release {version_number} x86_64 - Linux

    SQL> 
    ```


2. 执行ALTER SYSTEM语句，批量修改普通参数的值。

    - 仅调整**具备继承关系的PDB**的普通参数

    ```sql
    SELECT a.NAME AS CON_NAME, c.NAME AS parameter, c.VALUE
    FROM containers(V$PARAMETER) AS c
    INNER JOIN V$CONTAINERS a ON c.CON_ID = a.CON_ID
    WHERE c.NAME = 'CHECKPOINT_TIMEOUT';
    CON_NAME     PARAMETER                                             VALUE
    ------------ ----------------------------------------------------- ----------------------
    CDB$ROOT     CHECKPOINT_TIMEOUT                                    300
    PDB1         CHECKPOINT_TIMEOUT                                    1000
    PDB2         CHECKPOINT_TIMEOUT                                    300  

    ALTER SYSTEM SET CHECKPOINT_TIMEOUT=400 CONTAINER=CURRENT;

    SELECT a.NAME AS CON_NAME, c.NAME AS parameter, c.VALUE
    FROM containers(V$PARAMETER) AS c
    INNER JOIN V$CONTAINERS a ON c.CON_ID = a.CON_ID
    WHERE c.NAME = 'CHECKPOINT_TIMEOUT';
    CON_NAME NAME                                                      VALUE
    ------------ ----------------------------------------------------- ----------------------
    CDB$ROOT     CHECKPOINT_TIMEOUT                                    400
    PDB1         CHECKPOINT_TIMEOUT                                    1000
    PDB2         CHECKPOINT_TIMEOUT                                    400
    ```

    - 调整**所有PDB**的普通参数（不论继承关系是否存在）

    ```sql
    SELECT a.NAME AS CON_NAME, c.NAME AS parameter, c.VALUE
    FROM containers(V$PARAMETER) AS c
    INNER JOIN V$CONTAINERS a ON c.CON_ID = a.CON_ID
    WHERE c.NAME = 'CHECKPOINT_TIMEOUT';
    CON_NAME     PARAMETER                                             VALUE
    ------------ ----------------------------------------------------- ----------------------
    CDB$ROOT     CHECKPOINT_TIMEOUT                                    400
    PDB1         CHECKPOINT_TIMEOUT                                    1000
    PDB2         CHECKPOINT_TIMEOUT                                    400

    ALTER SYSTEM SET CHECKPOINT_TIMEOUT=300 CONTAINER=ALL;

    SELECT a.NAME AS CON_NAME, c.NAME AS parameter, c.VALUE
    FROM containers(V$PARAMETER) AS c
    INNER JOIN V$CONTAINERS a ON c.CON_ID = a.CON_ID
    WHERE c.NAME = 'CHECKPOINT_TIMEOUT';
    CON_NAME     PARAMETER                                             VALUE
    ------------ ----------------------------------------------------- ----------------------
    CDB$ROOT     CHECKPOINT_TIMEOUT                                    300
    PDB1         CHECKPOINT_TIMEOUT                                    300
    PDB2         CHECKPOINT_TIMEOUT                                    300
    ```

#### 定向修改

CDB管理员可以登录根容器对普通参数类配置进行指定PDB的定向修改，效果等同于登录PDB进行本地修改。

1. 以DBA用户连接并登录根容器。
    ```shell
    $ yasql c##sales/********@192.168.1.2:1688
    YashanDB SQL Enterprise Edition Release {version_number} x86_64

    Connected to:
    YashanDB Server Enterprise Edition Release {version_number} x86_64 - Linux

    SQL> 
    ```


2. 执行ALTER SYSTEM语句，定向调整指定PDB中的普通参数。
    
    ```sql
    SELECT a.NAME AS CON_NAME, c.NAME AS parameter, c.VALUE
    FROM containers(V$PARAMETER) AS c
    INNER JOIN V$CONTAINERS a ON c.CON_ID = a.CON_ID
    WHERE c.NAME = 'CHECKPOINT_TIMEOUT';
    CON_NAME     PARAMETER                                             VALUE
    ------------ ----------------------------------------------------- ----------------------
    CDB$ROOT     CHECKPOINT_TIMEOUT                                    300
    PDB1         CHECKPOINT_TIMEOUT                                    300
    PDB2         CHECKPOINT_TIMEOUT                                    300

    ALTER SYSTEM SET CHECKPOINT_TIMEOUT=350 CONTAINER=PDB1;

    SELECT a.NAME AS CON_NAME, c.NAME AS parameter, c.VALUE
    FROM containers(V$PARAMETER) AS c
    INNER JOIN V$CONTAINERS a ON c.CON_ID = a.CON_ID
    WHERE c.NAME = 'CHECKPOINT_TIMEOUT';
    CON_NAME     PARAMETER                                             VALUE
    ------------ ----------------------------------------------------- ----------------------
    CDB$ROOT     CHECKPOINT_TIMEOUT                                    300
    PDB1         CHECKPOINT_TIMEOUT                                    350
    PDB2         CHECKPOINT_TIMEOUT                                    300
    ```

#### 本地修改

管理员可以登录目标容器（根容器或PDB）对该容器的所有参数进行本地修改。

1. 以DBA用户连接并登录目标容器（根容器或PDB）。
    ```shell
    $ yasql sales/********@192.168.1.2:1688
    YashanDB SQL Enterprise Edition Release {version_number} x86_64

    Connected to:
    YashanDB Server Enterprise Edition Release {version_number} x86_64 - Linux

    SQL> 
    ```


2. 执行ALTER SYSTEM语句，修改当前容器本地的参数值。
    
    - 连接根容器时，可以指定CONTAINER=CURRENT修改当前容器的CDB私有参数。

    ```sql
    SELECT a.NAME AS CON_NAME, c.NAME AS parameter, c.VALUE
    FROM containers(V$PARAMETER) AS c
    INNER JOIN V$CONTAINERS a ON c.CON_ID = a.CON_ID
    WHERE c.NAME = 'HA_ELECTION_AUTO_PRIMARY_SWITCH';
    CON_NAME     PARAMETER                                             VALUE
    ------------ ----------------------------------------------------- ----------------------
    CDB$ROOT     HA_ELECTION_AUTO_PRIMARY_SWITCH                       FALSE
    PDB1         HA_ELECTION_AUTO_PRIMARY_SWITCH                       FALSE
    PDB2         HA_ELECTION_AUTO_PRIMARY_SWITCH                       FALSE

    ALTER SYSTEM SET HA_ELECTION_AUTO_PRIMARY_SWITCH='TRUE' CONTAINER=CURRENT;

    SELECT a.NAME AS CON_NAME, c.NAME AS parameter, c.VALUE
    FROM containers(V$PARAMETER) AS c
    INNER JOIN V$CONTAINERS a ON c.CON_ID = a.CON_ID
    WHERE c.NAME = 'HA_ELECTION_AUTO_PRIMARY_SWITCH';
    CON_NAME     PARAMETER                                             VALUE
    ------------ ----------------------------------------------------- ----------------------
    CDB$ROOT     HA_ELECTION_AUTO_PRIMARY_SWITCH                       TRUE
    PDB1         HA_ELECTION_AUTO_PRIMARY_SWITCH                       FALSE
    PDB2         HA_ELECTION_AUTO_PRIMARY_SWITCH                       FALSE
    ```

    - 连接PDB时，可以修改当前容器的普通参数、CDB私有参数。

    ```shell
    $ yasql sales/********@192.168.1.2:1688/pdb1

    SQL> SHOW PARAMETER UNDO_RETENTION;
    NAME                        VALUE   
    --------------------------- ------- 
    UNDO_RETENTION              300  

    SQL> ALTER SYSTEM SET UNDO_RETENTION=350;

    SQL> SHOW PARAMETER UNDO_RETENTION;
    NAME                        VALUE   
    --------------------------- ------- 
    UNDO_RETENTION              350 

    SQL> exit

    $ yasql sys/********@192.168.1.2:1688

    SQL> SELECT a.NAME AS CON_NAME, c.NAME AS parameter, c.VALUE
    FROM containers(V$PARAMETER) AS c
    INNER JOIN V$CONTAINERS a ON c.CON_ID = a.CON_ID
    WHERE c.NAME = 'UNDO_RETENTION';
    CON_NAME     PARAMETER                                             VALUE
    ------------ ----------------------------------------------------- ----------------------
    CDB$ROOT     UNDO_RETENTION                                        300
    PDB1         UNDO_RETENTION                                        350
    PDB2         UNDO_RETENTION                                        300
    ```

### 使用yasboot工具修改

[yasboot cluster config set](../../工具手册/yasboot/yasboot命令介绍/yasboot cluster)命令等价于登录根容器执行ALTER SYSTEM SET … CONTAINER=CURRENT语句，使用场景包括：

- 批量调整根容器和具备继承关系的PDB中的普通参数。

- 调整根容器中的CDB私有参数。

具体操作步骤如下：

1. 以安装用户登录数据库安装服务器。


2. 执行以下命令，查看目标参数的当前配置。

    ```shell
    $ yasql / as sysdba

    SQL> SELECT a.NAME AS CON_NAME, c.NAME AS parameter, c.VALUE
    FROM containers(V$PARAMETER) AS c
    INNER JOIN V$CONTAINERS a ON c.CON_ID = a.CON_ID
    WHERE c.NAME = 'CHECKPOINT_TIMEOUT';
    CON_NAME     PARAMETER                                             VALUE
    ------------ ----------------------------------------------------- ----------------------
    CDB$ROOT     CHECKPOINT_TIMEOUT                                    300
    PDB1         CHECKPOINT_TIMEOUT                                    350
    PDB2         CHECKPOINT_TIMEOUT                                    300

    SQL> exit
    ```

3. 执行以下命令，修改参数配置。

    ```shell
    $ yasboot cluster config set -c yashandb -k CHECKPOINT_TIMEOUT -v 3600
    ```

4. 执行以下命令，检查修改结果。

    ```shell
    $ yasql / as sysdba

    SQL> SELECT a.NAME AS CON_NAME, c.NAME AS parameter, c.VALUE
    FROM containers(V$PARAMETER) AS c
    INNER JOIN V$CONTAINERS a ON c.CON_ID = a.CON_ID
    WHERE c.NAME = 'CHECKPOINT_TIMEOUT';
    CON_NAME     PARAMETER                                             VALUE
    ------------ ----------------------------------------------------- ----------------------
    CDB$ROOT     CHECKPOINT_TIMEOUT                                    3600
    PDB1         CHECKPOINT_TIMEOUT                                    350
    PDB2         CHECKPOINT_TIMEOUT                                    3600
    ```
