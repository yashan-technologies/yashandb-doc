> **Warn**:
>
> 删除PDB的同时会删除PDB相关的持久化文件且无法回滚，**请谨慎操作**。

可以使用以下方法删除不必要的PDB：

| 方法 | 功能说明 |
| -------------------------------- | -------------------------------------------- |
| 连接根容器执行[DROP PLUGGABLE DATABASE](../../../开发手册/SQL参考手册/SQL语句/DROP PLUGGABLE DATABASE)语句 | 单次可以删除1个PDB，可按需选择是否保留目标PDB的redo日志文件、归档日志文件以及PDB元数据。 |
| [yasboot工具](../../../工具手册/yasboot/yasboot命令介绍/yasboot pdb) | 单次可以单个或批量删除PDB，但该操作属于彻底销毁PDB，无法自选保留部分持久化文件。 |

## 前提条件

- 执行操作的根容器处于OPEN状态。在主备部署中，需在主根容器上操作。

- 目标PDB处于关闭状态。

## 连接根容器执行SQL语句删除

1. 以DBA用户连接并登录根容器。
    ```shell
    $ yasql c##sales/********@192.168.1.2:1688
    YashanDB SQL Enterprise Edition Release {version_number} x86_64

    Connected to:
    YashanDB Server Enterprise Edition Release {version_number} x86_64 - Linux

    SQL> 
    ```


2. 获取目标PDB信息，包括状态、名称等。

    ```sql
    show pdbs

                   CON_ID CON_NAME                                                         STATUS
    --------------------- ---------------------------------------------------------------- -----------------
                        1 PDB$SEED                                                         CLOSED
                        2 PDB1                                                             OPEN
                        3 PDB2                                                             CLOSED
    ```

    若目标PDB处于运行中，需[关闭PDB](./PDB启停.html#close)再执行后续操作。

3. 执行DROP PLUGGABLE DATABASE语句删除目标PDB，可根据操作场景选择保留部分持久化文件：

    - 作为PDB恢复的前序操作：指定KEEP METADATA关键字，保留PDB的元数据，归档日志文件默认保留。若进行PITR恢复则还需额外指定KEEP LOGFILE关键字保留目标PDB的redo日志文件。

    ```sql
    DROP PLUGGABLE  DATABASE pdb2 KEEP METADATA;
    -- 或
    DROP PLUGGABLE  DATABASE pdb2 KEEP LOGFILE KEEP METADATA;
    ```

    - 作为重新构建PDB备库的前序操作：同时指定KEEP METADATA关键字和INCLUDING ARCHIVELOG关键字，仅保留PDB的元数据。

    ```sql
    DROP PLUGGABLE DATABASE pdb2 KEEP METADATA INCLUDING ARCHIVELOG;
    ```

    - 已明确目标PDB无需使用：无需保留任何持久化文件，指定INCLUDING ARCHIVELOG关键字一并删除归档日志文件。

    ```sql
    DROP PLUGGABLE DATABASE pdb2 INCLUDING ARCHIVELOG;
    ```

4. 确认删除结果。

    ```sql
    show pdbs

                   CON_ID CON_NAME                                                         STATUS
    --------------------- ---------------------------------------------------------------- -----------------
                        1 PDB$SEED                                                         CLOSED
                        2 PDB1                                                             OPEN
    ```

5. 若为共享集群/分布式集群部署，还需执行ycsctl remove pdb从集群中移除该PDB信息。

    ```shell
    SQL> exit
    $ ycsctl remove pdb -db yashandb -pdb pdb2
    ```

    若目标PDB处于运行中，需关闭PDB再执行后续操作，若为主备部署，只需关闭主PDB即可。

    ```shell
    $ yasboot pdb stop -c yashandb -n 1-1 --pdb pdb2
    ```

3. 执行yasboot pdb drop命令删除目标PDB，并根据提示输入确认信息。

    ```shell
    $ yasboot pdb drop -c yashandb --pdb pdb2
    Are you sure you want to drop pdb pdb2 ?[yes/no]:yes
    ```

    提示`task completed, status: SUCCESS`表示执行成功。
