YashanDB支持基于数据库全库维度或基于指定某个表进行闪回恢复，更多详情可查阅[FLASHBACK](../../开发手册/SQL参考手册/SQL语句（yashan模式）/FLASHBACK)。

## 全库闪回

全库闪回需满足以下条件：

- 仅适用于单机部署。
- 确保已开启[全库闪回](../../开发手册/SQL参考手册/SQL语句（yashan模式）/ALTER DATABASE.html#flashbackdatabaseclauses)功能，可通过查询V$DATABASE视图的FLASHBACK_ON字段确认是否开启。
- 执行全库闪回操作需使用具备DBA权限或FLASHBACK相关权限的用户。
- 执行全库闪回时数据库需处于MOUNT状态，闪回完成后必须[ALTER DATABASE OPEN RESETLOGS](../../开发手册/SQL参考手册/SQL语句（yashan模式）/ALTER DATABASE.html#startupclauses)重置redo时间线。
- 通过时间戳或SCN进行全库闪回时，可闪回恢复到的时间点由开启全库闪回功能的时间点决定，可通过V$FLASHBACK_DATABASE_LOG视图获取相关信息。
- 通过还原点进行全库闪回时，需先执行[CREATE RESTORE POINT](../../开发手册/SQL参考手册/SQL语句（yashan模式）/CREATE RESTORE POINT)创建还原点。

全库闪回存在如下约束：

- 目前无法闪回文件类DDL（例如表空间DDL、数据文件DDL等）、NOLOGGING对象。
- 归档文件和REDO文件的操作不会被闪回。

示例（单机部署）

```sql
-- 查询V$DATABASE视图的FLASHBACK_ON字段确认是否已开启全库闪回
SELECT FLASHBACK_ON FROM V$DATABASE;

FLASHBACK_ON
-----------------
NO

-- 如果字段值为NO表示未开启，需执行以下语句开启全库闪回功能
ALTER DATABASE FLASHBACK ON;

-- 创建area1表并插入数据
DROP TABLE IF EXISTS area1; 
CREATE TABLE area1
(area_no CHAR(2) NOT NULL PRIMARY KEY,
 area_name VARCHAR2(60),
 DHQ VARCHAR2(20) DEFAULT 'ShenZhen' NOT NULL);
INSERT INTO area1 VALUES ('01','EastChina','Shanghai');
INSERT INTO area1 VALUES ('02','WestChina','Chengdu');

-- 创建还原点
CREATE RESTORE POINT p20250101;

-- 误操作删除area1表
DROP TABLE area1; 

-- 将数据库重启至MOUNT阶段，并基于还原点闪回数据库
-- （可选）查询V$RESTORE_POINT获取还原点信息
SELECT NAME,CREATE_TIME FROM V$RESTORE_POINT;

-- 根据视图中的还原点信息决定需要闪回至哪个还原点
FLASHBACK DATABASE TO RESTORE POINT p20250101;

-- 启动数据库至OPEN，并重置redo时间线
ALTER DATABASE OPEN RESETLOGS;

-- 查询area1表信息
SELECT area_no,area_name FROM area1;
AREA_NO   AREA_NAME
--------- ----------------------------------------------------------------
01        EastChina
02        WestChina
```

## 表闪回

表闪回需满足以下条件：

- 执行表闪回操作需使用具备DBA权限或FLASHBACK相关权限的用户。
- 在当前时间点至目标闪回时间点期间，表的结构未发生变化。
- 表闪回可恢复的时间点由撤销保持期（UNDO_RETENTION）决定，建议将该参数设置为86400秒（24小时）或更长。
- 表闪回恢复的表对象只能是HEAP表，且不能是sys用户名下的表（sys用户名下的表drop或truncate后相应数据始终不会进入回收站）。
- 通过时间戳或SCN进行表闪回前需手动开启表的ROW MOVEMENT，且表闪回后的数据可能会改变rowid，请确保应用程序不依赖于rowid才能执行表闪回。
- 对于被drop的表，需确保历史数据仍然存放在回收站中才能将该表（包括表结构和数据）闪回恢复。
   - drop前已开启回收站。
   - drop表时，未指定purge语句。
   - 当前时间点至目标闪回时间点期间，未对回收站执行purge。
   - drop表时，表空间未满。
- 对于被truncate的表，需确保历史数据仍然存放在回收站中才能将该表数据（包括truncate表或truncate分区）闪回恢复。若当前时间点与truncate时间点期间表格已插入新数据，执行表闪回操作后该类新数据将会被放入回收站中。
   - truncate前已开启回收站。
   - 当前时间点至目标闪回时间点期间，未对回收站执行purge。
   - truncate表时，表空间未满。

### delete操作闪回

示例（HEAP表）

```sql
-- 开启finance_info表的ROW MOVEMENT开关
ALTER TABLE finance_info ENABLE ROW MOVEMENT;

-- finance_info表中存在的一条记录
SELECT year,month,branch,revenue_total,cost_total,fee_total FROM finance_info WHERE year='2021' AND month='02';
YEAR  MONTH BRANCH REVENUE_TOTAL  COST_TOTAL   FEE_TOTAL
----- ----- ------ ------------- ----------- -----------
2021  02    0101           37778       33000        6000   
 
-- 获取当前时间戳
SELECT SYSTIMESTAMP res FROM dual;
RES                                           
-----------------------------------------------
2023-12-17 14:10:28.736908   

-- 删除此条记录并提交
DELETE FROM finance_info WHERE year='2021' AND month='02';
COMMIT;
SELECT year,month,branch,revenue_total,cost_total,fee_total FROM finance_info WHERE year='2021' AND month='02';
YEAR  MONTH BRANCH REVENUE_TOTAL  COST_TOTAL   FEE_TOTAL
----- ----- ------ ------------- ----------- -----------

 
-- 利用FLASHBACK闪回历史数据（通过时间戳闪回）
FLASHBACK TABLE finance_info TO TIMESTAMP  TIMESTAMP('2023-12-17 14:10:28.736908');
SELECT year,month,branch,revenue_total,cost_total,fee_total FROM finance_info WHERE year='2021' AND month='02';
YEAR  MONTH BRANCH REVENUE_TOTAL  COST_TOTAL   FEE_TOTAL
----- ----- ------ ------------- ----------- -----------
2021  02    0101           37778       33000        6000   

-- 获取最后一次修改时SCN（通过ROWSCN获取）
SELECT rowscn FROM finance_info WHERE year='2021' AND month='02';
               ROWSCN 
--------------------- 
   408883147271815168

-- 再次删除记录
DELETE FROM finance_info WHERE year='2021' AND month='02';
COMMIT;
SELECT year,month,branch,revenue_total,cost_total,fee_total FROM finance_info WHERE year='2021' AND month='02';
YEAR  MONTH BRANCH REVENUE_TOTAL  COST_TOTAL   FEE_TOTAL
----- ----- ------ ------------- ----------- -----------

-- 利用FLASHBACK闪回历史数据（通过SCN闪回）
FLASHBACK TABLE finance_info TO SCN 408883147271815168;
SELECT year,month,branch,revenue_total,cost_total,fee_total FROM finance_info WHERE year='2021' AND month='02';
YEAR  MONTH BRANCH REVENUE_TOTAL  COST_TOTAL   FEE_TOTAL
----- ----- ------ ------------- ----------- -----------
2021  02    0101           37778       33000        6000  
```

### drop操作闪回

示例（HEAP表）

```sql
ALTER SYSTEM SET RECYCLEBIN_ENABLED=ON;

DROP TABLE finance_info;
DROP TABLE orders_info;
DROP TABLE sales_info;
DROP TABLE employees;

-- 1.查询回收站是否存在finance_info表
SELECT original_name,object_name FROM DBA_RECYCLEBIN 
WHERE original_name IN ('FINANCE_INFO','ORDERS_INFO','SALES_INFO','EMPLOYEES');
ORIGINAL_NAME                 OBJECT_NAME
----------------------------- -----------------------
SALES_INFO                    BIN$2393
ORDERS_INFO                   BIN$2389
EMPLOYEES                     BIN$2385
FINANCE_INFO                  BIN$2408

-- 2.表结构及表数据闪回
FLASHBACK TABLE "BIN$2393" TO BEFORE DROP;
-- 或使用表的原始名称进行闪回
FLASHBACK TABLE finance_info TO BEFORE DROP;
-- 或通过RENAME TO命令指定表的新名称
FLASHBACK TABLE employees TO BEFORE DROP RENAME TO employees_recycle;

-- 3.验证相关对象是否保留系统生成的回收站名称，若名称未恢复，请使用ALTER INDEX语句手动修改
SELECT INDEX_NAME
FROM USER_INDEXES
WHERE TABLE_NAME = 'FINANCE_INFO';
INDEX_NAME
---------------------------------
IDX_FINANCE_INFO_1
```

### truncate操作闪回

示例（HEAP表）

```sql
ALTER SYSTEM SET RECYCLEBIN_ENABLED=ON;
TRUNCATE TABLE product;

-- 1.查询回收站是否存在product表
SELECT original_name,object_name FROM DBA_RECYCLEBIN WHERE original_name = 'PRODUCT';
ORIGINAL_NAME                 OBJECT_NAME
----------------------------- -----------------------
PRODUCT                       PRODUCT

-- 2.表数据闪回
FLASHBACK TABLE product TO BEFORE TRUNCATE;

-- 3.验证相关对象是否保留系统生成的回收站名称，若名称未恢复，请使用ALTER INDEX语句手动修改
SELECT INDEX_NAME
FROM USER_INDEXES
WHERE TABLE_NAME = 'PRODUCT';
INDEX_NAME
--------------------------
SYS_C_133
```
