本视图显示YFS中的磁盘故障组信息。

|  字段| 类型| 说明|
|---------------|-------------|----------------|
| GROUP_ID      | NUMBER      | 组ID            |
| GROUP_NODE_ID | NUMBER      | 组内节点ID         |
| INST_ID       | NUMBER      | 实例ID           |
|  ID   | INTEGER     | 故障组在其所属磁盘组内的ID   |
| GLOBAL_ID     | INTEGER     | 故障组的全局ID           |
| NAME          | VARCHAR(32) | 故障组的名称             |
| GROUP_NUMBER  | INTEGER     | 故障组的所属磁盘组ID         |
