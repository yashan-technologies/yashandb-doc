本视图显示 YFS 故障组（Failgroup）信息。

|  字段| 类型| 说明|
|---------------|-------------|----------------|
| GROUP_ID      | NUMBER      | 组ID            |
| GROUP_NODE_ID | NUMBER      | 组内节点ID         |
| INST_ID       | NUMBER      | 实例ID           |
| ID            | INTEGER     | Failgroup所属Diskgroup内的ID   |
| GLOBAL_ID     | INTEGER     | Failgroup在全局ID           |
| NAME          | VARCHAR(32) | 名称             |
| GROUP_NUMBER  | INTEGER     | 所属DiskGroup的ID |
