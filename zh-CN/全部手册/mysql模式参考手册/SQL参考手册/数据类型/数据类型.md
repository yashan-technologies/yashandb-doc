
YashanDB运行在mysql模式时，可以使用的数据类型及其规格如下表所示。

|  数据类型| 类型长度| 取值范围| 说明|
|-----------------------| ------------- |------------------------------------------------------------------------------------------------------------------------------|-------------------------------------|
| BOOL / BOOLEAN / TINYINT    | 1Byte           | -128 ~ 127                                                                                                                   | 为1B带符号整数类型。<br>对BOOLEAN类型插入数据时，0值表示FALSE，非0值表示TRUE。<br>如果BOOLEAN类型列的值为TRUE，数据库计算按1值处理；如果BOOLEAN类型列的值为FALSE，数据库计算按0值处理。             |
| TINYINT UNSIGNED      | 1Bytes            | 0 ~ 255                                                                                                                      | 为1B无符号整数类型。             |
| SMALLINT   | 2Bytes            | -2<sup>15</sup> (-32,768)  ~ 2<sup>15</sup> - 1 (32,767)                                                                     | 为2B带符号整数类型。                |
| SMALLINT UNSIGNED  | 2Bytes            | 0  ~ 2<sup>16</sup>  (65,535)                                                                                                | 为2B无符号整数类型。                |
| MEDIUMINT  | 4Bytes            | -2<sup>23</sup> (-8,388,608)  ~ 2<sup>23</sup> - 1 (8,388,607)                | MYSQL特有的4B带符号整数类型。                |
| MEDIUMINT UNSIGNED | 4Bytes      | 0 ~ 2<sup>24</sup>-1(16777215)    | MYSQL特有的4B无符号整数类型。                |
| INTEGER    | 4Bytes            | -2<sup>31</sup> (-2,147,483,648) ~ 2<sup>31</sup> - 1 (2,147,483,647)                                                        | 为4B有符号整数类型。            |
| INTEGER UNSIGNED   | 4Bytes            | 0 ~ 2<sup>32</sup> - 1 (4,294,967,295)                                                                                       | 为4B无符号整数类型。            |
| BIGINT     | 8Bytes            | -2<sup>63</sup> (-9,223,372,036,854,775,808) ~ 2<sup>63</sup>-1 (9,223,372,036,854,775,807)                                  | 为8B有符号整数类型。           |
| BIGINT UNSIGNED    | 8Bytes            | 0  ~ 2<sup>64</sup> - 1 (18,446,744,073,709,551,615)                                                                         | 为8B无符号整数类型。<br>SERIAL数据类型是BIGINT UNSIGNED NOT NULL AUTO_INCREMENT UNIQUE的别名。           |
| FLOAT      | 4Bytes            | 32位单精度浮点数<br>负数：-3.402823E38 ~ -1.401298E-45<br>正数：1.401298E-45 ~ 3.402823E38，0                                              | 表示单精度浮点数，在括号中规定最大位数，在d参数中规定小数点右侧的最大位数<br>BINARY_FLOAT/REAL为FLOAT的别名，行为完全同FLOAT   |
| FLOAT UNSIGNED   | 4Bytes    | 32位单精度浮点数。<br> 1.401298E-45 ~ 3.402823E38，0                 | 表示单精度浮点数，在括号中规定最大位数，在d参数中规定小数点右侧的最大位数<br>UNSIGNED指定后不能为负数   |
| DOUBLE     | 8Bytes            | 64位双精度浮点数<br>负数： -1.797693134862315807E308 ~ -4.94065645841247E-324<br>正数：4.94065645841247E-324 ~ 1.797693134862315807E308，0 | 表示双精度浮点数<br/>BINARY_DOUBLE为DOUBLE的别名，行为完全同DOUBLE           |
| DOUBLE UNSIGNED     | 8Bytes            | 64位双精度浮点数<br>4.94065645841247E-324 ~ 1.797693134862315807E308，0 | 表示双精度浮点数<br/>UNSIGNED指定后不能为负数           |
| DECIMAL    | 20Bytes           | NUMBER(p,s)<br>p：1 ~ 38<br>s：0 ~ 30，且s小于等于p                                                                       | 用于精度要求非常高的计算，以二进制存储，因此实际存储长度、与表达的数据范围需要换算<br>DECIMAL/NUMERIC为NUMBER的别名，行为完全同NUMBER          |
| DECIMAL UNSIGNED   | 20Bytes           | 0 ~ NUMBER(p,s)<br>p：1 ~ 38<br>s：0 ~ 30，且s小于等于p        | 用于精度要求非常高的计算，以二进制存储，因此实际存储长度、与表达的数据范围需要换算<br>UNSIGNED指定后不能为负数          |
| CHAR(SIZE)            | SIZE*字符最大宽度<br />最大值不超过255 | 无                                                                                                                       | CHARACTER为CHAR的别名，行为完全同CHAR           |
| VARCHAR(SIZE)         | SIZE字符最大长度和字符集相关：<br>- UTF8：21844<br>- UTF8MB3：21844<br>- UTF8MB4：21844<br>- ASCII：65534<br>- GBK：32767<br>- GB18030：16383<br>- BINARY：65534<br>- LATIN1：65534  | 无          | CHARACTER VARYING为VARCHAR的别名，行为完全同VARCHAR         |
| TINYTEXT     | 0-255字节         | 无                                                                                                                            | 暂不支持该类型数据进行比较                |
| TEXT  | 0-65535字节       | 无                                                                                                                            | 暂不支持该类型数据进行比较                |
| MEDIUMTEXT | 0-16777215字节    | 无                                                                                                                            | 暂不支持该类型数据进行比较                |
| LONGTEXT     | 0-4294967295字节  | 无                                                                                                                            | 暂不支持该类型数据进行比较                |
| TINYBLOB     | 0-255字节         | 无                                                                                                                            | 无                |
| BLOB  | 0-65535字节       | 无                                                                                                                            | 无                |
| MEDIUMBLOB | 0-16777215字节    | 无                                                                                                                            | 无                |
| LONGBLOB     | 0-4294967295字节  | 无                                                                                                                            | 无                |
| DATE       | 8Bytes            | 1-1-1 ~ 9999-12-31                                                                                                  | YYYY-MM-DD     |
| TIME       | 8Bytes            | -838:59:59.999999 ~ 838:59:59.999999                                                                                         | 时分秒 微秒<br>微秒精度范围为[0,6]，默认精度为0           |
| TIMESTAMP  | 8Bytes            | 1-1-1 00:00:00.000000 ~ 9999-12-31 23:59:59.999999                                                                           | 记录数据的日期时间，格式为YYYY-MM-DD HH24:MI:SS.FF，微秒精度范围为[0,6]，默认精度为0。<br>TIMESTAMP类型受系统变量explicit_defaults_for_timestamp影响：<br>- 变量值默认OFF，表示该字段不可为空值，建表时如未指定字段默认值，则插入数据时以当前系统时间插入，用法与指定列属性`DEFAULT CURRENT_TIMESTAMP`一致；如果同一张表中指定了多个TIMESTAMP列，仅第一个TIMESTAMP列写入系统时间，后续的列自动被赋予DEFAULT '0000-00-00 00:00:00'。<br>- 修改变量值为ON，表示TIMESTAMP类型无任何自动生成属性，所有属性必须显式指定。|
| DATETIME  | 8Bytes            | 1-1-1 00:00:00.000000 ~ 9999-12-31 23:59:59.999999                                                                           | 记录数据的日期时间，格式为YYYY-MM-DD HH24:MI:SS.FF，微秒精度范围为[0,6]，默认精度为0。 |
| BINARY(SIZE)          | 字节数<br />最大值不超过255 | 无          | 存储二进制格式数据，显示时将二进制格式数据打印为字符串；当插入数据长度小于额定长度时，会使用0x00右补位到额定长度                |
| VARBINARY(SIZE)       | 字节数<br />最大值不超过65534 | 无            | 存储二进制格式数据，显示时将二进制格式数据打印为字符串；插入数据长度小于额定长度时不进行补位                |
