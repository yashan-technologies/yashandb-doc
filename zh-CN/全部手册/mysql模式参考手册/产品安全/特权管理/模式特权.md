模式特权是指对数据库中某个特定模式（schema）下的所有对象（例如表、视图、存储过程等）进行管理和控制的权限，通常用于控制用户对该模式内资源的访问和操作权限。

|  权限名称| 描述|
| --- | --- |
| ALL               | 具备特定schema下所有模式特权                                               |
| GRANT OPTION      | 具备特定schema下授予拥有的权限                                               |
| SELECT            | 具备特定schema下查询任意表的权限                                             |
| INSERT            | 具备特定schema下对任意表进行插入数据的权限                                   |
| UPDATE            | 具备特定schema下对任意表进行更新数据的权限                                   |
| DELETE            | 具备特定schema下对任意表进行删除数据的权限                                   |
| CREATE            | 具备特定schema下创建任意表的权限                                             |
| DROP              | 具备特定schema下删除任意表的权限                                             |
| ALTER             | 具备特定schema下对任意表进行修改的权限                                       |
| INDEX             | 具备特定schema下任意索引的创建和删除的权限                                           |
| CREATE VIEW       | 具备特定schema下创建任意视图权限                                             |
| EXECUTE           | 具备特定schema下执行任意存储过程权限                                         |
| CREATE ROUTINE    | 具备特定schema下创建存储过程权限                                             |
| ALTER ROUTINE     | 具备特定schema下修改存储过程权限                                             |
| TRIGGER           | 具备特定schema下触发器操作权限                                               |
