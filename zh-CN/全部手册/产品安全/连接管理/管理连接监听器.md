YashanDB通过数据库实例内部的一个工作线程处理客户端发来的连接请求，该线程称为连接监听器。



连接监听器的工作模式分为：

- 正常运行模式：接受新的连接，默认为该模式，可通过ALTER SYSTEM语句进行模式调整。

- 维护模式：保持现有连接，阻止新的连接（sys用户发起的本地连接除外）。监听器进入维护模式后，将仅允许由sys用户发起的本地连接会话接入数据库，直到再次调整为正常运行模式或重启数据库。



DBA可基于当前连接负载、连接准入原则等多方面考虑，按需配置连接监听器的运行模式，从而实现在数据库不停机的情况下管控是否接受新的连接与会话。

1. 以DBA用户连接并登录数据库。
    ```shell
    $ yasql sales/********@192.168.1.2:1688
    YashanDB SQL Enterprise Edition Release {version_number} x86_64

    Connected to:
    YashanDB Server Enterprise Edition Release {version_number} x86_64 - Linux

    SQL> 
    ```


2. 执行[ALTER SYSTEM](../../开发手册/SQL参考手册/SQL语句/ALTER SYSTEM)语句调整连接监听器的运行模式，配置立即生效。

    ```sql
    -- 将连接监听器设置为维护模式
    ALTER SYSTEM LISTENER STOP;

    -- 将连接监听器设置为正常运行模式
    ALTER SYSTEM LISTENER START;
    ```

    将连接监听器设置为维护模式后，仅sys用户发起的本地连接可正常使用，其他场景则会提示`listener closed`。
