YashanDB支持通过yasldr工具导入向量数据。

yasldr支持导入文本格式、CLOB格式以及FVECS二进制格式的向量数据。当需要快速导入大量的向量数据时，通过FVECS二进制格式文件进行导入可以获得更高的导入效率。

文本格式和CLOB格式导入方式与普通业务数据导入时的操作类似，请参考[yasldr指导](../工具手册/yasldr/yasldr使用指导)进行操作。本章节重点介绍导入FVECS二进制格式的向量数据。

> **Note**:
>
> 由于FVECS二进制格式文件只能处理FLOAT32精度的向量数据，因此当需要处理FLOAT64位向量数据时，请通过文本格式或CLOB格式进行导入。

## 前提条件

已生成FVECS二进制格式的向量数据文件，每个FVECS文件只包含一个向量数据。[附：将向量文本生成FVECS二进制文件](#charToFvecs)提供了示例脚本。

本章节假设需导入两个向量，因此生成了两个向量文件`vector_1.fvecs`和`vector_2.fvecs`。

## 操作步骤

1. 以系统管理员身份连接数据库，创建导入操作用户并授予必要的权限：

```sql
-- 以管理员身份登录
$ yasql sys/*******@192.168.1.2:1688

-- 创建用户
CREATE USER vector_user IDENTIFIED BY "password";

-- 授予连接权限
GRANT CONNECT TO vector_user;

-- 授予资源权限
GRANT RESOURCE TO vector_user;
```

2. 以新创建的用户连接数据库，创建向量表：

```sql
-- 以vector_user用户登录
$ yasql vector_user/password@127.0.0.1:1688

-- 创建向量表
CREATE TABLE vector_table (
    id INT NOT NULL,
    embedding VECTOR(1024, FLOAT32)
) ORGANIZATION HEAP;
```

3. 在数据库服务器上准备需要导入的数据文件。以上述向量表为例，此处创建一个包含id列和向量列的dat文件。

```bash
$ vi /home/yasldr/vector.dat
1|vector_1.fvecs
2|vector_2.fvecs
```

4. 在数据库服务器本地目录下创建控制文件`load_vector.ctl`，内容如下：

```bash
$ vi /home/yasldr/load_vector.ctl
LOAD DATA INFILE '/home/yasldr/vector.dat'
FIELDS TERMINATED BY '|'
INTO TABLE vector_table
(
    id,
    file1 FILLER
    embedding LOBFILE(file1 format "fvecs") terminated BY eof
)
```

5. 使用yasldr工具执行FVECS向量数据导入，MODE必须设置为BASIC：

```bash
$ yasldr vector_user/password@127.0.0.1:1688 MODE=BASIC CONTROL_FILE=/home/yasldr/load_vector.ctl
YashanDB Loader Enterprise Edition Release {version_number} x86_64 a533f66
2 rows successfully loaded.
Check /home/yasdb/vector_table_stats.log for more info.
[YASLDR] execute succeeded
```

6. 导入完成后，验证数据是否正确导入。

```sql
-- 统计导入的向量数据行数
SQL> SELECT COUNT(*) FROM vector_table;

          COUNT(*)
-----------------
                2
```

## 附：将向量文本生成FVECS二进制文件

本示例假设已将3个向量数据分别写入3个文本文件。

```bash
cat '[1.0,2.0,3.0]' > vector_1.txt
cat '[4.0,5.0,6.0]' > vector_2.txt
cat '[7.0,8.0,9.0]' > vector_3.txt
```

通过python脚本示例将文本文件生成FVECS二进制文件的示例脚本如下。

```py
#!/usr/bin/env python3
"""
fvecs格式: 每个向量以4字节int32 (维度数, 小端序) 开头，后跟对应数量的4字节 float32 (小端序)
"""

import os
import struct


def parse_vector_text(text):
    """解析文本格式的向量 [val1, val2, ...]"""
    text = text.strip()
    if text.startswith("[") and text.endswith("]"):
        text = text[1:-1]
    values = []
    for v in text.split(","):
        v = v.strip()
        if v:
            values.append(float(v))
    return values


def write_fvecs(filename, vectors):
    """将向量列表写入 fvecs 二进制文件 (FLOAT32格式)"""
    with open(filename, "wb") as f:
        for vec in vectors:
            dim = len(vec)
            # 写入维度 (int32, 小端序)
            f.write(struct.pack("<i", dim))
            # 写入向量数据 (float32, 小端序)
            for val in vec:
                f.write(struct.pack("<f", val))


def read_vector_file(filepath):
    """读取文本向量文件"""
    with open(filepath, "r") as f:
        content = f.read()
    return parse_vector_text(content)


def main():
    base_dir = os.path.dirname(os.path.abspath(__file__)) or "."

    # 读取现有的向量文本文件并转换为fvecs
    # 向量文本文件内容格式：[1.0,2.0,3.0,.....,10.0]
    print("=== 生成fvecs文件 ===")
    vector_files = [
        ("vector_1.txt", "vector_1.fvecs"),
        ("vector_2.txt", "vector_2.fvecs"),
        ("vector_3.txt", "vector_3.fvecs"),
    ]

    for txt_file, fvecs_file in vector_files:
        txt_path = os.path.join(base_dir, txt_file)
        fvecs_path = os.path.join(base_dir, fvecs_file)

        print(f"生成 {fvecs_file}...")

        # 读取向量数据
        vector = read_vector_file(txt_path)
        print(f"  维度: {len(vector)}")

        # 写入 fvecs 文件
        write_fvecs(fvecs_path, [vector])
        print(f"  已写入: {fvecs_path}")

    print("\nfvecs 文件生成完成!")


if __name__ == "__main__":
    main()
```
