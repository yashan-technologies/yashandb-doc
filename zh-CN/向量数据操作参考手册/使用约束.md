使用崖山向量数据库时，存在如下约束：

|  约束项| 约束行为|
| ----------------------- |-------------------------------------------|
| 部署形态 | 支持单机（主备）部署、共享集群部署 |
| 语法模式 | 在yashan模式下使用|
| 表类型 | HEAP表 |
| 数据操作 | 支持通过SQL语句进行向量数据插入、更新和删除 |
| 索引|支持HNSW索引|
| PL对向量的支持|- 支持自定义函数和存储过程支持向量类型作为入参和出参，存储过程中向量类型大小不超过65534Bytes <br>- 不允许在自定义类型和触发器中使用向量类型 |
| 数据导入导出 | - 导入：支持通过yasldr批量导入向量数据 <br>- 导出：不支持 |
| 驱动接口 | 支持C驱动和Python驱动 |
| 运维管理 | 实例管理、文件管理、高可用、备份恢复等运维管理操作与通用的崖山数据库管理操作一致 |
| 数据迁移 | 不支持通过YStream或YMP进行向量表的数据迁移 |
