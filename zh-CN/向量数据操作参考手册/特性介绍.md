## 向量数据库是什么？

向量是一组用于表示一个对象的特征的非结构化数据，面向的对象可以是文档、图像、视频或音频文件等。相对传统成熟的结构化数据存储和计算，向量数据的处理计算则主要通过向量计算来查找对象数据中具有一定相似性的实体。

向量数据库是指能够原生存储和管理向量数据的数据库。

向量数据库填补了传统关系数据库在处理非结构化数据和语义理解方面的巨大鸿沟。  

## 崖山向量数据库介绍

崖山数据库在原有关系数据处理模型的基础上，将向量作为一种原生数据类型，支持向量数据存储、查询和相似性计算。这使得业务数据和语义数据的搜索变得更快、更精确。

这种在单一数据库中整合关系数据、JSON文档、图、地理空间数据、文本和向量的数据，避免了多种类型数据库管理所带来的数据一致性问题。

同时，崖山向量数据库针对常见CPU指令集进行了性能调优，向量计算性能卓越。

崖山向量数据库提供了以下能力特性：

- 向量数据类型：创建向量来描述非结构化数据的内容或特征。

- 向量索引：向量数据库使用向量索引以分层方式组织向量，以便高效搜索和检索。

    崖山数据库基于HNSW（Hierarchical NavigableSmall World）算法实现向量索引，其目的是在极大量的候选集当中如何快速地找到一个查询点的最近邻的k个元素。

    HNSW算法是目前工业界影响力最大的基于图的近似最近邻索引算法，是一种基于图的数据结构，它将节点划分成不同层级，遍历来自上层的元素，直到达到局部最小值，然后切换到下一层，以上一层中的局部最小值作为新元素重新开始遍历，直到遍历完最低一层。

- 向量查询：向量数据库使用查询向量执行向量距离运算。向量在数学上越接近，它们所代表的对象就越相似。

- 后处理：在向量数据库检索到查询向量的最近邻之后，支持对结果集的行进行重新排序。

## 核心工作流程

向量数据处理的主要工作流程如下：

1. 整理业务相关的同类非结构化数据，并完成清洗、标准化和格式化；
2. 通过嵌入模型（如BERT、CLIP、ResNet等）生成高维特征向量，并完成向量数据标准化；
3. 选择合适的向量数据库对高维向量数据进行存储管理，并与原始元数据进行关联；
4. 根据数据规模和性能需求创建合适的向量索引算法，崖山向量数据库支持HNSW索引。
5. 查询时，利用输入的向量值在数据库中查找相似的向量：
    - 余弦相似度
    - 欧几里得距离
    - 点积相似度
6. 对相似度结果进行排序，关联返回相似对象的原始数据。

## 使用场景

向量数据库的应用主要面向需要理解对象“内容”而非简单匹配关键词的领域。  

| 场景领域| 具体应用| 说明|
| ---------------------------------- | ------------------------------------------------ | ------------------------------------------------------------ |
| 搜索与推荐         | 语义搜索                | 用户用自然语言搜索（如“适合雨天的心情音乐”），系统理解意图，返回相关结果，而非仅匹配关键词。 |
|                                    | 个性化推荐                                   | 根据用户历史行为向量（代表兴趣）和内容向量，找到最匹配的新内容进行推荐。 |
|                                    | 电商搜索                                     | 拍照搜同款、用文字描述找商品（如“带有复古花纹的陶瓷杯”）。   |
| AI与机器学习                  | 大语言模型（LLM）增强                        | 检索增强生成 的核心组件。为LLM提供实时、准确的外部知识库，解决其“幻觉”和知识陈旧问题。 |
|                                    | 多模态AI                                     | 统一处理文本、图像、视频，实现“以文搜图”、“以图搜视频”等跨模态检索。 |
|                                    | 模型特征库                                   | 存储和快速检索机器学习模型生成的特征向量，用于比对和推理。   |
| 内容与知识管理                 | 企业智能知识库                               | 将内部文档、邮件、会议纪要向量化，员工可像咨询专家一样自然提问获取信息。 |
|                                    | 内容去重与版权保护                           | 通过向量比对，发现高度相似的图片、文章或视频，识别抄袭或重复内容。 |
|                                    | 智能客服与问答                               | 从海量问答对、文档中快速定位与用户问题语义最匹配的答案。     |
| 生物信息与安全                 | 人脸识别/生物识别                            | 将人脸特征存储为向量，实现毫秒级比对和身份验证。             |
|                                    | 欺诈检测                                     | 将用户交易行为向量化，快速识别与已知欺诈模式相似的异常行为。 |
|                                    | 药物发现                                     | 将分子结构表示为向量，在浩瀚的化合物库中寻找具有相似药理特性的候选分子。 |

## 核心优势

崖山向量数据库相比传统关系数据库，具有如下优势：

| 优势维度| 具体说明| 优势对比|
| ------------------ | ------------------- | ----------------- |
| 高效的相似性搜索                               | 使用HNSW高级索引算法，在十亿级向量中实现毫秒级检索。 | 传统数据库的B-Tree索引无法有效支持高维向量的相似度计算（如余弦相似度），只能做精确匹配，性能极差。 |
| 强大的语义理解能力                             | 基于向量距离（如欧氏距离、内积）衡量数据间的语义相似性，而非字面匹配。 | 传统关键词搜索无法处理“同义词”（如“电脑”和“笔记本电脑”）或“语义关联”（如“国王”和“王后”）。 |
| 天然支持高维、非结构化数据                     | 数据模型、查询语言、存储引擎都围绕向量设计，无缝集成AI工作流。 | 传统数据库需将向量存储为BLOB或数组，无法建立有效索引，查询时必须全表扫描，性能无法接受。 |
| 灵活性                                         | 通常采用无模式或动态模式，方便快速迭代和添加新类型的数据向量。 | 关系型数据库需要预定义严格的表结构，变更成本高。             |
