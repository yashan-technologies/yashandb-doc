## 向量类型

定义数据列为向量类型时，语法规则如下：

```ebnf
col_definition = column_name VECTOR "(" dimension, format ")".
```

| 项| 描述|
| -------------- | ------------------------------------------------------------ |
| 维度 | (0-65535] |
| 数据类型 | FLOAT32, FLOAT64 |
| 存储格式 | DENSE |
| DML | - 支持向量类型的增删改；<br>- 查询支持order by, fetch, limit, 精确查询向量列；<br>- 支持向量函数和向量运算符。 |

**使用约束**

- 仅支持在HEAP表上使用向量类型；
- 不允许在vector上创建check/unique/primary key约束，支持增加not null约束；
- 不允许表的向量列指定default值；
- 不允许ALTER TABLE MODIFY向量列的数据类型、维度信息，支持modify null/visible属性；
- 不允许向量列指定列加密；
- 不允许向量列作为表分区的分区列；
- 不支持向量类型定义UDT；
- 向量列计算不支持DISTINCT, COUNT, ORDER BY, GROUP BY, JOIN操作，也不支持集合操作（UNION ALL除外）；
- 向量列不支持比较运算符（>, <, =, !=）。

YashanDB支持向量数据与字符类型或CLOB进行转换，可以通过显示指定转换函数进行转换，也支持隐式转换。

- 在INSERT、UPDATE以及向量运算场景，如果入参与目标参数数据类型不一致，会自动进行隐式转换，支持CHAR/VARCHAR/CLOB类型与向量类型的隐式转换；
- 支持通过TO_VECTOR/VECTOR函数将VARCHAR/CLOB类型数据转换为VECTOR类型，向量维度以入参维度为准，向量值数据类型默认为FLOAT32；
- 支持通过TO_VECTOR/VECTOR函数转换原向量数据的维度值以及向量值数据类型；
- 支持通过FROM_VECTOR函数将向量数据转换为VARCHAR或者CLOB类型数据。

使用向量类型创建向量表的示例SQL如下所示：

```sql
CREATE TABLE vector_table(
    doc_id BIGINT NOT NULL,
    chunk_id BIGINT NOT NULL,
    content VARCHAR(4000),
    embedding VECTOR(1024, FLOAT32)
) ORGANIZATION HEAP;
```

## 向量索引

| 项| 描述|
| -------- | ------------------------------------------------------------ |
| 索引类型 | HNSW |
| 存储方式 | 磁盘索引 |
| 维度 | (0-65535] |
| 度量 | COSINE, EUCLIDEAN, DOT,  EUCLIDEAN_SQUARED |
| 参数 | - neighbors: [2, 100]，默认值16；<br>- efConstruction: [4, 1000]，默认值64；<br>- efSearch: [1, 1000]，默认为40； |
| DDL | - 支持CREATE/DROP向量索引；<br>- 支持ALTER向量索引； |
| DML | - 支持增量的增删改等DML操作； <br>- 支持向量索引强事务一致性； |

**使用约束**

- 不允许在一张表上创建多个向量索引；
- 不允许创建带vector列的函数索引；
- 不允许创建、rebuild HNSW向量索引时指定ONLINE选项；
- 不允许在全局临时表上创建HNSW向量索引。
