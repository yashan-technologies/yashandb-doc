当YashanDB部署为容器数据库（配置参数ENABLE_PLUGGABLE_DATABASE=TRUE）时，依托[yasrman工具](../../../工具手册/yasrman/00yasrman.md)可对整个CDB或任意数量的PDB的数据备份和恢复。按照实际部署模式和使用场景，可灵活运维数据备份管理，高效的保障数据安全。

## CDB级备份与恢复

CDB级备份与恢复能力旨在提供全局统一的运维管理能力，其核心价值主要体现在以下几个方面：

- 整体性数据保护：提供一站式全数据库保护能力，可同时备份根容器和所有PDB的数据及元数据。这种整体性保护确保在灾难发生时能快速恢复整个多租户环境，大幅简化备份管理复杂度。

- 高效的运维管理：通过CDB级统一备份，管理员无需逐个PDB进行备份操作，显著减少备份作业数量和管理成本。一次备份操作即可完成整个容器数据库的保护，运维效率提升数十倍，特别适用于大规模多租户环境。

- 一致性的数据恢复：CDB级备份确保所有PDB在同一时间点的数据一致性，避免因逐个PDB备份导致的时间差问题。恢复时能保证整个多租户环境的数据完整性，满足严格的业务连续性要求。

- 简化的灾难恢复：当发生重大系统故障或数据中心级灾难时，CDB级恢复可快速重建整个多租户环境，包括所有租户的数据。这种"一键式"恢复能力大幅缩短灾难恢复时间，降低业务中断风险。

- 成本优化的存储管理：通过统一备份策略，可实现备份数据的集中存储和管理，充分利用存储资源，避免重复备份造成的存储浪费。同时支持增量备份和压缩技术，进一步优化存储成本。

CDB级别的备份与恢复均需**连接根容器**操作，具体的命令关键字如下：

| 待操作对象 | 备份命令 | 恢复命令 |
|-------------------------|--------------------------------------|-------------------------|
| 整个CDB（包括根容器、种子容器以及所有PDB）的控制文件、数据文件、redo日志文件以及部分归档日志文件 | BACKUP DATABASE | RESTORE DATABASE |
| 整个CDB（包括根容器、所有PDB）的归档日志文件 | BACKUP ARCHIVELOG | RESTORE ARCHIVELOG |
| 根容器的控制文件、数据文件、redo日志文件以及部分归档日志文件 | BACKUP DATABASE ROOT | RESTORE DATABASE ROOT |
| 根容器的归档日志文件 | BACKUP ARCHIVELOG ROOT | RESTORE ARCHIVELOG ROOT |
| 种子容器或指定PDB的控制文件、数据文件、redo日志文件以及部分归档日志文件 | BACKUP PLUGGABLE DATABASE | RESTORE PLUGGABLE DATABASE<br /> |
| 指定PDB的归档日志文件 | BACKUP PLUGGABLE ARCHIVELOG | 直连目标PDB执行RESTORE ARCHIVELOG |

>**Note**:
>
> - 不能同时对同一个数据库对象执行备份，直连根容器执行全库备份命令时，不论是BACKUP DATABASE、BACKUP DATABASE ROOT或BACKUP PLUGGABLE DATABASE，除指定目标外均会备份根容器实例。
>
> - 种子容器默认处于关闭状态且只能以只读模式启动，不会产生归档日志，因而无法也无需单独备份其归档日志文件。

## PDB级备份与恢复

PDB级备份与恢复旨在提供租户级运维管理能力，其核心价值主要体现在以下几个方面：

- 租户自治的数据保护：PDB级备份赋予每个租户独立的数据保护能力，租户可根据自身业务需求和服务等级协议（SLA，Service Level Agreement）要求制定个性化备份策略。这种自治模式满足了不同租户对数据保护频率、保留周期和恢复点目标（RPO）的差异化需求。

- 精准的资源控制：通过PDB级备份操作，可精确控制备份资源使用，避免大租户频繁备份影响小租户正常业务。管理员可为不同规模的PDB分配相应备份窗口和资源配额，实现资源合理分配和优化利用。

- 高效的故障恢复：当某个PDB出现数据损坏或逻辑错误时，PDB级备份支持对该租户进行独立恢复，无需影响其他PDB正常运行。这种精准恢复能力大幅缩短故障恢复时间，提高业务连续性保障水平。

- 灵活的业务支持：PDB级备份支持按需备份和恢复，特别适用于租户迁移、测试环境搭建、数据分析等场景。租户可随时对数据进行独立备份操作，为业务创新和数据利用提供便利。

- 成本优化的备份策略：通过PDB级备份管理，可根据各租户重要性和数据变化频率制定差异化备份策略。重要租户采用高频备份，一般租户采用低频次备份策略，在保证数据安全前提下实现备份成本最优化。

PDB级备份与恢复主要是指**直连目标PDB**进行操作，其[操作方式](../yasrman工具备份恢复/00yasrman工具备份恢复.md)同非容器数据库一致，具体的命令关键字如下：

| 待操作对象 | 备份命令 | 恢复命令 |
|-------------------------|-------------|-------------------------|
| 当前PDB的控制文件、数据文件、redo日志文件以及部分归档日志文件 | BACKUP DATABASE | RESTORE DATABASE<br />无法执行PITR恢复 |
| 当前PDB中目标表空间的数据文件 | BACKUP TABLESPACE | RESTORE TABLESPACE |
| 当前PDB的归档日志文件 | BACKUP ARCHIVELOG | RESTORE ARCHIVELOG |
