## 配置连接监听

通过设置LSNR_LOG参数可以控制监听日志记录的启动和关闭，默认为开启。

```sql
-- 查看当前监听是否打开
SHOW PARAMETER LSNR_LOG;
NAME             VALUE     
---------------- ----------
LSNR_LOG         ON        

-- 关闭监听
ALTER SYSTEM SET LSNR_LOG= OFF SCOPE=SPFILE;

-- 开启监听
ALTER SYSTEM SET LSNR_LOG= ON SCOPE=SPFILE;
```

开启时，所有对YashanDB的连接请求（包括远程TCP连接和UDS本地连接，且不论成功与否）都将记录在监听日志中。

## 监听日志管理

在YashanDB产品安装过程中会自动在$YASDB_HOME/log/listener文件夹中创建监听日志文件listener.log。连接监听开启后时，所有的连接信息均会被记录在listener.log文件中，包括连接成功和连接失败的记录。

### 查看日志内容

使用安装用户登录数据库所在服务器，进入监听日志文件的存放路径查看对应的文件。

```shell
$ cd $YASDB_DATA/log/listener
$ ls -lrt
total 4
-rw-r----- 1 yashan yashan 2274 Mar 23 11:45 listener.log

$ cat listener.log
```

#### 远程连接相关监听日志

YashanDB远程连接遵循TCP/IP协议，监听日志中会记录时间戳、TCP协议、IP、端口号、用户名和连接状态信息，如下所示：

```verilog
2022-11-02 17:58:47.357 protocal = TCP  ip = 127.0.0.1 port = 60607 user = SALES status = SUCCESS
2022-11-02 17:59:59.414 protocal = TCP  ip = 127.0.0.1 port = 60693 user = SALES status = ERROR
```

#### UDS本地连接相关监听日志

YashanDB的UDS本地连接遵循IPC协议，监听日志中会记录时间戳、IPC协议、用户名和连接状态信息，如下所示：

```verilog
2022-11-02 18:02:06.839 protocal = IPC  user = SYS status = SUCCESS
2022-11-02 18:50:34.438 protocal = IPC  user = SYS status = ERROR
```

### 配置自动清理策略

默认情况下，监听日志文件大小没有上限，当listener.log文件过大时可能会占用过多磁盘容量造成浪费，需根据实际情况对物理文件进行手动编辑删减。

为简化运维，YashanDB提供了监听日志的自动清理机制，在相关参数配置符合业务需求的情况下，不再需要人为介入。

| 参数名称| 参数描述| 默认值|
| --------------------------- | ------------------------------------------------------------ | ------------------------ |
| LISTENER_LOG_ENABLED        | 是否对监听日志进行自动清理：<br />- TRUE：进行自动清理。<br />- FALSE：不进行自动清理。 | FALSE                    |
| LISTENER_LOG_FILE_SIZE      | 仅当LISTENER_LOG_ENABLED=TRUE时，该参数生效。<br />单个监听日志文件的最大大小，当文档容量触达该上限值时，自动将其归档，归档后的文件名称为listener-YYYYMMDDHHMMSS.log。 | 20M                      |
| LISTENER_LOG_FILE_COUNT     | 仅当LISTENER_LOG_ENABLED=TRUE时，该参数生效。<br />监听日志文件的总个数，即1个正在使用中的listener.log文件和N-1个归档后的listener-YYYYMMDDHHMMSS.log文件。<br />当文件数量触达该上限值时，自动清理最早的listener-YYYYMMDDHHMMSS.log文件。 | 10                       |

1. 以DBA用户连接并登录数据库。
    ```shell
    $ yasql sales/********@192.168.1.2:1688
    YashanDB SQL Enterprise Edition Release {version_number} x86_64

    Connected to:
    YashanDB Server Enterprise Edition Release {version_number} x86_64 - Linux

    SQL> 
    ```


2. 查看相关参数配置。

    ```sql
    SELECT NAME,VALUE FROM V$PARAMETER WHERE NAME LIKE 'LISTENER_LOG_%';
    NAME                               VALUE
    ---------------------------------------------------------------- ----------------------------------------------------------------
    LISTENER_LOG_ENABLED                                             FALSE
    LISTENER_LOG_FILE_COUNT                                          10
    LISTENER_LOG_FILE_SIZE                                           20M
    ```

3. 按需配置自动清理策略。

    ```sql
    -- 开启自动清理
    ALTER SYSTEM SET LISTENER_LOG_ENABLED=TRUE SCOPE=SPFILE;
    
    -- 调整单个监听日志文件的容量大小
    ALTER SYSTEM SET LISTENER_LOG_FILE_SIZE=40M SCOPE=SPFILE;
    
    -- 调整监听日志文件的总个数
    ALTER SYSTEM SET LISTENER_LOG_FILE_COUNT=15 SCOPE=SPFILE;
    ```
