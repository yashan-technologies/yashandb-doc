YashanDB默认会记录监听日志，记录与否的开关由`LSNR_LOG`参数的取值控制，默认`LSNR_LOG = ON`。非必要不建议关闭监听日志，若当前已关闭该功能，可参考[管理监听日志配置](../../../产品安全/连接管理/管理连接监听器.md#LSNR_LOG)按需开启。

开启时，所有对YashanDB的连接请求（包括远程TCP连接和UDS本地连接，且不论成功与否）都将记录在监听日志中。

## 查看日志内容

监听日志文件listener.log存放在$YASDB_DATA/log/listener文件夹中。使用安装用户登录数据库所在服务器即可查看日志文件。

```shell
$ cd $YASDB_DATA/log/listener
$ ls -lrt
total 4
-rw-r----- 1 yashan yashan 2274 Mar 23 11:45 listener.log

$ cat listener.log
```

### 远程连接相关监听日志

YashanDB远程连接遵循TCP/IP协议，监听日志中会记录时间戳、TCP协议、IP、端口号、用户名和连接状态信息，如下所示：

```verilog
2022-11-02 17:58:47.357 protocal = TCP  ip = 127.0.0.1 port = 60607 user = SALES status = SUCCESS
2022-11-02 17:59:59.414 protocal = TCP  ip = 127.0.0.1 port = 60693 user = SALES status = ERROR
```

### UDS本地连接相关监听日志

YashanDB的UDS本地连接遵循IPC协议，监听日志中会记录时间戳、IPC协议、用户名和连接状态信息，如下所示：

```verilog
2022-11-02 18:02:06.839 protocal = IPC  user = SYS status = SUCCESS
2022-11-02 18:50:34.438 protocal = IPC  user = SYS status = ERROR
```

## 日志清理与归档

listener.log文件大小不设上限，文件过大时可能会占用过多磁盘容量造成浪费，需根据实际情况对物理文件进行手动编辑删减或按需归档。
