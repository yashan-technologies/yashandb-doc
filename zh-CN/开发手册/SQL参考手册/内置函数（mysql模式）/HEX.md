```ebnf+diagram
hex::= HEX "(" (str|N) ")"
```

HEX函数将对输入的字符串或数字进行十六进制转换，函数返回字符串的十六进制形式或返回数值的十六进制。

本函数遵循如下规则：

- 对不能直接以bigint表示的数据报错或强制转换成bigint后统一处理。
- 将N视为BIGINT（小数四舍五入），实际有效上界2^64-1，实际有效下界-2^63，超过上界后输出对应二进制全为1，超过下界后输出对应二进制除符号位外全0。正数输出无符号整数对应二进制的十六进制，负数输出补码对应二进制的十六进制。
- 入参若为NULL，则函数返回NULL。

示例（单机HEAP表）

```sql

SELECT HEX('YASHAN');

hex('YASHAN')
-------------
59415348414E


SELECT HEX(b'1111111111111111111111111111111111111111111111111111111111111110') col1;

col1 
---------------------------------------------------------------- 
FFFFFFFFFFFFFFFE                                                

```
