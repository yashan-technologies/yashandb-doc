```ebnf+diagram
time::= TIME "(" expr ")"
```

TIME函数提取[expr](../通用SQL语法/expr)的时间部分数值，函数返回值为TIME类型。

当expr的值为数值型时，expr的值域为-8385959.999999-8385959.999999。对任一数值，TIME函数会取整数部分的最低2位为秒值，中间2位为分钟值，最高3位为小时值，小数部分最多保留6位，若位数不足将补0。由数值获得的小时、分钟、秒值，需符合限制条件，即小时值介于0-838之间、分钟值介于0-59之间、秒值介于0-59之间、微秒值介于0-999999之间。

当expr的值为字符型时，其格式必须符合以下规范：

*   字符型1：字符串可被转换为数值。此时等同于TIME函数对数值的处理。
*   字符型2：'yyyy-mm-dd hh24:mi:ss.ff'格式的字符串，需符合年、月、日、小时、分、秒的限制条件，即年值介于0-9999之间、月份值介于1-12之间、日期值介于1-31之间、小时值介于0-23之间、分钟值介于0-59之间、秒值介于0-59之间。此时TIME函数仅提取'hh24:mi:ss.ff'格式对应的内容。该字符型中'hh24:mi:ss.ff'对应的字符串可从后向前省略部分，字符串前可含有负号，但函数返回的结果中不含负号。
*   字符型3：'hh838:mi:ss.ff'格式的字符串，该字符串可从后向前省略部分，需符合分、秒的限制条件，即分钟值介于0-59之间、秒值介于0-59之间。此时小时值介于0-838之间，分隔符只可使用`':'`，字符串前可含有负号，并且函数返回的结果包含负号。

示例（单机HEAP表）

```sql
SELECT TIME('-13:24:56.66') res FROM DUAL;
RES
--------------------
-13:24:56.660000

 
SELECT TIME(8385959) res FROM DUAL;
RES
--------------------
838:59:59.000000

 
SELECT TIME('2012-3-18') res FROM DUAL;

[1:13]YAS-00008 type convert error : incorrect time value
 
SELECT TIME('2012-3-18 14') res FROM DUAL;
RES 
--------------------
14:00:00.000000
```
