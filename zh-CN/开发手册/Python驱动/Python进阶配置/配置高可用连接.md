Python驱动支持多地址连接，实现高可用和负载均衡，包括主备类型连接、负载均衡类型连接、连接池高可用和连接超时配置。

## 多地址连接

### 主备类型连接

连接多个数据库节点，主节点故障时自动切换到备节点。

```python
# 主备类型连接
dsn = "PRIMARY:192.168.1.1:1688,192.168.1.2:1688,192.168.1.3:1688"
conn = yaspy.connect(user="username", password="password", dsn=dsn)

# 或者使用简写格式
dsn = "192.168.1.1:1688,192.168.1.2:1688,192.168.1.3:1688"
conn = yaspy.connect(user="username", password="password", dsn=dsn)
```

### 负载均衡类型连接

使用负载均衡模式，连接会分散到多个节点。

```python
# 负载均衡类型连接
dsn = "LOADBALANCE:192.168.1.1:1688,192.168.1.2:1688,192.168.1.3:1688"
conn = yaspy.connect(user="username", password="password", dsn=dsn)
```

## 连接池高可用

在连接池中使用多地址连接，实现高可用。

```python
# 连接池 + 高可用
pool = yaspy.SessionPool(
    user="username",
    password="password",
    dsn="192.168.1.1:1688,192.168.1.2:1688,192.168.1.3:1688",
    min=1,
    max=4,
    increment=1,
    getmode=1
)

# 获取连接
conn = pool.acquire()

# 使用连接（假设example_table已存在）
cursor = conn.cursor()
cursor.execute("SELECT * FROM example_table")
rows = cursor.fetchall()
print(f"Retrieved {len(rows)} rows")
```

## 超时配置

> **Note**:
>
> 超时参数由YAC底层解析，非`yaspy.connect()`的直接形参。以下参数名（如`connectTimeout`、`poolTimeout`）仅供参考，实际支持的超时参数名及取值范围需与YAC产品文档核对。在部分YAC版本中可能不被识别，调用时可能报错`YAS-08057 invalid connect param name`。建议在生产环境使用前先做兼容性测试。

### connectTimeout - 连接超时

connectTimeout用于设置建立连接时socket连接的超时时间，单位为秒，默认值为10秒。超时配置需在DSN连接串中设置，示例：

```python
# 设置连接超时（在DSN中通过连接参数配置）
# 注意：当前环境connect_timeout / connectTimeout 参数可能不被支持
# 调用时可能报错YAS-08057 invalid connect param name
# 建议在生产环境使用前先做兼容性测试
conn = yaspy.connect(
    dsn="192.168.1.2:1688",
    user="sales",
    password="sales"
)
```

### poolTimeout - 多地址连接超时

poolTimeout用于设置多地址连接的超时时间，仅适用于多地址连接场景（primary类型或standby类型）。在整个连接过程中，即便快速遍历完所有地址且所有地址均未连接成功，系统仍会等待poolTimeout时长后才提示连接失败，默认值为300秒。超时配置需在DSN连接串中设置，示例：

```python
# 多地址连接场景下，设置连接池超时（在DSN中通过连接参数配置）
# 注意：当前环境 pool_timeout / poolTimeout 参数可能不被支持
# 调用时可能报错 YAS-08057 invalid connect param name
# 建议在生产环境使用前先做兼容性测试
conn = yaspy.connect(
    dsn="192.168.1.1:1688,192.168.1.2:1688,192.168.1.3:1688",
    user="sales",
    password="sales"
)
```
