本章节介绍Python驱动的各种连接配置方式。

## 连接参数

> **Note**：
>
> - `yaspy.connect()`的`dsn` 参数支持两种格式：
>   - 完整格式：`user/password@host:port`（用户名和密码合并在dsn中）
>   - 简化格式：`host:port`（用户名和密码通过独立的`user`和`password`参数指定）
> - `SessionPool`的`dsn`参数**仅支持**`host:port`格式，用户名和密码必须通过独立的`user`和`password`参数指定。

| 参数     | 说明     |
| -------- | ------------------------------|
| dsn      | 数据源名称。对于connect()：支持`user/password@host:port`或`host:port`格式；对于SessionPool：仅支持`host:port`格式 |
| user     | 数据库用户名（SessionPool必填；connect()可选，若dsn中未指定则必填）   |
| password | 数据库密码（SessionPool必填；connect()可选，若dsn中未指定则必填）   |

## 连接方式

### 方式一：使用DSN连接（推荐）

DSN是一种将连接信息整合为单一字符串的连接方式，格式为"用户名/密码@主机:端口"。适用于大多数应用场景。

```python
# 方式一：直接在dsn中包含用户名和密码
conn = yaspy.connect(dsn="sales/sales@192.168.1.2:1688")

# 方式二：dsn只包含主机和端口，用户名密码单独传入
conn = yaspy.connect(
    dsn="192.168.1.2:1688",
    user="sales",
    password="sales"
)
```

### 方式二：使用连接池连接

连接池是一种管理数据库连接的机制，通过预先建立并维护一定数量的连接对象，来提高数据库访问效率。适用于高并发Web应用、频繁数据库操作的场景，可以减少连接创建销毁的开销。

```python
pool = yaspy.SessionPool(
    user="sales",
    password="sales",
    dsn="192.168.1.2:1688",
    min=1,
    max=4
)
conn = pool.acquire()
```
