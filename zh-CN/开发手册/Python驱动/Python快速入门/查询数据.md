使用游标对象执行SQL语句并获取查询结果，游标对象是执行SQL语句和获取结果的核心对象。

## 执行查询

```python
# 创建游标
cursor = connection.cursor()

# 执行查询（使用命名绑定）
cursor.execute("SELECT * FROM example_table WHERE id = :id", {"id": 1})
```

## 查询单条数据

使用fetchone()方法获取结果集中的下一条记录。

```python
cursor = connection.cursor()

# 执行查询
cursor.execute("SELECT * FROM example_table WHERE id = 1")

# 获取单条数据
row = cursor.fetchone()
print(row)

cursor.close()
```

## 查询多条数据

使用fetchall()方法获取结果集中的所有记录。

```python
cursor = connection.cursor()

# 执行查询
cursor.execute("SELECT * FROM example_table")

# 获取所有数据
rows = cursor.fetchall()
for row in rows:
    print(row)

cursor.close()
```

## 批量获取数据

使用fetchmany()方法获取指定数量的记录。

```python
cursor = connection.cursor()

# 执行查询
cursor.execute("SELECT * FROM example_table")

# 每次获取5条记录
while True:
    rows = cursor.fetchmany(5)
    if not rows:
        break
    for row in rows:
        print(row)

cursor.close()
```

## 使用游标迭代

游标对象是可迭代的，可以直接用于循环。

```python
cursor = connection.cursor()

# 执行查询
cursor.execute("SELECT * FROM example_table")

# 使用游标迭代
for row in cursor:
    print(row)

cursor.close()
```

## 使用fetchone循环获取

```python
cursor = connection.cursor()

# 执行查询
cursor.execute("SELECT * FROM example_table")

# 使用fetchone循环获取
row = cursor.fetchone()
while row:
    print(row)
    row = cursor.fetchone()

cursor.close()
```

## 获取列信息

通过description属性获取结果集的列信息（列名、类型等）。

```python
cursor = connection.cursor()

# 执行查询
cursor.execute("SELECT id, name, created_at FROM example_table")

# 获取列信息
for desc in cursor.description:
    print(desc)
# 输出示例：FetchInfo(name='id', type_code=<class 'int'>, ...)

cursor.close()
```

> **Note**：
>
> `cursor.description`中的每个元素是`FetchInfo`对象，包含`name`（列名）、`type_code`（列类型）等属性，而非简单的元组。可以通过`desc.name` 获取列名。

## 完整示例

```python
import yaspy

try:
    # 连接数据库
    conn = yaspy.connect(dsn='sales/sales@192.168.1.2:1688')

    # 创建游标
    cursor = conn.cursor()

    # 执行查询（使用命名绑定）
    cursor.execute("SELECT id, name, created_at FROM example_table WHERE status = :status", {"status": 1})

    # 查看返回行数
    print(f"Total rows: {cursor.rowcount}")

    # 查看列信息
    print("Column info:")
    for desc in cursor.description:
        print(f"  {desc[0]}: {desc[1]}")

    # 获取所有数据
    rows = cursor.fetchall()

    # 打印结果
    for row in rows:
        print(f"ID: {row[0]}, Name: {row[1]}, Created: {row[2]}")

    # 关闭游标
    cursor.close()

    # 关闭连接
    conn.close()

except Exception as e:
    print(f"Error: {e}")
```

执行：

```python
$ python query_example.py
Total rows: 0
Column info:
  CUSTOMER_ID: FetchInfo(name='CUSTOMER_ID', type_code=12, ...)
  TOTAL_ORDERS: FetchInfo(name='TOTAL_ORDERS', type_code=4, ...)
ID: C001, Total Orders: 5
```

其中：
- Total rows：返回的行数。**对于SELECT语句，rowcount通常为0或-1**，这是DB-API的规范行为，实际行数需通过`fetchall()`等方法获取后通过`len()`获取。
- Column info：列信息，每个元素为`FetchInfo`对象，`name`属性为列名，`type_code`为列类型代码。
- ID: C001, Total Orders: 5：查询返回的实际数据。
