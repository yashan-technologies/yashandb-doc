提交事务将挂起的更改保存到数据库。默认情况下，YashanDB Python驱动处于手动提交模式（autocommit=False），每条SQL语句需要手动调用commit()进行提交。

```python
# 查看自动提交状态
print(connection.autocommit)

# 开启自动提交
connection.autocommit = True

# 关闭自动提交（恢复手动提交模式）
connection.autocommit = False
```

## 完整示例

```python
import yaspy

try:
    # 连接数据库
    conn = yaspy.connect('sales/sales@192.168.1.2:1688')

    # 查看默认autocommit状态
    print(f'Default autocommit: {conn.autocommit}')
    # Default autocommit: False

    cursor = conn.cursor()

    # 创建测试表
    cursor.execute('DROP TABLE IF EXISTS test_commit')
    cursor.execute('CREATE TABLE test_commit (id INT, name VARCHAR(50))')
    conn.commit()
    print('Table created')

    # 手动提交模式下插入数据
    cursor.execute("INSERT INTO test_commit VALUES (1, 'Alice')")
    cursor.execute("INSERT INTO test_commit VALUES (2, 'Bob')")
    conn.commit()
    print('Records committed')

    # 查询验证数据
    cursor.execute('SELECT * FROM test_commit ORDER BY id')
    rows = cursor.fetchall()
    print(f'Total records: {len(rows)}')
    for row in rows:
        print(f'  ID: {row[0]}, Name: {row[1]}')

    # 清理测试表
    cursor.execute('DROP TABLE test_commit')
    conn.commit()
    print('Test table cleaned up')

    cursor.close()
    conn.close()
    print('Connection closed')

except Exception as e:
    print(f'Error: {e}')
```

执行：

```python
Default autocommit: False
Table created
Records committed
Total records: 2
  ID: 1, Name: Alice
  ID: 2, Name: Bob
Test table cleaned up
Connection closed
```

其中：
- Default autocommit: False：默认autocommit为False（手动提交模式）
- Table created：表创建成功
- Records committed：记录提交成功
- Total records: 2：查询返回的记录总数
- Test table cleaned up：测试表清理完成
