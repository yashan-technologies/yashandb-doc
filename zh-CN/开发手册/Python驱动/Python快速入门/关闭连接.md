正确关闭数据库连接是良好的编程习惯。

> **Note**
>
> - 关闭连接池会切断池中所有连接，请确保已结束所有使用中的连接操作。
> - 使用连接池时，正确的关闭顺序为：先调用`pool.release(connection=conn)`归还连接，再调用`pool.close()`关闭连接池。**请勿在未归还连接的情况下直接调用`pool.close()`**，否则可能导致连接未正确释放。

## 完整示例

```python
import yaspy

# 创建连接（独立连接模式）
connection = yaspy.connect(dsn="sales/sales@192.168.1.2:1688")
print("Connection created")

# 创建游标
cursor = connection.cursor()
print("Cursor created")

# 创建测试表并插入数据
cursor.execute("CREATE TABLE IF NOT EXISTS example_table (id INT, name VARCHAR(50))")
cursor.execute("INSERT INTO example_table VALUES (1, 'test')")
connection.commit()

# 执行查询操作
cursor.execute("SELECT * FROM example_table")
result = cursor.fetchall()
print(f"Query result: {result}")

# ========== 关闭游标 ==========
cursor.close()
print("Cursor closed")

# ========== 关闭连接 ==========
connection.close()
print("Connection closed")

# ========== 关闭连接池（仅连接池模式使用） ==========
# 如果使用连接池（SessionPool），需要额外关闭连接池
# pool.close()
# print("Connection pool closed")
```

执行：

```python
$ python close_example.py
Connection created
Cursor created
Query result: [(1, 'test')]
Cursor closed
Connection closed
```

其中：
- Connection created：连接创建成功
- Cursor created：游标创建成功
- Query result: [(1, 'test')]：查询执行结果
- Cursor closed：游标关闭成功
- Connection closed：连接关闭成功
