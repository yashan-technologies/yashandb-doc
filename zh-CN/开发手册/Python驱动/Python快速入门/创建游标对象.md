游标对象用于执行SQL语句和获取结果。

## 游标属性

| 属性| 说明|
| ------------------ | -------------------- |
| description | 返回结果集的列信息 |
| rowcount | 返回受影响的行数 |
| arraysize | 获取/设置每次fetch返回的行数 |

## 游标方法

| 方法| 说明|
| --------------- | -------------------- |
| execute() | 执行单条SQL语句 |
| executemany() | 批量执行SQL语句 |
| fetchone() | 获取单条记录 |
| fetchall() | 获取所有记录 |
| fetchmany() | 获取多条记录 |
| close() | 关闭游标 |

## 完整示例

```python
# 通过连接对象创建游标
cursor = connection.cursor()
print("Cursor created successfully")

# 执行SQL语句（假设example_table已存在）
cursor.execute("SELECT * FROM example_table")
print("Query executed successfully")

# 获取结果
result = cursor.fetchone()
print(f"Result: {result}")

# 查看列信息
print(f"Description: {cursor.description}")

# 获取rowcount（SELECT语句execute后通常为0或-1，fetch后可能变为已取行数）
print(f"Rowcount: {cursor.rowcount}")

# 关闭游标
cursor.close()
print("Cursor closed")
```

执行：

```python
$ python cursor_example.py
Cursor created successfully
Query executed successfully
Result: ('C001', 5)
Description: [FetchInfo(name='CUSTOMER_ID', type=26, ...), FetchInfo(name='TOTAL_ORDERS', type=4, ...)]
Rowcount: 1
Cursor closed
```

其中：
- Cursor created successfully：游标创建成功
- Query executed successfully：查询执行成功
- Result：查询返回的结果
- Description：结果集的列信息（包含列名、类型等，`cursor.description`中每个元素为FetchInfo对象）
- Rowcount：受影响的行数（对于SELECT语句，可能不准确）
- Cursor closed：游标关闭成功
