## 限定名称和点符号

当一个名称项属于另一个命名项时，您可以使用点表达法使用父项名称来限定子项的名称。

| 常见使用场景| 语法| 使用说明|
|------------------|----------------------------|--------------------|
| 访问RECORD的成员 | record.member | 通过RECORD名称进行限定<br />点符号前后允许存在单个或多个空白符，空白符包括半角/全角空格、制表符`\t`，回车符`\r`、换行符`\n`以及空字符`\0`，例如`record .member` |
| 访问数组元素成员 | array(i).member | 通过数组名称进行限定<br />点符号前后允许存在单个或多个空白符，空白符包括半角/全角空格、制表符`\t`，回车符`\r`、换行符`\n`以及空字符`\0` |
| 访问函数返回的RECORD的成员 | func(arg).member | 通过RECORD名称进行限定<br />点符号前后允许存在单个或多个空白符，空白符包括半角/全角空格、制表符`\t`，回车符`\r`、换行符`\n`以及空字符`\0` |
| 访问多维数组成员 | array(i)(j).member | 通过数组名称进行限定<br />标识符和括号之间、括号和括号之间、点符号前后均允许存在单个或多个空白符，空白符包括半角/全角空格、制表符`\t`，回车符`\r`、换行符`\n`以及空字符`\0`，例如`array  (  i  )  (  j  ) . member` |
| 访问高级包的变量 | package_name.var_name | 通过包名称进行限定 |

如果在命名的PL单元中声明了一个标识符，可以使用该单元的名称来限定其声明中的名称（简单名称），使用以下语法：

*unit_name.simple_identifier_name*

如果标识符不可见，则必须限定其名称，标识符可见性具体请参考[标识符](标识符.md)。

如果标识符属于另一个模式，则必须使用模式名称限定其名称。例如：

*schema_name.package_name*
