存储过程是数据库里的一种PL对象。

- 在单机主备、主备集群部署中，只能在主库/主集群上创建、管理以及使用存储过程。

- 存储过程不适用于存算一体分布式集群部署。

创建存储过程
------

使用[CREATE PROCEDURE](../../SQL参考手册/SQL语句/CREATE PROCEDURE)语句创建存储过程，其语法定义为：

**create procedure::=**

```ebnf
= CREATE [OR REPLACE] [EDITIONABLE|NONEDITIONABLE] PROCEDURE procedure_head_clause (IS|AS) procedure_body_clause ";".
```

**procedure_head_clause::=**

```ebnf
= [schema "."] procedure_name ["(" argument_define {"," argument_define} ")"] [invoker_rights_clause].
```

**invoker_rights_clause::=**

```ebnf
= AUTHID (CURRENT_USER|DEFINER).
```

<span id="procedurebodyclause" name="procedurebodyclause"></span>

**procedure_body_clause::=**

```ebnf
= [variable_declare] BEGIN pl_statements END [procedure_name].
```

### OR REPLACE

当要创建的存储过程已经存在时，将其进行重建。

### EDITIONABLE | NONEDITIONABLE

用于语法兼容，无实际含义。

### procedure\_name

存储过程的名称，不可省略，且需符合YashanDB的[对象命名规范](../../SQL参考手册/基本SQL元素/标识符)。

### argument\_define

定义存储过程的参数（形参），可省略，此时procedure\_name()=procedure\_name。最多可以指定4095个参数。

更多详情请查阅[PL参数描述](../参数/00参数)。

### invoker_rights_clause

详情请查阅[invoker_rights_clause](./00PL对象.md#invoker)相关描述。

### variable\_declare

声明PL过程体的全局变量，可省略。

更多详情请查阅[PL声明](../PL语言基础/变量/00变量)。

### pl\_statements

定义过程体中的执行语句，为[PL语句](../PL语句/00PL语句)中的一项或多项。

示例（单机/共享集群/分布式集群部署）

```plsql
CREATE OR REPLACE PROCEDURE ya_proc(i INT) IS
BEGIN
CASE i
WHEN 1 THEN
DBMS_OUTPUT.PUT_LINE('hello');
WHEN 2 THEN
DBMS_OUTPUT.PUT_LINE('world');
END CASE;
END ya_proc;
/
```

运行存储过程
------

### SQL语句中调用

通过CALL、EXEC语句调用存储过程，其语法定义为：

```ebnf
= (CALL|EXEC) procedure_name ["(" arguments ")"].
```

arguments为与argument\_define一一对应的实参。

示例（单机/共享集群/分布式集群部署）

```plsql
exec ya_proc(1);

--result
hello
```

### 过程体中调用

格式为：_procedure\_name(arguments);_。

arguments为与argument\_define一一对应的实参。

示例（单机/共享集群/分布式集群部署）

```plsql
BEGIN
  ya_proc(1);
  ya_proc(2);
END;
/

--result
hello
world
```
