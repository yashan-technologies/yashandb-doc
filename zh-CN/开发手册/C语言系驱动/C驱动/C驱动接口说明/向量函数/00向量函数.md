C驱动向量功能是通过VECTOR数据类型实现对向量数据的存储和检索的功能。VECTOR数据类型用于存储向量数据，例如浮点数向量数组，支持向量相似度计算等操作。在数据库中，VECTOR类型用于存储定长或变长的浮点数向量。

C驱动提供了一组API函数来执行VECTOR数据类型相关的操作，包括向量的分配和释放、从文本或数组构造向量、向量转换为文本或数组、以及获取向量元数据（维度、格式）等。

|  接口名称| 接口说明|
|-------------------|--------------------------------------|
| [yacDescAlloc2](yacDescAlloc2) | 为向量描述符分配空间 |
| [yacDescFree2](yacDescFree2) | 释放向量描述符空间 |
| [yacVectorFromText](yacVectorFromText) | 从字符串构造yacVector |
| [yacVectorFromArray](yacVectorFromArray) | 从数组构造yacVector |
| [yacVectorToText](yacVectorToText) | 将yacVector转换为文本 |
| [yacVectorToArray](yacVectorToArray) | 将yacVector转换为数组 |
| [yacVectorGetDimension](yacVectorGetDimension) | 获取yacVector中向量对象的维度 |
| [yacVectorGetFormat](yacVectorGetFormat) | 获取yacVector中向量对象的数值类型 |
