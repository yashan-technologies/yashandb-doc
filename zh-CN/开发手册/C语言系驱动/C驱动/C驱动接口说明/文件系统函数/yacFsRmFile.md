## 功能简介

yacFsRmFile函数用于在当前设置的卷下删除指定文件。

## 函数声明

```c
YacResult yacFsRmFile (YacHandle hConn,
                       YacChar*  name);
```

## 参数说明

|  参数名| 说明|
| ----------------- | ----------------------------------------------------------- |
| hConn (IN)        | 连接句柄，标识与数据库的连接。                               |
| name (IN)         | 待删除的文件名称（路径，已存在的文件）。                       |
