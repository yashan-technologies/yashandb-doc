## 功能简介

yacFsMkDir函数用于在当前设置的卷下创建指定目录。

## 函数声明

```c
YacResult yacFsMkDir (YacHandle hConn,
                      YacChar*  name);
```

## 参数说明

|  参数名| 说明|
| ----------------- | ----------------------------------------------------------- |
| hConn (IN)        | 连接句柄，标识与数据库的连接。                               |
| name (IN)         | 新目录名称（路径）。名称长度限制为255字节。                   |
