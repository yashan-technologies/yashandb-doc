## 功能简介

yacFsCreateFile函数用于在当前设置的卷下创建指定文件。

## 函数声明

```c
YacResult yacFsCreateFile (YacHandle hConn,
                           YacChar*  name);
```

## 参数说明

|  参数名| 说明|
| ----------------- | ----------------------------------------------------------- |
| hConn (IN)        | 连接句柄，标识与数据库的连接。                               |
| name (IN)         | 新文件名称（路径）。名称长度限制为255字节。                   |
