C驱动文件系统功能提供了一套文件系统和目录操作接口，支持客户端程序对数据库内的非结构化数据文件进行操作。该功能采用客户端-服务端交互模式，通过CMD_FILE命令实现文件操作请求与响应。

使用文件系统函数前，需要先通过 [DBMS_FS](../../../../PL参考手册/内置高级包/DBMS_FS) 高级包创建卷，然后通过`yacFsSetCurrentVolume`设置当前卷。文件操作（创建、删除、读写等）均在当前设置的卷下进行。

|  接口名称| 接口说明|
|-------------------|--------------------------------------|
| [yacFsSetCurrentVolume](yacFsSetCurrentVolume) | 设置当前连接使用的卷 |
| [yacFsGetCurrentVolume](yacFsGetCurrentVolume) | 获取当前连接使用的卷 |
| [yacFsMkDir](yacFsMkDir) | 在当前卷下创建指定目录 |
| [yacFsRmDir](yacFsRmDir) | 在当前卷下删除指定目录 |
| [yacFsCreateFile](yacFsCreateFile) | 在当前卷下创建指定文件 |
| [yacFsRmFile](yacFsRmFile) | 在当前卷下删除指定文件 |
| [yacFsFileExist](yacFsFileExist) | 在当前卷下判断指定文件是否存在 |
| [yacFsFileStat](yacFsFileStat) | 在当前卷下获取文件信息 |
| [yacFsFileRead](yacFsFileRead) | 在当前卷下从指定位置读取文件数据 |
| [yacFsFileWrite](yacFsFileWrite) | 在当前卷下将数据写入指定文件 |
| [yacFsListDir](yacFsListDir) | 在当前卷下列出指定目录下的文件或目录 |
