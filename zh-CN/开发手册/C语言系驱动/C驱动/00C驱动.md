YashanDB C驱动提供了通过C应用程序连接和操作数据库的接口（C API）。

每个版本的YashanDB产品安装包中均会配套提供C驱动软件包，包括接口声明的头文件以及实现所有接口的动态库。开发者获取并安装驱动软件包后，即可开始通过标准的C和SQL语言使用YashanDB，具体步骤请参见[YashanDB C驱动安装说明](./C驱动安装说明/00C驱动安装说明)。

C驱动支持的操作系统+CPU架构组合如下：

- Windows 7~11 + x64

- Windows 7~10 + x86

- Linux + ARM64

- Linux + LoongArch64

- Linux + x86_64
