下表展示了所有支持的YashanDB内部数据类型：

|  内部数据类型标识符| 对应的数据库数据类型|
|------------------------|------------------------|
| YAC_TYPE_BOOL          | BOOL                   |
| YAC_TYPE_TINYINT       | TINYINT                |
| YAC_TYPE_UTINYINT      | TINYINT UNSIGNED               |
| YAC_TYPE_SMALLINT      | SMALLINT               |
| YAC_TYPE_USMALLINT     | SMALLINT UNSIGNED      |
| YAC_TYPE_INTEGER       | INTEGER                |
| YAC_TYPE_UINTEGER      | INTEGER UNSIGNED       |
| YAC_TYPE_BIGINT        | BIGINT                 |
| YAC_TYPE_UBIGINT       | BIGINT UNSIGNED        |
| YAC_TYPE_FLOAT         | FLOAT                  |
| YAC_TYPE_DOUBLE        | DOUBLE                 |
| YAC_TYPE_NUMBER        | NUMBER                 |
| YAC_TYPE_DATE          | DATE                   |
| YAC_TYPE_SHORTTIME     | SHORTTIME              |
| YAC_TYPE_TIMESTAMP     | TIMESTAMP              |
| YAC_TYPE_TIMESTAMP_LTZ | TIMESTAMP              |
| YAC_TYPE_TIMESTAMP_TZ  | TIMESTAMP              |
| YAC_TYPE_YM_INTERVAL   | INTERVAL YEAR TO MONTH |
| YAC_TYPE_DS_INTERVAL   | INTERVAL DAY TO SECOND |
| YAC_TYPE_CHAR          | CHAR                   |
| YAC_TYPE_NCHAR         | NCHAR                  |
| YAC_TYPE_VARCHAR       | VARCHAR                |
| YAC_TYPE_NVARCHAR      | NVARCHAR               |
| YAC_TYPE_BINARY        | BINARY                 |
| YAC_TYPE_CLOB          | CLOB                   |
| YAC_TYPE_BLOB          | BLOB                   |
| YAC_TYPE_BIT           | BIT                    |
| YAC_TYPE_ROWID         | ROWID                  |
| YAC_TYPE_NCLOB         | NCLOB                  |
| YAC_TYPE_JSON          | JSON                   |
| YAC_TYPE_VECTOR  | VECTOR|
