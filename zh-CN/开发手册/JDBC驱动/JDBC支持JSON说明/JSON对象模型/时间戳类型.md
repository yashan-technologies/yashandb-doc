YashanDB JDBC驱动里面定义了YasonTimestamp对象模型，用来表示JSON里面时间戳数据，是对java的Timestamp的包装类型。一般是作为YasonObject或者YasonArray的一个value使用，但是也可以单独存在。

它包含两个构造方法：

|  方法| 备注|
|----------------------------------------------|-----------------------------------|
| YasonTimestamp(Timestamp value)              | 创建一个值为指定时间戳的YasonTimestamp对象      |
| YasonTimestamp(LocalDateTime localDateTime)  | 根据localDateTime创建YasonTimestamp对象 |

它包含如下方法：

|  返回类型| 方法| 备注|
|---------------|----------------------|---------------------|
| Timestamp     | getTimestamp()       | 获取Timestamp类型的值     |
| Timestamp     | TimestampValue()     | 获取Timestamp类型的值     |
| LocalDateTime | getLocalDateTime()   | 获取LocalDateTime类型的值 |
| LocalDateTime | localDateTimeValue() | 获取LocalDateTime类型的值 |
 
```java

        YasonTimestamp timestamp = new YasonTimestamp(Timestamp.valueOf("2022-08-12 15:35:55.444555"));
        System.out.println(timestamp.getLocalDateTime()); // 2022-08-12T15:35:55.444555
        
        YasonTimestamp timestamp1 = new YasonTimestamp(LocalDateTime.of(2022,8,12,15,35,55,444555000));
        System.out.println(timestamp1.getTimestamp()); // 2022-08-12 15:35:55.444555
        
        System.out.println(timestamp1.equals(timestamp)); //true

```
