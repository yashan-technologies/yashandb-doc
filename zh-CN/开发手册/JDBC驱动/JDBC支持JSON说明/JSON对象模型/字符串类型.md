YashanDB JDBC驱动里面定义了YasonString对象模型，用来表示JSON里面字符串数据，是对java的String的包装类型。一般是作为YasonObject或者YasonArray的一个value使用，但是也可以单独存在。

它包含两个构造方法：

|  方法| 备注|
|---------------------------|-----------------------------------|
| YasonString(String value) | 创建一个值为指定字符串的YasonString对象         |
| YasonString(Object value) | 创建一个值为指定对象的toString的YasonString对象 |

它包含如下普通方法：

|  返回类型| 方法| 备注|
|---------|---------------|-------------|
| String  | getString()   | 获取String的值  |
| String  | stringValue() | 获取String的值  |

```java
        YasonString yasonString = new YasonString("stringValue");
        System.out.println(yasonString.getString()); // stringValue
        System.out.println(yasonString); // "stringValue",json里面的String类型一定是带双引号的

        //作为YasonObject的一个值使用
        YasonObject json = new YasonObject();
        json.put("key",yasonString);
        System.out.println(json); // {"key":"stringValue"}

```
