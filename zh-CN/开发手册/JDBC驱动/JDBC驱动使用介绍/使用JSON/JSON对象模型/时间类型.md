YashanDB JDBC驱动里面定义了YasonTime对象模型，用来表示JSON里面时间数据，是对java的java.sql.time的包装类型。一般是作为YasonObject或者YasonArray的一个value使用，但是也可以单独存在。

它包含两个构造方法：

|  方法| 备注|
|--------------------------------------|--------------------------|
| YasonTime(Time value)           | 创建一个值为指定日期的YasonTime对象   |
| YasonTime(LocalTime localTime)  | 根据localTime创建YasonTime对象 |

它包含如下方法：

|  返回类型| 方法| 备注|
|-----------|------------------|-----------------|
| Time      | getTime()        | 获取Time类型的值      |
| Time      | TimeValue()      | 获取Time类型的值      |
| LocalTime | getLocalTime()   | 获取LocalTime类型的值 |
| LocalTime | localTimeValue() | 获取LocalTime类型的值 |
 
```java

        YasonTime yasonTime = new YasonTime(LocalTime.of(15,35,55,434000000));
        System.out.println(yasonTime.getLocalTime()); // 15:35:55.434
        System.out.println(yasonTime.getTime()); // 15:35:55.434000

        YasonObject json = new YasonObject();
        json.put("time1",yasonTime);
        System.out.println(json); // {"time1":"15:35:55.434"}

```
