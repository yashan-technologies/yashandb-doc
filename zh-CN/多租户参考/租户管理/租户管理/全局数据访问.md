全局数据访问是指在容器数据库中可在根容器上查询所有PDB数据的能力。

基于此，DBA可以在根容器下进行所有PDB状态信息巡查和监控，减少必须直连每个PDB查询对应数据的冗余繁琐操作，CDB运维更便捷高效。

## CDB视图

YashanDB部署为容器数据库（配置参数ENABLE_PLUGGABLE_DATABASE=TRUE）时提供了一组[CDB视图](../../../全部手册/参考手册/系统视图/CDB视图)，供DBA在根容器上获取全局信息，例如查询CDB_TABLES视图可以获取当前环境中所有的表、查询CDB_ROLE_PRIVS视图可以获取当前环境中所有基于角色授权的记录等。

示例（单机/共享集群/分布式集群部署）

```sql
-- 查询所有用户自定义创建的用户
SELECT CON_ID,USERNAME,COMMON FROM CDB_USERS WHERE DATABASE_MAINTAINED = 'N';
      CON_ID USERNAME                                                         COMMON
------------ ---------------------------------------------------------------- ------
           2 SYS_PDB1                                                         N

-- 基于CON_ID还可进行连接查询，直接返回容器名称和实际数据信息
SELECT c.NAME AS CON_NAME, CDB_USERS.USERNAME, CDB_USERS.COMMON
FROM CDB_USERS
INNER JOIN V$CONTAINERS c ON CDB_USERS.CON_ID = c.CON_ID
WHERE DATABASE_MAINTAINED = 'N';
CON_NAME                                                         USERNAME                                                         COMMON
---------------------------------------------------------------- ---------------------------------------------------------------- ------
PDB1                                                             SYS_PDB1                                                         N
```

## 容器函数

通过容器函数containers可以在根容器中汇聚查询所有容器（根容器和所有PDB）中同名查询对象的相关数据，实现全局查询功能，查询结果中将生成伪列CON_ID以区分数据来源。

 

如需查询全局的汇聚数据，需满足以下要求：

- 具备所有查询对象的相应权限。

- PDB中的查询对象应与根容器中的相应对象具有相同的表结构定义。

- 若汇聚查询的列项（select_list）中存在LOB类型列，整个查询结果集将为NULL。

 

示例（单机/共享集群/分布式集群部署）

```sql
-- 获取PDB信息
SELECT NAME,TYPE,STATUS FROM V$CONTAINERS;
NAME                                                             TYPE              STATUS
---------------------------------------------------------------- ----------------- -----------------
CDB$ROOT                                                         ROOT              OPEN
PDB$SEED                                                         SEED              CLOSED
PDB1                                                             PDB               OPEN


-- 在根容器上全局查询v$parameter视图，获取所有容器（根容器和所有PDB）的某个参数配置
SELECT con_id,name,value FROM containers(V$PARAMETER) WHERE name ='DB_BLOCK_SIZE';

      CON_ID NAME                                                  VALUE
------------ ----------------------------------------------------- ----------------------
           0 DB_BLOCK_SIZE                                         8192
           2 DB_BLOCK_SIZE                                         8192

-- 基于CON_ID还可进行连接查询，直接返回容器名称和实际数据信息
SELECT a.NAME AS CON_NAME, c.NAME AS parameter, c.VALUE
FROM containers(V$PARAMETER) AS c
INNER JOIN V$CONTAINERS a ON c.CON_ID = a.CON_ID
WHERE c.NAME = 'DB_BLOCK_SIZE';
CON_NAME     PARAMETER                                             VALUE
------------ ----------------------------------------------------- ----------------------
CDB$ROOT     DB_BLOCK_SIZE                                         8192
PDB1         DB_BLOCK_SIZE                                         8192
```
