### ycsctl add network

该命令用于为集群增加公网配置。添加公网后才能使用VIP或SCAN功能。

命令格式及参数介绍如下：

```shell
ycsctl add network -subnet <subnet/netmask[/interface]> [-offline]
```

| 参数选项 | 取值 | 参数描述 |
| ---------- | ----------- | ------------------------------------------------------------ |
| -subnet |subnet/netmask[/interface]|指定公网的配置信息，格式为：子网/子网掩码/网卡名，其中网卡名可选。<br />* 若不指定网卡名，将使用可以访问给定子网的任意网卡。<br />* 若指定网卡名，请确保同一集群中所有服务器都有可以访问给定子网的同名网卡。|
| -offline | | 可选参数，表示允许在YCS未启动时执行该命令。 |

### ycsctl modify network

该命令用于修改集群的公网配置。

执行此命令前，必须确保当前集群未配置SCAN和VIP（或均已移除）。

命令格式及参数介绍如下：

```shell
ycsctl modify network -subnet <subnet/netmask[/interface]> [-offline]
```

| 参数选项 | 取值 | 参数描述 |
| ---------- | ----------- | ------------------------------------------------------------ |
| -subnet |subnet/netmask[/interface]|指定公网的配置信息，格式为：子网/子网掩码/网卡名，其中网卡名可选。<br />* 若不指定网卡名，将使用可以访问给定子网的任意网卡。<br />* 若指定网卡名，请确保同一集群中所有服务器都有可以访问给定子网的同名网卡。|
| -offline | | 可选参数，表示允许在YCS未启动时执行该命令。 |

示例

```shell
# 在线修改公网子网
$ ycsctl modify network -subnet 192.168.2.0/24/ens192
```

### ycsctl remove network

该命令用于为集群删除公网配置，必须先删除所有VIP和SCAN配置才能删除公网。

命令格式如下：

```shell
ycsctl remove network
```

### ycsctl add vip

该命令用于在集群运行时动态添加一个VIP资源。

命令格式及参数介绍如下：

```shell
ycsctl add vip -n <nodename> --vip <ip/netmask[/interface]> [-offline]
```

| 参数选项 | 取值 | 参数描述 |
| ---------- | ----------- | ------------------------------------------------------------ |
| -n |nodename|指定需添加VIP资源的实例节点名。|
| --vip | ip/netmask[/interface] | 指定VIP资源的配置信息，必须属于公网子网。格式为：IP地址/子网掩码/网卡名，其中网卡名可选。<br />* 若不指定网卡名，将延续network的网卡名配置。如果无法确保同一集群中所有服务器访问公网的网卡名一致，则必须省略。<br />* 若指定网卡名，请确保不与network指定的冲突，且同一集群中所有服务器均有可以访问公网子网的同名网卡。 |
| -offline | | 可选参数，表示允许在YCS未启动时执行该命令。 |

### ycsctl start vip

该命令用于在当前YCS上启动VIP资源。

命令格式及参数介绍如下：

```shell
ycsctl start vip [-n <nodename>]
```

| 参数选项 | 取值 | 参数描述 |
| ---------- | ----------- | ------------------------------------------------------------ |
| -n | nodename| 可选参数，指定需启动VIP资源的实例节点名，省略时默认启动当前节点的VIP资源。|

### ycsctl stop vip

该命令用于在当前YCS上停止已接管的VIP资源。

命令格式及参数介绍如下：

```shell
ycsctl stop vip [-n <nodename>]
```

| 参数选项 | 取值 | 参数描述 |
| ---------- | ----------- | ------------------------------------------------------------ |
| -n | nodename| 可选参数，指定需停止VIP资源的实例节点名，省略时默认启动当前节点的VIP资源。|

### ycsctl relocate vip

该命令用于迁移指定的VIP资源到其他YCS节点。

命令格式及参数介绍如下：

```shell
ycsctl relocate vip -n <nodename> [-t <target_nodename>]
```

| 参数选项 | 取值 | 参数描述 |
| ---------- | ----------- | ------------------------------------------------------------ |
| -n | nodename | 指定待迁移的目标VIP资源所属的实例节点名。<br/>实例节点与VIP的对应关系可通过ycsctl show config查看。 |
| -t | target_nodename | 可选参数，指定VIP资源待迁往的目标节点名称，省略时YCS将按照高可用和均匀分布的原则自动迁移。 |

### ycsctl modify vip

该命令用于修改集群的VIP资源的相关配置。

执行此命令后，会自动停止当前集群的VIP资源，需执行ycsctl start vip命令将其启动后才能正常使用VIP连接数据库。

命令格式及参数介绍如下：

```shell
ycsctl modify vip -n <nodename> --vip <ip/netmask[/interface]> [-offline]
```

| 参数选项 | 取值 | 参数描述 |
| ---------- | ----------- | ------------------------------------------------------------ |
| -n |nodename|指定需修改VIP资源的实例节点名。|
| --vip | ip/netmask[/interface] | 指定VIP资源的新配置信息，必须属于公网子网。格式为：IP地址/子网掩码/网卡名，其中网卡名可选。<br />* 若不指定网卡名，将延续network的网卡名配置。如果无法确保同一集群中所有服务器访问公网的网卡名一致，则必须省略。<br />* 若指定网卡名，请确保不与network指定的冲突，且同一集群中所有服务器均有可以访问公网子网的同名网卡。 |
| -offline |  | 可选参数，表示离线执行。不指定时默认在线执行。 |

示例

```shell
# 在线修改VIP
$ ycsctl modify vip -n host0001 --vip 192.168.1.70/24/ens192
```

### ycsctl add scan

命令格式及参数介绍如下：

```shell
ycsctl add scan -scanname <scan_name> -p <port> [-offline]
```

| 参数选项 | 取值 | 参数描述 |
| ---------- | ----------- | ------------------------------------------------------------ |
| -scanname |scan_name|指定SCAN域名，需为完整限定主机名。<br />客户端/驱动可通过该名称连接数据库。|

| -offline | | 可选参数，表示允许在YCS未启动时执行该命令。 |

### ycsctl start scan

该命令用于启动SCAN VIP。

命令格式及参数介绍如下：

```shell
ycsctl start scan [-scannumber <ordinal_number>] [-node <nodename>]
```

| 参数选项 | 取值 | 参数描述 |
| ---------- | ----------- | ------------------------------------------------------------ |
| -scannumber |ordinal_number|可选参数，指定待启动的目标SCAN VIP的序号，取值为1、2或3，省略时表示启动所有SCAN VIP。<br />序号与SCAN VIP的对应关系可通过ycsctl show config查看。|
| -node | nodename | 可选参数，指定目标SCAN VIP的启动实例节点名称，省略时YCS将按均匀分布的原则自动分配启动节点。 |

### ycsctl modify scan

该命令用于修改集群的SCAN域名或端口。

如需修改域名，在执行此命令前需根据新域名规划在DNS服务器中配置DNS解析规则。

执行此命令后，会自动停止当前集群的SCAN资源，需执行ycsctl start scan命令将其启动后才能正常使用域名连接数据库。

命令格式及参数介绍如下：

```shell
ycsctl modify scan -scanname <scan_name> -p <port> [-offline]
```

| 参数选项 | 取值 | 参数描述 |
| ---------- | ----------- | ------------------------------------------------------------ |
| -scanname | scan_name | 如需需需要域名则需指定新的SCAN域名，否则需指定原域名。 |
| -p | port | 如需修改端口则需指定新的SCAN监听端口，否则需指定原端口。 |
| -offline | | 可选参数，表示允许在YCS未启动时执行该命令。 |

示例

```shell
# 在线修改SCAN域名
$ ycsctl modify scan -scanname scan.new_example.com -p 1688
```
