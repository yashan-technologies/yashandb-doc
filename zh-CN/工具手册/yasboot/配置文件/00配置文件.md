toml配置文件用于配置搭建YashanDB的环境信息，YashanDB通过yasboot所提供的运维服务功能均以toml文件为基准。



>**Caution**:
>
> 本文提供的配置文件示例内容，主要用于介绍配置项的组成及其含义。为避免引入不必要的错误，**不建议**直接复制示例内容来手动构造配置文件。



- [服务器配置文件](服务器配置文件)（hosts.toml）和集群配置文件（集群名称.toml，根据部署形态可能为[单机配置文件](单机配置文件)、[共享集群配置文件](共享集群配置文件)或[存算一体分布式集群配置文件](存算一体分布式集群配置文件)）是通过yasboot package se/ce/de gen命令生成YashanDB需要的一套最基本的配置文件。

- [服务器检查配置文件](服务器检查配置文件)（yascheck.toml）是通过yasboot config host gen命令生成进行服务器检查的配置文件（仅使用默认检查项可以不生成该文件）。

- [集群扩容配置文件](集群扩容配置文件)（集群名称_add.toml）和[服务器扩容配置文件](服务器扩容配置文件)（hosts_add.toml）是通过yasboot config node/group gen生成YashanDB需要的扩容配置文件。

- [数据库拓扑文件](数据库拓扑文件)（集群名称_topology.toml）是通过yasboot cluster load 命令生成YASOM需要的数据库信息配置文件。
