## 版本定位

YashanDB v23.4.6版本在v23.4.4的基础上丰富了新特性与持续进行性能优化，为可用于长期服务支持的版本。

## 版本信息

**版本号**：v23.4.6.100

**发版日期**：2025 年 12 月 15 日

## 新增功能

YashanDB v23.4.6版本继承自YashanDB v23.4.4版本全部发布的功能，同时新增了以下关键特性：

### SQL引擎增强

#### SQL功能增强

- 函数能力增强

    - 新增支持VALUE内置函数：主要用于对象关系型数据（类似嵌套表）操作，将与对象表中某一行关联的关联变量（表别名）作为参数，并返回存储在该对象表中的对象实例。对象实例的类型与对象表的类型相同。VALUE函数提供了便捷访问对象属性、调用对象的方法，是操作自定义对象类型数据的关键接口。

    - 新增支持TO_BLOB内置函数：用于将BFILE类型或RAW类型数据转成BLOB数据，实现不同二进制数据类型间的兼容处理，满足二进制数据存储、操作以及传输的需求。

- PL能力增强

    - 支持创建自定义函数索引：该版本新增支持基于自定义函数创建索引，将自定义函数对列的计算结果预存储到索引中，从而加速依赖该函数计算的查询，既继承函数索引的优势，又可支持复杂业务规则的高效查询，在编写代码时简化SQL写法，无需在查询中重复编写复杂计算逻辑。

    - 支持高级包调试功能：在v23.4.6版本前，仅支持对存储过程进行调试，该版本实现支持对高级包子程序进行调试，通过调用JDBC调试器接口测试，可支持高级包子程序添加断点、全局变量显示等调试功能，实现追踪包内代码执行流程、监控变量状态、定位异常根源，确保高级包的功能正确性、逻辑完整性与性能合理性，提高了代码开发的效率。

    - 简化高级包子程序的声明/定义方式：在v23.4.6版本之前，YashanDB必须要在包头先进行对子函数/过程进行声明/定义，包体才能对声明/定义的对象进行初始化、定义实现。该版本实现跳过包头在包体直接进行声明/定义子函数/过程，使代码更灵活，提高易用性，也增强了与Oracle的兼容性。

    - 支持DBMS_XSLPROCESSOR高级包：新增DBMS_XSLPROCESSOR高级包及XML节点操作函数（valueof、selectsinglenode、selectnodes），满足企业级XML数据解析与转换需求。

- GIS能力增强：

    - 支持直接查询和插入geometry数据：在v23.4.6版本前，YashanDB在查询和插入geometry数据时，需要使用GIS函数转换后才能操作。该版本实现了直接进行geometry数据操作，即查询时可以使用select *、具体字段返回ewkb格式数据，插入时可以直接向geometry字段中插入ewkb和wkt格式数据，提高了易用性。

    - 新增支持ST_Translate函数：用于平移空间对象，将指定的空间几何对象（例如点、线、面、多边形等）沿X、Y（以及Z轴，针对三维对象）方向按指定距离移动，保持对象的形状、大小和方向不变，仅改变其在空间中的位置。

    - 新增支持ST_Scale函数：用于缩放空间对象，按照指定的比例因子对空间几何对象（点、线、面、多边形等）进行放大或缩小，改变对象的大小但保持其形状和相对比例不变（除非使用非均匀缩放）。

    - 新增支持ST_XMin、ST_XMax、ST_YMin、ST_YMax、ST_ZMin、ST_ZMax函数：用于获取空间对象边界范围极值的函数，主要针对二维或三维空间数据，提取其在X、Y、Z轴上的最小和最大值，用于快速确定空间对象的位置范围和边界。

    - 新增支持ST_DUMPPOINTS函数：用于提取空间对象中所有顶点，将复杂的空间几何对象（例如线、多边形、多点集合等）拆解为构成它们的原始顶点，并以结构化形式返回这些点的坐标信息，方便对空间对象的顶点进行单独分析或处理。

#### SQL性能增强

- 优化器支持去除无效的分组/去重操作：当数据库需要执行分组/去重操作且目标数据已无重复数据时，优化器生成的计划可去除对应的分组/去重操作，例如`SQL select c1 from (select c1 from t1 union select c1 from t1) group by c1; `中只需要执行一次union后，外层的group by分组操作可去除，减少了操作次数，提高计算效率。

- 新增支持在闪回查询时自动使用索引：若存在可用索引，数据库会自动基于对应索引进行闪回查询，提高查询效率。

- 优化器将分区剪枝调整至Cost模型评估前：在多个分区的数据分布可能存在不均匀且SQL中查询分区条件较明确的场景下，优化器可先进行分区剪枝后，再根据Cost模型评估，可减少元数据的扫描，简化Cost计算复杂度，又可避免无效的执行计划生成，从而提高查询执行效率。

### 共享集群能力

- yasboot适配主备共享集群部署中的[滚动升级](../../安装和升级/升级/升级操作/滚动升级.md)：

    在v23.4.4版本中，共享集群内核已具备滚动升级能力，但因yasboot工具暂未适配使得操作相对复杂，易用性不高，滚动升级流程包括：1. 将备集群切换成逻辑备集群；2. 升级逻辑备集群；3. 执行主备切换，把原主集群构建成物理备集群；4. 如有必要，可再回切主备。
    
    在v23.4.6版本中，yasboot支持主备共享集群在线滚动升级，一键式完成上述全流程操作，减少升级维护耗时，提高了易用性。支持从v23.4.4.0及以上版本向所有新版本进行滚动升级。

### 易用性

- 支持导入/导出XMLTYPE数据：在v23.4.6版本之前，YashanDB已经支持XMLTYPE数据类型和计算，为了提升功能的完备性，该版本新增导数工具imp/exp支持导入导出XMLTYPE数据，功能包括XML数据的导出、导出csv以及导入。实现XML数据的备份、迁移、集成和归档的能力，可灵活满足不同场景下XMLTYPE数据的传输需求，支撑业务系统的高效运作与合规管理。

- 数据库升级时支持备份项可选和备份路径可设置：在v23.4.6版本之前，YashanDB升级时始终会对数据库进行全备，在磁盘不足的场景下升级过程中存在磁盘写满的风险。该版本新增支持在升级时备份项可选和备份路径可设置能力，可按照实际的环境情况进行升级调整，能适配更丰富的磁盘配置场景，提高了灵活性。

- 支持不停库开启停止监听能力：通过新增ALTER SYSTEM LISTENER START/STOP语法，实现对监听的功能进行控制，START表示监听器正常运行模式，接受所有连接；STOP表示监听器维护模式，保持现有连接，阻止新的连接，但始终允许由sys用户发起的UDS本地连接。可在不中断数据库服务运行的前提下，灵活管理客户端连接接入，平衡运维需求与业务连续性。

### 驱动

- JDBC驱动增强

    - JDBC新增支持标准的转义语法：提供一种与数据库无关的方式来编写SQL语句，转义后的代码片段可正常在YashanDB中运行，该版本支持了日期转义{d 'yyyy-mm-dd'}、时间转义{t 'hh:mm:ss'}以及时间戳转义{ts 'yyyy-mm-dd hh:mm:ss[.f...]'}，丰富了使用场景，提高易用性。

    - JDBC新增适配XMLTYPE数据类型：可以提供一套标准化接口，实现Java应用与数据库中XML数据的交互（读取、写入、解析、修改）。

### MySQL兼容 

- 新增支持BIT_AND()、BIT_OR()、BIT_XOR()函数：用于对分组内的数值进行按位与、按位或、按位异或运算，最终返回聚合结果。

- 新增支持INTERVAL函数：用于比较一个数值与一组有序数值的大小关系，返回该数值在这组数值中的“位置索引”（即第一个大于该数值的参数的索引）。

- 新增支持ONLY_FULL_GROUP_BY sql_mode，提高MySQL兼容性。
  
    - 打开时，用于强制限制查询结果集中的投影列必须是GROUP BY子句中的分组列，或被聚合函数（例如SUM()、AVG()、MAX()等）处理过的列。
    
    - 关闭时，查询结果集中的投影列中可以是非GROUP BY子句中的分组列。

### 安全 

- 在v23.4.6版本之前，客户端通过C驱动只能一对一SSL连接到一个服务端。该版本通过支持C驱动的本地环境变量级别的配置能力，支持同时配置多个服务端且每个服务端的SSL配置信息不同，实现一对多安全连接，提高灵活性。

- 在v23.4.6版本之前，使用SSL连接时必须配置参数ssl_cert_file验证服务端的根证书，在安全要求性不高的场景下运维成本高、灵活性差。该版本对ssl_cert_file策略进行优化，调整为默认SSL连接时不需要配置ssl_cert_file参数，表示SSL连接不开启服务器端的CA根证。避免了证书更新与替换繁琐，丰富了使用场景，满足不同的安全要求程度的多选择诉求。

- 新增系统权限和对象权限：

    - CREATE JOB：具备在用户自己的schema下创建定时任务的权限（即调用DBMS_SCHEDULER.CREATE_JOB、DBMS_JOB.SUBMIT）。

    - MANAGE SCHEDULER：仅语法兼容，无实际含义。

    - LOCK ANY TABLE：具备对数据库中任意表进行锁定（sys schema除外）的权限。

    - SELECT ANY DICTIONARY：具备查询/访问sys schema下任意对象的权限。

    - DEBUG ANY PROCEDURE：具备调试任意过程体或函数（sys schema除外）的权限。

    - DEBUG CONNECT SESSION：仅语法兼容，无实际含义。

    - SELECT ON SQUENCE：具备对序列进行查询权限。
