本视图显示所有数据库级别的权限信息。

|  字段| 类型| 说明|
| --- | --- | --- |
| HOST | VARCHAR(60) | 数据库实例所在服务器的名称 |
| DB | VARCHAR(64) | 数据库的名称 |
| USER | VARCHAR(64) | 数据库用户的用户名 |
| SELECT_PRIV | VARCHAR(1) | SELECT权限 |
| INSERT_PRIV | VARCHAR(1) | INSERT权限 |
| UPDATE_PRIV | VARCHAR(1) | UPDATE权限 |
| DELETE_PRIV | VARCHAR(1) | DELETE权限 |
| CREATE_PRIV | VARCHAR(1) | CREATE权限 |
| DROP_PRIV | VARCHAR(1) | DROP权限 |
| GRANT_PRIV | VARCHAR(1) | GRANT权限 |
| REFERENCES_PRIV | VARCHAR(1) | REFERENCES权限 |
| INDEX_PRIV | VARCHAR(1) | INDEX权限 |
| ALTER_PRIV | VARCHAR(1) | ALTER权限 |
| CREATE_TMP_TABLE_PRIV | VARCHAR(1) | 创建临时表权限 |
| LOCK_TABLES_PRIV | VARCHAR(1) | LOCK TABLES权限 |
| CREATE_VIEW_PRIV | VARCHAR(1) | CREATE VIEW权限 |
| SHOW_VIEW_PRIV | VARCHAR(1) | SHOW VIEW权限 |
| CREATE_ROUTINE_PRIV | VARCHAR(1) | CREATE ROUTINE权限 |
| ALTER_ROUTINE_PRIV | VARCHAR(1) | ALTER ROUTINE权限 |
| EXECUTE_PRIV | VARCHAR(1) | EXECUTE权限 |
| EVENT_PRIV | VARCHAR(1) | EVENT权限 |
| TRIGGER_PRIV | VARCHAR(1) | TRIGGER权限 |
