```ebnf+diagram
unhex::= UNHEX "(" expr ")"
```

UNHEX函数用于将[expr](../通用SQL语法/expr)中的每对字符或每对字节解释为十六进制数，并将其转换为十六进制数所代表的字节。返回类型为二进制类型。

本函数遵循如下规则：

- expr不能为JSON类型。
- 如果expr为二进制类型或bit类型，函数会先将每个字节都转换成十六进制字符，然后将每2个十六进制字符解释为十六进制数（若识别到非十六进制字符则报错）并将其转换为十六进制数所代表的字节。
- 如果expr为其他类型，函数会先将其转换为字符串（转换失败将报错），然后将每2个字符解释为十六进制数（若识别到非十六进制字符则报错）并将其转换为十六进制数所代表的字节。
- 当expr为NULL时，函数返回NULL。

示例（单机HEAP表）

```sql
SELECT UNHEX('41') res;
+-------------+
| res         |
+-------------+
| A           |
+-------------+
1 row in set (0.00 sec)
```
