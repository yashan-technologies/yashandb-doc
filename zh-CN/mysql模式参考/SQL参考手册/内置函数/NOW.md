```ebnf+diagram
now::= NOW "(" [fsp] ")"
```

NOW函数返回数据库所在的操作系统设置的当前日期时间值，返回值类型为TIMESTAMP，格式为'YYYY-MM-DD HH24:MI:SS.ff'。

可选参数fsp为0-6的整型数字，表示返回值中小数的有效位数，若不指定参数，默认为0。

NOW函数始终返回语句开始执行的时间，若同一SQL语句中存在多个NOW函数，每个NOW函数的返回值将完全一致。该特征与[SYSDATE](./SYSDATE)函数不同。

示例（HEAP表）

```sql
-- example via yasql
SELECT NOW(), SLEEP(1), NOW();

NOW()                             SLEEP(1) NOW(0)
--------------------------- -------------- ---------------------------
2024-12-26 17:59:10.000000                0 2024-12-26 17:59:10.000000

-- example via MySQL Client
SELECT NOW(), SLEEP(1), NOW();
+---------------------+----------+---------------------+
| NOW()               | SLEEP(1) | NOW()               |
+---------------------+----------+---------------------+
| 2025-10-16 15:06:48 |        0 | 2025-10-16 15:06:48 |
+---------------------+----------+---------------------+
```
