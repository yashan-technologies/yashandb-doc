伪列的行为类似于普通列，但其数据并不存储在表中。用户可以SELECT伪列，但不能对伪列进行INSERT、UPDATE、DELETE操作。

YashanDB（mysql模式）通过变量__ysmy_rowid来实现ROWID伪列功能，表示行所在的地址。

- 该伪列仅适用于HEAP表。

- 伪列不能用于[多表条件插入](../../../全部手册/开发手册/SQL参考手册/SQL语句/INSERT.html#conditionalinsertclause)的WHEN条件子句、insert_values_clause以及子查询。

- 伪列不能用于`create view as select`和`create table as select`语句中的select子句。

- 支持rowid作为变量名。

示例（HEAP表）

```sql
SELECT __ysmy_rowid FROM area;

SET @ROWID=0; 
SELECT @ROWID:=@ROWID+1 AS ROWID,area.* FROM area;
```
