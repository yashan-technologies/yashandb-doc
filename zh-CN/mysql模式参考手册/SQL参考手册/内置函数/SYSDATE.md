```ebnf
sysdate = SYSDATE "(" [fsp] ")".
```

SYSDATE函数返回数据库所在的操作系统设置的当前日期时间值，返回值类型为TIMESTAMP，格式为'YYYYMMDD HH:MI:SS'。

可选参数fsp为0-6的整型数字，表示返回值中小数的有效位数，若不指定参数，默认为0。

SYSDATE函数返回自身开始执行的时间，若同一SQL语句中存在多个SYSDATE函数，每个SYSDATE函数的返回值将不同。该特征与[NOW](./NOW.md)函数不同。

示例（HEAP表）

```sql
-- example via yasql
SELECT SYSDATE(), SLEEP(1), SYSDATE();

SYSDATE()                       SLEEP(1) SYSDATE()
-------------------------- ------------- ---------------------------
2024-12-26 17:52:21.000000             0 2024-12-26 17:52:22.000000

-- example via MySQL Client
SELECT SYSDATE(), SLEEP(1), SYSDATE();
+---------------------+----------+---------------------+
| SYSDATE()           | SLEEP(1) | SYSDATE()           |
+---------------------+----------+---------------------+
| 2025-10-16 15:54:17 |        0 | 2025-10-16 15:54:18 |
+---------------------+----------+---------------------+
```
