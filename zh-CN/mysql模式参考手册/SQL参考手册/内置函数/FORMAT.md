```ebnf
format = FORMAT "(" X "," D ")".
```

FORMAT函数能将数字X格式化为“#,###,###.###”，四舍五入到小数点后D位，并以字符串形式返回结果。如果D为0，结果就没有小数点或小数部分。

本函数遵循如下规则：

- 如果X或D为NULL，函数返回NULL。
- 若X为非数值类型，函数会先将其转换为数值，转换过程中以科学计数法识别，若不是科学计数法将立刻截断。
- 若D为非数值类型，函数会先将其转换为数值，不能以科学计数法识别，且合法字符仅包括'0'-'9'以及作为符号位出现的'-'，其他字符将直接截断。
- 要求数字转换后大小不超过NUMBER类型精度，否则报错。

示例（单机HEAP表）

```sql

SQL> select format('1e2',1) res;

res 
--------------- 
100.0          

1 row fetched.
```
