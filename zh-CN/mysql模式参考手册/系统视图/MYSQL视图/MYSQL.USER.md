本视图显示所有用户的权限信息。

|  字段| 类型| 说明|
| --- | --- | --- |
| HOST | VARCHAR(60) | 数据库实例所在服务器的名称 |
| USER | VARCHAR(64) | 数据库用户的用户名 |
| SELECT\_PRIV | VARCHAR(1) | SELECT权限 |
| INSERT\_PRIV | VARCHAR(1) | INSERT权限 |
| UPDATE\_PRIV | VARCHAR(1) | UPDATE权限 |
| DELETE\_PRIV | VARCHAR(1) | DELETE权限 |
| CREATE\_PRIV | VARCHAR(1) | CREATE权限 |
| DROP\_PRIV | VARCHAR(1) | DROP权限 |
| RELOAD\_PRIV | VARCHAR(1) | RELOAD权限 |
| SHUTDOWN\_PRIV | VARCHAR(1) | SHUTDOWN权限 |
| PROCESS\_PRIV | VARCHAR(1) | PROCESS权限 |
| FILE\_PRIV | VARCHAR(1) | FILE权限 |
| GRANT\_PRIV | VARCHAR(1) | GRANT权限 |
| REFERENCES\_PRIV | VARCHAR(1) | REFERENCES权限 |
| INDEX\_PRIV | VARCHAR(1) | INDEX权限 |
| ALTER\_PRIV | VARCHAR(1) | ALTER权限 |
| SHOW\_DB\_PRIV | VARCHAR(1) | SHOW DB权限 |
| SUPER\_PRIV | VARCHAR(1) | SUPER权限 |
| CREATE\_TMP\_TABLE\_PRIV | VARCHAR(1) | CREATE TMP TABLE权限 |
| LOCK\_TABLES\_PRIV | VARCHAR(1) | LOCK TABLES权限 |
| EXECUTE\_PRIV | VARCHAR(1) | EXECUTE权限 |
| REPL\_SLAVE\_PRIV | VARCHAR(1) | REPL SLAVE权限 |
| REPL\_CLIENT\_PRIV | VARCHAR(1) | REPL CLIENT权限 |
| CREATE\_VIEW\_PRIV | VARCHAR(1) | CREATE VIEW权限 |
| SHOW\_VIEW\_PRIV | VARCHAR(1) | SHOW VIEW权限 |
| CREATE\_ROUTINE\_PRIV | VARCHAR(1) | CREATE ROUTINE权限 |
| ALTER\_ROUTINE\_PRIV | VARCHAR(1) | ALTER ROUTINE权限 |
| CREATE\_USER\_PRIV | VARCHAR(1) | CREATE USER权限 |
| EVENT\_PRIV | VARCHAR(1) | EVENT权限 |
| TRIGGER\_PRIV | VARCHAR(1) | TRIGGER权限 |
| CREATE\_TABLESPACE\_PRIV | VARCHAR(1) | CREATE TABLESPACE权限 |
| SSL\_TYPE | VARCHAR(0) | SSL/TLS协议类型 |
| SSL\_CIPHER | VARCHAR(0) | SSL/TLS加密算法或密码套件 |
| X509\_ISSUER | VARCHAR(0) | X.509证书中的一个字段，用于表示证书颁发机构（CA）的身份信息 |
| X509\_SUBJECT | VARCHAR(0) | X.509证书中的一个字段，用于表示证书持有者（Subject）的身份信息 |
| MAX\_QUESTIONS | BIGINT | 最大查询次数 |
| MAX\_UPDATES | BIGINT | 最大更新次数 |
| MAX\_CONNECTIONS | BIGINT | 最大连接数（所有用户） |
| MAX\_USER\_CONNECTIONS | BIGINT | 最大连接数（单个用户）|
| PLUGIN | VARCHAR(64) | 插件 |
| AUTHENTICATION\_STRING | VARCHAR(4000) | 加密密码或身份验证字符串 |
| PASSWORD\_EXPIRED | VARCHAR(1) | 密码是否已过期 |
| PASSWORD\_LAST\_CHANGED | TIMESTAMP | 最近一次修改密码的时间 |
| PASSWORD\_LIFETIME | BIGINT | 密码的有效期 |
| ACCOUNT\_LOCKED | VARCHAR(1) | 用户是否被锁定 |
