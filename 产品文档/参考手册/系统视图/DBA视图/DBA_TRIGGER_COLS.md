本视图显示所有触发器中列的使用信息。

| 字段  | 类型  | 说明                                                                                                                                                                                                                  |
| --- | --- |---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TRIGGER_OWNER | VARCHAR(64) | 触发器所属用户名                                                                                                                                                                                                            |
| TRIGGER_NAME | VARCHAR(64) | 触发器的名称                                                                                                                                                                                                              |
| TABLE_OWNER | VARCHAR(64) | 触发器所在的表所属用户名                                                                                                                                                                                                        |
| TABLE_NAME | VARCHAR(64) | 触发器所在的表的名称                                                                                                                                                                                                          |
| COLUMN_NAME | VARCHAR(64) | 触发器使用的表的列的名称                                                                                                                                                                                                        |
| COLUMN_LIST | VARCHAR(3) | 表明列是定义在UPDATE声明中（YES）还是过程体中（NO）                                                                                                                                                                                     |
| COLUMN_USAGE | VARCHAR(17) | 列在触发器中的使用场景<br> * NONE：未使用<br>  * OLD IN：旧值作入参<br> * NEW IN：新值作入参<br> * NEW IN OLD IN：新值作入参，旧值作入参<br> * NEW OUT：新值作出参<br> * NEW OUT OLD IN：新值作出参，旧值作入参<br> * NEW IN OUT：新值作出入参<br> * NEW IN OUT OLD IN：新值作出入参，旧值作入参 |
