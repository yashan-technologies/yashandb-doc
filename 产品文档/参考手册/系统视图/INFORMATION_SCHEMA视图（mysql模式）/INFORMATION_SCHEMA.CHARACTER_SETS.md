本视图显示可用字符集的信息。

| 字段                    | 类型          | 说明              |
|-----------------------|-------------|-----------------|
| CHARACTER_SET_NAME    | VARCHAR(32) | 字符集名称           |
| DEFAULT_COLLATE_NAME  | VARCHAR(32) | 字符集的默认排序规则      |
| DESCRIPTION           | VARCHAR(60) | 字符集的描述          |
| MAXLEN                | BIGINT(38)  | 存储一个字符所需的最大字节数  |
