本视图显示segment级别统计信息的属性。

| 字段            | 类型        | 说明         |
|-----------------|-------------|--------------|
| GROUP_ID       | NUMBER      | 组ID         |
| GROUP_NODE_ID | NUMBER      | 组内节点ID   |
| INST_ID        | NUMBER      | 实例ID       |
| STATISTIC#      | TINYINT     | 统计信息ID   |
| NAME            | VARCHAR(64) | 统计信息名字 |
| SAMPLED         | VARCHAR(3)  | 是否采样     |
