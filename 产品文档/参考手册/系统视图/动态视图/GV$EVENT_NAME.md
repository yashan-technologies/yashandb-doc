本视图显示等待事件的信息，等待事件的具体定义及说明请查阅[等待事件](../../等待事件)。

| 字段  | 类型  | 说明  |
| --- | --- | --- |
| GROUP_ID | NUMBER | 组ID |
| GROUP_NODE_ID | NUMBER | 组内节点ID |
| INST_ID | NUMBER  | 实例ID |
| EVENT_ID | INTEGER | 等待事件ID |
| NAME | VARCHAR(32) | 等待事件名称 |
| WAIT_CLASS_ID | BIGINT | 等待事件类ID |
| WAIT_CLASS# | BIGINT | 等待事件类号 |
| WAIT_CLASS | VARCHAR(32) | 等待事件类名字 |
