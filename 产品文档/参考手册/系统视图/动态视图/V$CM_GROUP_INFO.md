本视图显示CM模块存储的GROUP INFO信息列表。

| 字段  | 类型  | 说明  |
| --- | --- | --- |
| TYPE| VARCHAR(16) | 组类型，例如CN、DN等 |
| ID | INTEGER | 组ID |
| NAME| VARCHAR(64) | 组名 |
| VERSION | INTEGER | 组静态信息版本号 |
| NEXT_NODE_ID | INTEGER | 组中下一个节点的ID |
| CREATE_TIME | TIMESTAMP | 组创建时间 |
| LAST_UPDATE_TIME | TIMESTAMP | 组信息最后更新时间 |
