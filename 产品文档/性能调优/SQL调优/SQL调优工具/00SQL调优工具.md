- hint的使用介绍请查阅[Hint](../SQL调优工具/Hint)。

- explain的使用介绍请查阅[执行计划](../../性能调优特性与工具/执行计划)。

- autotrace的使用介绍请查阅[AUTOTRACE](../../性能调优特性与工具/AUTOTRACE)。

- outline的使用介绍请查阅[Outline](../SQL调优工具/Outline)。
