| 接口名称               | 接口说明                                 |
|--------------------|--------------------------------------|
| [SQLBindCol](SQLBindCol) | 为结果列分配存储并指定数据类型 |
| [SQLColAttribute](SQLColAttribute) | 描述结果集内列的属性 |
| [SQLDescribeCol](SQLDescribeCol) | 描述结果集的列 |
| [SQLFetch](SQLFetch) | 返回多个结果行 |
| [SQLFetchScroll](SQLFetchScroll) | 返回可滚动的结果行。 |
| [SQLGetData](SQLGetData) | 返回结果集一行一列的部分或全部数据 |
| [SQLGetDiagField](SQLGetDiagField) | 返回诊断数据结构的单个字段中的其他诊断 |
| [SQLGetDiagRec](SQLGetDiagRec) | 返回诊断数据结构（多个字段中的其他诊断） |
| [SQLNumResultCols](SQLNumResultCols) | 返回结果集的列数 |
| [SQLRowCount](SQLRowCount) | 返回受插入、更新或删除请求影响的行数 |
