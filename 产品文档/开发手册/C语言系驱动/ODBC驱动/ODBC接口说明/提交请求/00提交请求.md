| 接口名称               | 接口说明                                 |
|--------------------|--------------------------------------|
| [SQLExecDirect](SQLExecDirect) | 执行语句 |
| [SQLExecute](SQLExecute) | 执行已准备的语句 |
| [SQLNumParams](SQLNumParams) | 返回语句中参数的个数 |
| [SQLParamData](SQLParamData) | 与SQLPutData结合使用 ，在执行时提供参数数据。 |
| [SQLPutData](SQLPutData) | 发送参数的一部分或全部数据值。 |
