| 接口名称               | 接口说明                                 |
|--------------------|--------------------------------------|
| [SQLDataSources](SQLDataSources) | 返回可用数据源的列表 |
| [SQLGetFunctions](SQLGetFunctions) | 返回驱动程序函数的支持情况 |
| [SQLGetInfo](SQLGetInfo) | 返回有关特定驱动程序和数据源的信息 |
| [SQLGetTypeInfo](SQLGetTypeInfo) | 返回有关数据源支持的数据类型的信息 |
| [SQLTables](SQLTables) | 返回存储在特定数据源中的表、目录或架构名称和表类型的列表 |
| [SQLColumns](SQLColumns) | 返回指定表中的列名的列表。 |
