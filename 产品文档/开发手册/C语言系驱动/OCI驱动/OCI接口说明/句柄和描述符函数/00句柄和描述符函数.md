| 接口名称               | 接口说明                               |
|--------------------|------------------------------------|
| [OCIAttrGet](OCIAttrGet) | 获取当前指向OCI句柄的属性 |
| [OCIAttrSet](OCIAttrSet) | 设置当前指向OCI句柄的属性 |
| [OCIDescriptorAlloc](OCIDescriptorAlloc) | 分配存储空间来保存描述符或LOB定位器 |
| [OCIDescriptorFree](OCIDescriptorFree) | 释放先前分配的描述符 |
| [OCIHandleAlloc](OCIHandleAlloc) | 返回已分配和初始化句柄 |
| [OCIHandleFree](OCIHandleFree) | 显式释放句柄 |
| [OCIParamGet](OCIParamGet) | 返回由描述句柄或语句句柄中的位置指定的参数的描述符 |
