## 功能简介

OCIBreak函数用于立即执行异步中断。

## 函数声明

```c
sword OCIBreak ( void       *hndlp,
                 OCIError   *errhp );
```

## 参数说明

| 参数名    | 说明                                   |
| --------- | -------------------------------------- |
| hndlp (IN/OUT) | 服务上下文句柄或服务器上下文句柄。 |
| errhp (IN/OUT) | 错误句柄，当出现错误时可以获取诊断信息。 |
