本文将介绍YashanDB的OCI连接配置方式。

## 使用URL连接

直接使用URL连接，例如：

- 使用IPv4连接：`192.168.1.2:1688`
    
- 使用HA场景多IP primary模式（`PRIMARY:`关键字可省略）：`PRIMARY:192.168.1.2:1688,192.168.1.3:1688,192.168.1.4:1688`

- 使用HA场景多IP standby模式：`STANDBY:192.168.1.2:1688,192.168.1.3:1688,192.168.1.4:1688`
    
- 使用多IP loadBalance模式：`LOADBALANCE:192.168.1.2:1688,192.168.1.3:1688,192.168.1.4:1688`。

- 使用多IP primaryLoadBalance模式：`PRIMARYLOADBALANCE:192.168.1.2:1688,192.168.1.3:1688,192.168.1.4:1688`。

- 使用多IP standbyLoadBalance模式：`STANDBYLOADBALANCE:192.168.1.2:1688,192.168.1.3:1688,192.168.1.4:1688`。

## 使用别名连接

URL使用别名配置连接，需先在$YASDB_HOME/client/yasc_service.ini中定义DBNAME，例如：

```shell
vi yasc_service.ini

CITEST = 192.168.1.2:1688
REMOTE = PRIMARY:192.168.1.2:1688,192.168.1.3:1688,192.168.1.4:1688
REMOTE2 = STANDBY:192.168.1.2:1688,192.168.1.3:1688,192.168.1.4:1688
ABROAD = LOADBALANCE:192.168.1.2:1688,192.168.1.3:1688,192.168.1.4:1688
ABROAD2 = PRIMARYLOADBALANCE:192.168.1.2:1688,192.168.1.3:1688,192.168.1.4:1688
ABROAD3 = STANDBYLOADBALANCE:192.168.1.2:1688,192.168.1.3:1688,192.168.1.4:1688
```
