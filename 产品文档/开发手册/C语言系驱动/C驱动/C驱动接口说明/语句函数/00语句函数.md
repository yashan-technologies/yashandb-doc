| 接口名称               | 接口说明                                 |
|--------------------|--------------------------------------|
| [yacDirectExecute](yacDirectExecute) | 客户端发起执行无需绑定数据或绑定参数数据的SQL的请求 |
| [yacExecute](yacExecute) | 客户端发起执行yacPrepare预编译的SQL的请求 |
| [yacPrepare](yacPrepare) | 客户端发起预编译SQL的请求     |
| [yacNumResultCols](yacNumResultCols) |获取语句结果集中列的数量  |
| [yacFetch](yacFetch) | 客户端发起获取结果集的请求            |
| [yacNumParams](yacNumParams) | 获取语句中参数的数量 |
| [yacStmtGetNextResult](yacStmtGetNextResult) | 获取隐式结果集 |
| [yacGetData](yacGetData) | 用于客户端从已缓存的结果集中获取数据 |
