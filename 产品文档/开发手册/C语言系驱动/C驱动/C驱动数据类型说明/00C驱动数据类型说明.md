YashanDB C驱动的数据类型分为两种，以YAC_SQLT_为前缀的外部数据类型和以YAC_TYPE_为前缀的内部数据类型。
- [C驱动外部数据类型](C驱动外部数据类型)：
YashanDB C驱动使用YAC_SQLT类型代码在绑定中指定数据类型（包括YacBindParameter、YacBindParameterByName以及yacBindColumn等），开发者能够获取对应用程序透明的数据结构或数据结构句柄来构建应用程序。
- [C驱动内部数据类型](C驱动内部数据类型)：
YashanDB C驱动使用YAC_TYPE类型代码指定YashanDB数据库类型，每一个YAC_TYPE类型代码唯一确定一个YashanDB数据库类型，例如YAC_TYPE_VARCHAR映射到YashanDB中的varchar类型。此类数据类型主要用于元数据接口yacColAttribute等。
