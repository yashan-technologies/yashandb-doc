YashanDB JDBC驱动里面定义了YasonBinary对象模型，用来表示JSON里面二进制数据，是对java的byte[]的包装类型。一般是作为YasonObject或者YasonArray的一个value使用，但是也可以单独存在。

构造方法为：
YasonBinary(byte[] value)

它包含如下普通方法：

| 返回类型    | 方法           | 备注          |
|---------|--------------|-------------|
| byte[]  | getBytes()   | 获取byte[]的值  |
| byte[]  | bytesValue() | 获取byte[]的值  |

注意它的toString()方法是对byte数组进行16进制转换。

```java
        YasonBinary binary = new YasonBinary(new byte[]{97,97,-1});
        byte[] bytes = binary.getBytes();
        System.out.println(Arrays.toString(bytes)); // [97,97,-1]
        System.out.println(binary); // "6161FF"，转化成了16进制

```
