LBAC$SA_LABELS包提供了一组内置子函数，用于将策略、组件类型、级别、范围的值构成的字符串内容转为级别、范围的名称构成的字符串内容。

该内置高级包仅适用于单机部署。

## FROM\_LABEL

```plsql
LBAC$SA_LABELS.FROM_LABEL (
    ILABEL    VARCHAR(4000)
);
```
此函数用于查看由策略、组件类型、级别、范围的值构成的字符串内容对应的该策略下级别、范围名称构成的字符串内容。

| 参数 | 描述 |
| :--- | :---- |
| ILABEL| 由策略、组件类型、级别、范围的值构成的字符串内容 |

ILABEL格式如下：

```txt
policyId + 组件类型 + 级别 + '.' + [%范围%...%] + '.'
```

| 参数 | 描述 |
| :--- | :---- |
| policyId | 对应的策略值的数值字符串，长度为20字节，不足20字节需要前面补'0' |
| 组件类型 | “10” 表示只含有级别，“11” 表示含有级别和分割 |
| 级别 | 对应级别值的数值字符串，长度为4字节，不足4字节需要前面补'0' |
| 范围 | 对应间隔值的数值字符串，长度为4字节，不足4字节需要前面补'0' |

示例（单机部署）

```sql
SELECT LBAC$SA_LABELS.FROM_LABEL(ILABEL) AS LABEL FROM SYS.YLS$LAB;

LABEL                                                            
---------------------------------------------------------------- 
GENERAL:MNG                                                     

```
