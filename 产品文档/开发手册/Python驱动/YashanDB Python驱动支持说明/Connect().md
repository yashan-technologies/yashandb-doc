## 功能简介

用于创建与数据库连接的构造函数，创建连接后返回连接对象（Connection）。

### 参数列表

| 参数     | 说明             | 是否支持 |
| -------- | ---------------- | -------- |
| dsn      | 数据库连接描述符 | 支持     |
| user     | 数据库用户名     | 支持     |
| password | 数据库密码       | 支持     |
| host     | 数据库所在服务器的IP地址         | 支持   |
| database | 数据库名称       | 不支持   |
