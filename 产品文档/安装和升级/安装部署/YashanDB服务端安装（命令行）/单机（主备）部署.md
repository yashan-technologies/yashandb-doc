## 交互式部署

交互式部署支持部署yashan模式的单库或主备环境，如需搭建[级联备环境](#Cascading)或[双复制组主备部署](#dual_rep_group)只能通过手动部署。

>**Note**:
>
> 在执行交互式部署的过程中，输入相应配置后均需按**Enter**提交信息（步骤中将不再重复赘述），对于已设置默认值（形如`(default: xxx)`）且无需自定义调整的配置，直接按**Enter**进入下一步即可。

> 如需在过程中退出程序，按**Ctrl**+**C**即可。

## 手动部署（单库）

### 步骤1：生成部署文件

1. 执行yasboot package命令生成配置文件，命令详细参数可查阅[yasboot](../../../工具手册/yasboot/yasboot命令介绍/yasboot package)。

    ```shell
    $ ./bin/yasboot package se gen --cluster yashandb --recommend-param \
    -u yashan -p password --ip 192.168.1.2 --port 22 \
    --install-path /data/yashan/yasdb_home  \
    --data-path /data/yashan/yasdb_data \
    --log-path /data/yashan/log \
    --begin-port 1688 \
    # 需部署为mysql模式时，请添加如下命令选项
    --mode mysql
    ```

    默认安装所有插件，若只需安装部分插件可使用[--plugins](../../../工具手册/yasboot/yasboot命令介绍/yasboot package)参数指定。

    | 参数               | 说明                                 |
    |--------------------|--------------------------------------|
    | --cluster | 指定数据库集群名称，该名称也将作为初始数据库的名称（database name） |
    | -u,--username<br/>-p,--password       | 指定[YashanDB安装用户](../安装前准备/创建安装用户)的用户名和密码，若已配置免密登录，可省略密码参数             |
    |--port|指定SSH服务端口  |
    | -su,--sudo-username<br/>-sp,--sudo-password | 指定具有sudo权限的SSH用户名和密码，若安装用户已具备sudo权限则可省略该参数<br/>安装过程中，部分操作可能会使用或校验sudo权限，例如：如需使用[资源管理](../../../数据库管理/资源管理/00资源管理)功能，创建cgroup目录需要使用sudo权限         |
    | --install-path |指定数据库安装路径（即事先规划的[HOME目录](../安装前准备/目录划分)），支持数字、字母（区分大小写）以及部分符号（`/`、`-`、`_`、`.`）  |
    | --data-path | 指定数据存放目录（即事先规划的[DATA目录](../安装前准备/目录划分)），支持数字、字母（区分大小写）以及部分符号（`/`、`-`、`_`、`.`） |
    | --log-path | 指定数据库的[运行日志目录](../安装前准备/目录划分)，支持数字、字母（区分大小写）以及部分符号（`/`、`-`、`_`、`.`） |
    | --begin-port | 指定数据库监听端口 |
    | -m, --mode | 指定数据库的语法模式，可选项[yashandb,mysql]<br/>* yashandb：表示部署为yashan模式，省略时默认为该值，以yashan模式安装后无法直接切换至mysql模式<br/>* mysql：表示部署为mysql模式|

    用于提高数据库性能的参数：
    | 参数               | 说明                                 |
    |--------------------|--------------------------------------|
    | --create-cgroup | 可选参数，指定创建cgroup目录<br/>仅需安装可开启CPU等资源管理的单机数据库（非级联备）时需配置该参数，具体请查阅[配置资源管理](../../../数据库管理/资源管理/配置资源管理) |
    | --recommend-param | 可选参数，开启并使用推荐的配置参数 |
    | --memory-limit  | 可选参数，服务器的可使用内存百分比上限，默认为80，须配合--recommend-param使用 |
    | --cpu-limit       | 可选参数，服务器的可使用CPU百分比上限，默认为100，须配合--recommend-param使用                                           |
    | --scene           | 可选参数，参数调优的场景，可选[NORMAL]，默认为NORMAL，须配合--recommend-param使用                       |
    | --scale-factor    | 可选参数，诸如TPCH等测试场景的数据规模，默认为100，表示100G测试数据，须配合--recommend-param使用                                |
    | --table-type      | 可选参数，主要的业务的表类型，默认为HEAP，该参数会使数据库配置参数更适合此表类型，须配合--recommend-param使用 |


    执行完毕后，当前目录下将生成{集群名称}.toml和hosts.toml两个配置文件，可手动修改，但不建议删除文件中任何行，否则可能导致后续安装过程报错，或所搭建的环境后续无法进行扩展配置。

## 手动部署（1主1备1级联备）

级联备，即备库的备库，它从其上级备库接收日志，详细介绍请查阅[级联备部署](../../../高可用/YashanDB高可用概述.html#Cascading)。

### 步骤1：生成部署文件

1. 执行yasboot package命令生成配置文件，命令详细参数可查阅[yasboot](../../../工具手册/yasboot/yasboot命令介绍/yasboot package)。

    ```shell
    $ ./bin/yasboot package se gen --cluster yashandb \
    -u yashan -p password --ip 192.168.1.2,192.168.1.3,192.168.1.4 --port 22  \
    --install-path /data/yashan/yasdb_home  \
    --data-path /data/yashan/yasdb_data \ 
    --log-path /data/yashan/log \
    --begin-port 1688 \
    --node 2 \
    --cascade-node 1 --cascade-parent 1
    ```

    默认安装所有插件，若只需安装部分插件可使用[--plugins](../../../工具手册/yasboot/yasboot命令介绍/yasboot package)参数指定。

    | 参数               | 说明                                 |
    |--------------------|--------------------------------------|
    | --cluster | 指定数据库集群名称，该名称也将作为初始数据库的名称（database name） |
    |--port|指定SSH服务端口  |
    | --install-path |指定数据库安装路径（即事先规划的[HOME目录](../安装前准备/目录划分)），支持数字、字母（区分大小写）以及部分符号（`/`、`-`、`_`、`.`）  |
    | --data-path | 指定数据存放目录（即事先规划的[DATA目录](../安装前准备/目录划分)），支持数字、字母（区分大小写）以及部分符号（`/`、`-`、`_`、`.`） |
    | --log-path | 指定数据库的[运行日志目录](../安装前准备/目录划分)，支持数字、字母（区分大小写）以及部分符号（`/`、`-`、`_`、`.`） |
    | --listen-cidr       | 数据库的监听地址网段，该配置将用于LISTEN_ADDR参数，格式为`192.168.1.0/24`<br/>若生产环境中为数据库的规划了不同网段，需采用该参数指定规划的公网网段<br/>若未规划不同网段，则直接省略该参数即可       |
    | --replica-cidr      | 主备复制链路地址网段，该配置将用于REPLICATION_ADDR参数，格式为`192.168.1.0/24`<br/>若生产环境中为数据库的规划了不同网段，需采用该参数指定规划的私网网段<br/>若未规划不同网段，则直接省略该参数即可    |
    | --begin-port | 指定数据库监听端口，其他端口将根据规律自动生成，可在生成的配置文件中手动修改 |
    | --node | 主备库节点数量（不包括级联备的数量），省略则默认为1，例如部署1主1备1级联备则该参数需设置为2 |
    | *--cascade-node*      | 级联备节点个数                                           |
    | *--cascade-parent*    | 级联备绑定备节点的index                                    |


    执行完毕后，当前目录下将生成{集群名称}.toml和hosts.toml两个配置文件，可手动修改，但不建议删除文件中任何行，否则可能导致后续安装过程报错，或所搭建的环境后续无法进行扩展配置。

    ```shell
    -rw-------. 1 yashan yashan       444 Aug 31 16:27 hosts.toml
    -rw-------. 1 yashan yashan       708 Aug 31 16:27 yashandb.toml
    ```

2. 根据实际需要调整配置文件中的相关参数：

    - 数据库集群的配置文件yashandb.toml：可在group级别设置YashanDB的所有[建库参数](../../../工具手册/yasboot/建库参数)，可在node级别设置YashanDB的所有[配置参数](../../../参考手册/配置参数)。

      请参考[数据库配置调优](../../../性能调优/数据库性能基础/数据库配置调优)和自身环境配置调整相关参数。若安装高可用环境，还需了解与[主备部署强相关的参数](#PrimaryStanbyParam)。

    - 服务器的配置文件hosts.toml：可以按需修改yasom与yasagent的监听端口、日志存放路径等信息。


### 步骤2：执行安装
