## DN节点1主1备部署

以使用三台服务器部署1个MN组（MN节点1主2备）、2个CN、1个DN组（DN节点1主1备）的规格为例，介绍分布式部署形态的安装步骤。

### 步骤1: 生成部署文件

1. 执行yasboot package命令生成配置文件，命令详细参数可查阅[yasboot](../../../工具手册/yasboot/yasboot命令介绍/yasboot package)。

    ```shell
    $ ./bin/yasboot package de gen --cluster yashandb --recommend-param \
    -u yashan -p password --ip 192.168.1.2,192.168.1.3,192.168.1.4 --port 22 \
    --install-path /data/yashan/yasdb_home \
    --data-path /data/yashan/yasdb_data \
    --log-path /data/yashan/log \
    --begin-port 1688 \
    --mn 3 --cn 2 --dn 1-2
    ```

    默认安装所有插件，若只需安装部分插件可使用[--plugins](../../../工具手册/yasboot/yasboot命令介绍/yasboot package)参数指定。

    | 参数           | 说明                                                         |
    | -------------- | ------------------------------------------------------------ |
    | --cluster      | 指定数据库集群名称，该名称也将作为初始数据库的名称（database name） |
    | --port         | 指定SSH服务端口                                              |
    | --install-path |指定数据库安装路径（即事先规划的[HOME目录](../安装前准备/目录划分)），支持数字、字母（区分大小写）以及部分符号（`/`、`-`、`_`、`.`）  |
    | --data-path | 指定数据存放目录（即事先规划的[DATA目录](../安装前准备/目录划分)），支持数字、字母（区分大小写）以及部分符号（`/`、`-`、`_`、`.`） |
    | --log-path | 指定数据库的[运行日志目录](../安装前准备/目录划分)，支持数字、字母（区分大小写）以及部分符号（`/`、`-`、`_`、`.`） |
    | --listen-cidr       | 数据库的监听地址网段，该配置将用于LISTEN_ADDR参数，格式为`192.168.1.0/24`<br/>若生产环境中为数据库的规划了不同网段，需采用该参数指定规划的公网网段<br/>若未规划不同网段，则直接省略该参数即可       |
    | --replica-cidr      | 同组内主备节点复制链路地址网段，该配置将用于REPLICATION_ADDR参数，格式为`192.168.1.0/24`<br/>若生产环境中为数据库的规划了不同网段，需采用该参数指定规划的私网网段<br/>若未规划不同网段，则直接省略该参数即可    |
    | --din-cidr      | 分布式网络通信链路地址网段，该配置将用于DIN_ADDR参数，格式为`192.168.1.0/24`<br/>若生产环境中为数据库的规划了不同网段，需采用该参数指定规划的私网网段<br/>若未规划不同网段，则直接省略该参数即可    |
    | --begin-port | 指定第一个CN节点上数据库监听端口，其他端口将根据规律自动生成，可在生成的配置文件中手动修改 |
    | --mn/cn/dn     | 分别指定MN节点/CN节点/DN组-节点数量                          |

    用于提高数据库性能的参数：

    | 参数              | 说明                                                         |
    | ----------------- | ------------------------------------------------------------ |
    | --create-cgroup   | 可选参数，指定创建cgroup目录<br/>仅需开启CPU等资源管理时需配置该参数，具体请查阅[配置资源管理](../../../数据库管理/资源管理/配置资源管理) |
    | --recommend-param | 可选参数，开启并使用推荐的配置参数                           |
    | --memory-limit    | 可选参数，服务器的可使用内存百分比上限，默认为80，须配合--recommend-param使用 |
    | --cpu-limit       | 可选参数，服务器的可使用CPU百分比上限，默认为100，须配合--recommend-param使用                                           |
    | --scene           | 可选参数，参数调优的场景，可选[NORMAL,TPCH]，默认为NORMAL，须配合--recommend-param使用                       |
    | --scale-factor    | 可选参数，诸如TPCH等测试场景的数据规模，默认为100，表示100G测试数据，须配合--recommend-param使用                                |
    | --table-type      | 可选参数，主要的业务的表类型，默认为LSC，该参数会使数据库配置参数更适合此表类型，须配合--recommend-param使用 |

```shell
$ ./bin/yasboot package install -t hosts.toml
```

### 步骤3: 数据库部署

```shell
$ ./bin/yasboot cluster deploy -t yashandb.toml -p sys_password
```

| 参数               | 说明                                 |
|--------------------|--------------------------------------|
| -t, --toml | 部署数据库集群的toml文件路径 |
| -p, --sys-password |设置数据库超级管理员sys用户的密码，配置要求如下：<br/>* 密码长度为8 - 64位<br/>* 密码中不能包含对应的数据库用户名称<br/>* 密码必须同时包含数字、字母和特殊字符<br/>* OS命令相关的特殊字符（例如`@`、`/`、`.`、`!`、`$`、`'`等）需进行转义  |

> **Note**:
>
> 可通过指定`-d, --child`参数展示任务以及子任务信息，从而了解部署进度。

返回如下信息表示已成功部署。

```shell
task completed, status: SUCCESS
```

# 如~/.bashrc中已存在YashanDB相关的环境变量，将其清除

$ cat yashandb.bashrc >> ~/.bashrc
$ source ~/.bashrc

# 校验环境变量是否生效（回显信息中的路径请以实际为准）
$ echo $YASDB_DATA
/data/yashan/yasdb_data/cn-2-1

$ ./bin/yasboot package install -t hosts.toml

### 步骤3: 数据库部署

```shell
$ ./bin/yasboot cluster deploy -t yashandb.toml -p sys_password
```

| 参数               | 说明                                 |
|--------------------|--------------------------------------|
| -t, --toml | 部署数据库集群的toml文件路径 |
| -p, --sys-password |设置数据库超级管理员sys用户的密码，配置要求如下：<br/>* 密码长度为8 - 64位<br/>* 密码中不能包含对应的数据库用户名称<br/>* 密码必须同时包含数字、字母和特殊字符<br/>* OS命令相关的特殊字符（例如`@`、`/`、`.`、`!`、`$`、`'`等）需进行转义  |

> **Note**:
>
>可通过指定`-d, --child`参数展示任务以及子任务信息，从而了解部署进度。

返回如下信息表示已成功部署。

```shell
task completed, status: SUCCESS
```
