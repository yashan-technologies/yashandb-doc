## 共享集群部署（单集群）

### 步骤1：生成部署文件

1. 执行yasboot package命令生成配置文件，命令详细参数可查阅[yasboot](../../../工具手册/yasboot/yasboot命令介绍/yasboot package)。

    ```shell
    $ ./bin/yasboot package ce gen --cluster yashandb \
    -u yashan -p password --ip 192.168.1.2,192.168.1.3 --port 22 \
    --install-path /data/yashan/yasdb_home \
    ```

    | 参数               | 说明                                 |
    |--------------------|--------------------------------------|
    | --cluster | 指定数据库集群名称，该名称也将作为初始数据库的名称（database name） |

    |--port|指定SSH服务端口  |
    | -su,--sudo-username<br/>-sp,--sudo-password | 指定具有sudo权限的SSH用户名和密码，若安装用户已具备sudo权限则可省略该参数<br/>安装过程中，部分操作可能会使用或校验sudo权限，例如：<br/>* 在安装部署共享集群的过程中，会自动检测当前环境是否满足SCSI I/O Fencing的要求，需要使用sudo权限（检测报错并不会阻塞安装部署）<br/>* 如需使用[资源管理](../../../数据库管理/资源管理/00资源管理)功能，创建cgroup目录需要使用sudo权限         |

    | --data-path | 指定数据存放目录（即事先规划的[DATA目录](../安装前准备/目录划分)），支持数字、字母（区分大小写）以及部分符号（`/`、`-`、`_`、`.`） |

    | --data | 指定绑定的[数据盘](../安装前准备/目录划分.html#lun)路径 |
    | --disk-found-path | 指定磁盘发现路径，即数据盘的上一层目录 |
    | --system-data | 指定绑定的[系统盘](../安装前准备/目录划分.html#lun)路径 |

### 步骤2：执行安装

```shell
$ ./bin/yasboot package install -t hosts.toml
```

### 步骤3：数据库部署

1. 执行如下命令，部署数据库：

    ```shell
    $ ./bin/yasboot cluster deploy -t yashandb.toml --yfs-force-create -p sys_password
    ```

    | 参数               | 说明                                 |
    |--------------------|--------------------------------------|
    | -t, --toml | 部署数据库集群的toml文件路径 |
    |--yfs-force-create |YFS强制创建diskgroup  |
    | -p, --sys-password |设置数据库超级管理员sys用户的密码，配置要求如下：<br/>* 密码长度为8 - 64位<br/>* 密码中不能包含对应的数据库用户名称<br/>* 密码必须同时包含数字、字母和特殊字符<br/>* OS命令相关的特殊字符（例如`@`、`/`、`.`、`!`、`$`、`'`等）需进行转义  |

    > **Note**:
    >
    >可通过指定`-d, --child`参数展示任务以及子任务信息，从而了解部署进度。
      
    返回如下信息表示已成功部署。
    ```shell
    task completed, status: SUCCESS
    ```

2. 执行如下命令，重启数据库：

    ```shell
    $ ./bin/yasboot cluster restart -c yashandb
    ```

```shell
$ ./bin/yasboot package install -t hosts.toml
```

### 步骤3：数据库部署

1. 执行如下命令，部署数据库：

    ```shell
    $ ./bin/yasboot cluster deploy -t yashandb.toml --yfs-force-create -p sys_password
    ```

    | 参数               | 说明                                 |
    |--------------------|--------------------------------------|
    | -t, --toml | 部署数据库集群的toml文件路径 |
    |--yfs-force-create |YFS强制创建diskgroup  |
    | -p, --sys-password |设置数据库超级管理员sys用户的密码，配置要求如下：<br/>* 密码长度为8 - 64位<br/>* 密码中不能包含对应的数据库用户名称<br/>* 密码必须同时包含数字、字母和特殊字符<br/>* OS命令相关的特殊字符（例如`@`、`/`、`.`、`!`、`$`、`'`等）需进行转义  |

    > **Note**:
    >
    >可通过指定`-d, --child`参数展示任务以及子任务信息，从而了解部署进度。
      
    返回如下信息表示已成功部署。
    ```shell
    task completed, status: SUCCESS
    ```

2. 执行如下命令，重启数据库：

    ```shell
    $ ./bin/yasboot cluster restart -c yashandb
    ```

### 步骤4：配置环境变量

以安装用户登录到每个服务器上，执行如下命令生效环境变量。

```shell
# 部署命令成功执行后将会在$YASDB_HOME目录下的conf文件夹中生成<<集群名称>>.bashrc环境变量文件
$ cd /data/yashan/yasdb_home/{版本号}/conf
# 如~/.bashrc中已存在YashanDB相关的环境变量，将其清除

$ cat yashandb.bashrc >> ~/.bashrc
$ source ~/.bashrc
```
