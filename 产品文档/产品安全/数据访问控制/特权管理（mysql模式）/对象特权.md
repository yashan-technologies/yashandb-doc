对象特权是指允许用户执行特定对象的特定操作的权限，将权限范围缩小化，便于控制对象访问，保证数据安全。


| 权限名称 | 描述  |
| --- | --- |
| ALL    | 具有所有对象级权限           |
| SELECT | 使用SELECT语句对表进行查询   |
| ALTER  | 对表进行修改操作             |
| INSERT | 对表进行插入操作             |
| UPDATE | 对表更新数据                 |
| DELETE | 删除表中数据                 |
| GRANT  | 授予拥有的权限               |
| INDEX  | 对索引进行创建和删除操作               |
| REFERENCES | 允许用户在表上创建外键约束 |
