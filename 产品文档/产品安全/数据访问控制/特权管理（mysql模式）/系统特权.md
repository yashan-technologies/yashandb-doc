系统特权是允许用户执行某种系统级操作的权限，可能作用于某类对象的相关操作，也可能作用于整个数据库的相关操作。系统特权的功能广泛，请慎重授权。通常仅由管理员授予系统特权，保证被授权者是可信的用户。


| 权限名称 | 描述  |
| --- | --- |
| ALL               | 具备所有的系统特权                                               |
| CREATE USER       | 具备创建、修改、删除用户的权限                                   |
| GRANT OPTION      | 具备授予拥有的权限                                               |
| FILE              | 具备执行LOAD DATA语句进行导入的权限                              |
| SELECT            | 具备查询任意表的权限                                             |
| INSERT            | 具备对任意表进行插入数据的权限                                   |
| UPDATE            | 具备对任意表进行更新数据的权限                                   |
| DELETE            | 具备对任意表进行删除数据的权限                                   |
| CREATE            | 具备创建任意表的权限                                             |
| DROP              | 具备删除任意表的权限                                             |
| ALTER             | 具备对任意表进行修改的权限                                       |
| INDEX             | 具备任意索引的创建和删除的权限                                           |
| CREATE VIEW       | 具备创建任意视图权限                                             |
| EXECUTE           | 具备执行任意存储过程权限                                         |
| CREATE ROUTINE    | 具备创建存储过程权限                                             |
| ALTER ROUTINE     | 具备修改存储过程权限                                             |
| TRIGGER           | 具备触发器操作权限                                               |
| CREATE TABLESPACE | 具备创建表空间权限                                               |
